NEWS & TRENDS

 FITBIT EDGE: PREMIUM DESIGN FOR AN ACTIVE LIFE (4 MINUTE READ) [4]

 Fitbit Edge pairs the brand's largest, brightest Hybrid OLED tracker
display with a tactile side button for quick control mid-workout, even
with sweaty fingers. A subtly curved chassis of 100% recycled aluminum
keeps sensors against the wrist for 24/7 heart-rate and sleep
tracking. Four finishes, four redesigned band styles, and up to seven
days of battery life round out the design.

 OPENAI NOW LETS YOU TEXT YOUR CHATGPT DOT AGENT TO GET THINGS DONE (3
MINUTE READ) [5]

 ChatGPT Dot can now communicate through iMessage and RCS, letting
users assign tasks, send photos or voice notes, and receive proactive
updates without opening ChatGPT. Dot can use context from ChatGPT
conversations and connected channels to decide where updates belong,
while users can specify that only urgent information should arrive by
text and approvals still happen inside ChatGPT. The beta is currently
limited to ChatGPT Pro users in the US, with one-to-one messaging
supported but no group chats, regular phone calls, or FaceTime.

 WINDOWS SECURITY IS FINALLY GETTING THE WINDOWS 11 MAKEOVER IT
SHOULD'VE HAD YEARS AGO (2 MINUTE READ) [6]

 Microsoft is redesigning Windows Security to finally align its
interface with the rest of Windows 11, replacing layouts and visual
elements that still feel inherited from an older generation of
Windows. Navigation, typography, spacing, colors, controls, dialogs,
and status indicators are being modernized, with layouts also adapting
more consistently across different window sizes. The update
additionally improves how security status and available actions are
communicated, while device information on supported managed PCs will
progressively load so useful details appear sooner.

OPINIONS & TUTORIALS

 NOBODY ASKED FOR THE SPARKLE BUTTON (13 MINUTE READ) [7]

 Products, from note apps to banks, ship the same AI chat panel behind
a sparkle icon, often switched on by default and hard to turn off. Big
cloud firms are projected to spend more than their cloud revenue on
capex, while a cited study found that 95 percent of companies saw no
measurable return from generative AI pilots. The fix is to build
features with AI, not AI features, and to ask who asked, what it's
named after, and whether it survives off by default.

 THE SYSTEM I NO LONGER KNOW BY HEART (6 MINUTE READ) [8]

 Working with AI agents means the author no longer memorizes every
detail of the design system they build, a shift that requires making
systems legible to LLMs. That knowledge has to move into the system
itself, through explicit naming, current documentation, and
composition rules, since agents can't rely on informal context or
unwritten history. Understanding why the system works still matters,
but less inventory in the designer's head is a trade worth taking if
the system knows more about itself.

 BUILDING AN AI-READY DESIGN SYSTEM LIBRARY: CODE → FIGMA WITH MCP.
HANDS-ON GUIDE (15 MINUTE READ) [9]

 Figma captures only part of the behavior encoded in production
components, leaving AI to invent missing details such as focus order,
error states, accessibility behavior, and failure handling when
translating designs directly into code. Reversing the workflow makes
code the source of truth and Figma its visual mirror, with AI and MCP
transferring real tokens, styles, properties, variants, and states
from a repository into a usable design library. Storybook provides
designers with a visual view of the production system, while explicit
documentation of anything that cannot be represented in Figma helps
maintain parity instead of allowing invisible differences to
accumulate.

 DESIGNING A SKILL (5 MINUTE READ) [14]

 Agent skills can be treated like apps whose interfaces happen to be
written largely through instructions, with both the human invoking the
skill and the AI interpreting it acting as users. Building a polished
skill requires many familiar design practices, including finding the
right form, refining copy, creating a visual system, anticipating
repeated use, offering meaningful customization, and testing across
different contexts. Precise instructions matter because agents fall
back on familiar patterns when given vague directions, making skills a
useful place to encode the context, trade-offs, intuition, and taste
that individual prompts cannot reliably communicate.
