DEEP DIVES

 THE FUTURE OF DATA SCIENCE AND ANALYTICS ENGINEERING AT KLAVIYO (4
MINUTE READ) [6]

 AI can produce code and analysis faster than people can review it at
Klaviyo, making human attention and clear ownership the main
bottlenecks. Data science and analytics engineering are merging into a
broader role focused on guiding AI, checking its work, and turning
useful findings into action.

 HOW PINTEREST IMPROVED ANALYTICS AGENT COMPLIANCE WITH LOOP
ENGINEERING (10 MINUTE READ) [7]

 Pinterest's Analytics Agent can skip required steps, such as
inspecting table metadata before writing SQL. Manual instruction edits
left one rule at 64% compliance, so the team built loop engineering:
propose a change, test it on paired test suites, and keep what works.
The first large run reached 89.3% compliance, though 10.3% of cases
changed verdict between runs.

 READ LESS, SOLVE MORE: TOKEN-EFFICIENT SPARSE READING FOR AI AGENTS
(8 MINUTE READ) [8]

 SparseRead is a training-free control layer that decides how much of
a file, webpage, or repository enters an agent's context. Its read
gate, bounded evidence packs, and explicit raw fallback target the
common read-everything pattern. The authors report lower token use and
latency without changing the model across six models and five
workloads.

OPINIONS & ADVICE

 DO DATA ROLES HAVE A FUTURE? (8 MINUTE READ) [9]

 This post splits data work into production, interpretation, and
accountability, and argues AI makes production dramatically cheaper
while the other two stay human. In the 2026 Practical Data Community
Survey, 80% of respondents used AI daily. Only about 10% had built it
into organisational workflows, and nearly 89% still wrestled with
basic data modelling.

 DATA GOVERNANCE THAT ACTUALLY RUNS (8 MINUTE READ) [10]

 Governance-as-code turns policy into checks across a local,
open-source stack: MinIO for S3-like intake; Postgres for operations
and warehousing; Airflow 3 and dbt for pipelines; DataHub, Apache
Ossie, and Superset for catalog, semantic definitions, and dashboards;
and MCP-connected AI assistants. CI enforces contracts, ownership,
masking, lineage, consumer-impact approval, and least-privilege access
before production.

 HOW OPEN IS OPEN? ICEBERG, CATALOGS, AND USER CHOICE (5 MINUTE READ)
[11]

 Open table formats do not by themselves make a lakehouse portable: an
Iceberg catalog's support for commits, metadata loading, planning,
concurrent writers, and credentials can still create hard-to-see
dependencies. The proposal is a deployable community baseline built
around the REST catalog protocol, Apache Polaris, compatibility
testing, performance benchmarks, and tested migration procedures, so
teams can verify what they can run, swap, and take with them.

 AUTO ONTOLOGY: GROUNDING AGENTS IN ENTERPRISE DATA (GITHUB REPO) [15]


 NVIDIA's Apache-licensed Auto Ontology turns database metadata into a
semantic graph that humans can review and certify, and agents can
access over MCP, API, or CLI. It maps business terms, certified SQL
attributes, and relationships to underlying data so it can generate
queries and disclose their provenance. The aim is to make
natural-language analytics more consistent and auditable than direct
text-to-SQL.

 PYPI'S REDESIGNED PROJECT PAGES WITH CLEARER SECURITY SIGNALS ARE NOW
LIVE (6 MINUTE READ) [16]

 PyPI has redesigned its package pages with a security tab showing
where release files came from and warnings when that information is
missing, inconsistent, or unexpectedly changed. Updated file lists and
release histories make packages easier to assess, though verified
origins do not guarantee safe code.

 DB-BRANCH (GITHUB REPO) [17]

 db-branch is a self-hosted, open-source tool that creates isolated
MySQL and PostgreSQL database copies in seconds, sharing existing
storage until changes are made. It lets developers and AI agents test
queries, migrations, and upgrades without changing production data,
with options to reset, restore, or automatically delete each copy.

 POSTGRESQL 18.7, 17.12, 16.16, 15.20, 14.25, AND 19 RC 2 RELEASED! (4
MINUTE READ) [18]

 PostgreSQL shipped patch releases for all supported branches, fixing
52 security vulnerabilities and more than 140 bugs. PostgreSQL 14 is
now end-of-life, so production teams should upgrade to a supported
version. The updates are cumulative and usually straightforward,
though some deployments may also need index rebuilds or a fresh full
backup.

MISCELLANEOUS

 WHAT THOUSANDS OF CONVERSATIONS LOOK LIKE INSIDE A LANGUAGE MODEL (9
MINUTE READ) [19]

 An experiment mapped Qwen's internal representations of thousands of
question-and-answer examples, finding overlapping regions shaped
partly by language, with Chinese more visibly separated from English,
German, Croatian, and Python code. The 3D maps captured only 17.6% of
the full variation, showing how visualizations can reveal patterns
while hiding much of the underlying complexity.

 REAL-TIME ALERT IN SPARK (6 MINUTE READ) [20]

 UiPath built a Spark Structured Streaming alerting system that
evaluates 20,000 alert definitions per minute, including windowed
conditions and SLA checks, without repeatedly rescanning source data.
The key design was joining streams to static definitions once and
managing state carefully, which cut memory from 12 GB to 4 GB and
reduced downstream network calls.

row counts, and low-selectivity filters can still touch most heap
