DEEP DIVES

 FACT-CHECKING AT SCALE: BUILDING A MORE ACCURATE AND EFFICIENT
SYNOPSIS FACTUALITY SYSTEM (11 MINUTE READ) [7]

 Netflix automatically checks synopses of its shows for factual
errors. Its new factuality service cuts cost per synopsis by 52.4% and
raises recall on non-factual synopses from 0.77 to 0.86. Its
explanations now overlap about 82% with human annotators' reasoning,
up from about 69%.

 TIMESTRAL, T0, TABBY, AND MORPHEUS-2.0 COMPARED ON GIFT-EVAL (22
MINUTE READ) [8]

 Mistral, The Forecasting Company, Huawei, and JPMorganChase released
time-series foundation models between September 10 and October 16.
Sean Moran compared them on GIFT-Eval and reran the three with public
weights. The top three are hard to separate, with Timestral ahead on
CRPS and Morpheus on MASE. Training appears to explain much of the
recent improvement.

 PARQUET'S REVISED MODULAR FOOTER PROPOSAL: ROW GROUPS STOP BEING
PHYSICAL BOUNDARIES (14 MINUTE READ) [9]

 A revised Apache Parquet proposal would replace monolithic Thrift
footers with independently readable metadata modules encoded as
Parquet pages. Column chunks become contiguous page sequences,
row-group metadata becomes optional, and statistics can describe
arbitrary row ranges rather than fixed groups. Readers could retrieve
metadata only for relevant columns, reducing planning overhead on wide
tables. The redesign remains under community review and would require
changes across readers and writers.

 ICEBERG V4 STATS-ONLY FIELDS: HOW TABLES STORE STATISTICS FOR
PARTITION EXPRESSIONS (15 MINUTE READ) [10]

 Apache Iceberg v4 introduces stats-only fields that store metadata
for derived expressions, such as partition buckets or case-normalized
strings, without materializing additional table columns. Statistics
are encoded as typed fields in manifest content_stats structures,
enabling expression-aware file pruning. A new file-level tight_stats
flag identifies exact live-row counts and eligible bounds, improving
planning and potentially enabling metadata-only computations without
scanning underlying data files.

 IS BI DEAD? WHY HEX HIT RESET AND REWROTE EVERYTHING FOR THE AI AGENT
ERA (29 MINUTE VIDEO) [11]

 Traditional drag-and-drop BI is losing its value as AI agents become
better at building charts and apps through code. BI's future lies in
providing trusted data, business context, and governance so people can
generate and use reliable analysis with any agent.

 WHY THE LAKEHOUSE VENDORS AND THE CLOUDS BET ON POSTGRES FOR AI
APPLICATIONS (11 MINUTE READ) [12]

 Databricks bought Neon for around one billion dollars, and Snowflake
bought Crunchy Data for around 165 million dollars. Google, Amazon,
and Microsoft have each extended their Postgres services. This post
explains why five vendors with five strategies chose the same
database, what the extensions made possible, and what to ask before
committing to a Postgres offering.

 MCP ON RAW DATA IS JUST EXCEL HELL AGAIN (4 MINUTE READ) [13]

 Connecting AI agents directly to operational systems through MCP
risks recreating fragmented spreadsheet analytics at machine speed.
Without governed business rules, agents accessing Salesforce, Stripe,
or HubSpot independently can produce conflicting revenue and customer
metrics. A more reliable architecture separates an ontology that
translates business intent from a precision layer that enforces tested
calculations, keeping the warehouse's role as a consistent source of
truth.

 CLAUDE WHITEBOARDS, CLAUDE SHEETS, AND CLAUDE DATA (6 MINUTE READ)
[17]

 Anthropic made Claude Dashboards generally available as Claude Data,
which answers questions over warehouses such as Amazon Redshift,
BigQuery, and ClickHouse. In beta, data teams can certify the queries
everyone should use, and live sharing shows current numbers to
colleagues without their own connector access.

 DBDELVE: A LIGHTWEIGHT DATABASE CLIENT BUILT WITH RUST AND GPUI
(GITHUB REPO) [18]

 DBDelve is an open-source database client built with Rust and GPUI,
designed as a native alternative to heavier desktop database tools. It
supports multiple SQL databases, schema-aware completion, query plans,
and previewable data edits. CSV, Excel, JSON, and Parquet files can
also be opened directly through embedded DuckDB.

 SKIPPER, AIRBNB'S EMBEDDED WORKFLOW ENGINE, IS NOW OPEN SOURCE (6
MINUTE READ) [19]

 Airbnb has open-sourced Skipper, the embedded workflow engine its
teams run in production, under Apache 2.0. Processes are Java or
Kotlin classes whose progress persists in the service's own database,
with no central orchestration cluster. Replicas run the scheduler and
use leases to take over work when one fails.

MISCELLANEOUS

 E-MEANS: OUTPERFORMING K-MEANS IN ONE-TENTH THE EPOCHS (9 MINUTE
READ) [20]

 Meta FAIR researchers introduced e-means, a mini-batch clustering
algorithm that updates centroids using exponential moving averages
instead of repeatedly processing entire datasets. Across embedding
benchmarks, it achieves lower clustering loss in 1.4–2.6 epochs than
traditional Lloyd's k-means reaches in 25, with reported GPU speedups
of 10–45x against optimized implementations.

 WHO IS ACTUALLY USING YOUR SNOWFLAKE MCP SERVER? (15 MINUTE READ)
[21]

 Snowflake's query history cannot tell a Snowsight query from the same
SQL sent by Claude through an MCP server. This post presents a fix
that gives each MCP server its own OAuth security integration, then
joins query history to login history on one column to get usage per
server, user, and day. It also covers where the approach stops
working.
