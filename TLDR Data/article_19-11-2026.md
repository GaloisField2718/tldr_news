DEEP DIVES

 REBUILDING DATA LINEAGE AT LINKEDIN: FROM STORAGE TO COMPUTE (15
MINUTE READ) [6]

 LinkedIn rebuilt its data lineage platform to capture dependencies
directly from running jobs, giving engineers a more precise view of
where data comes from and what depends on it. The resulting graph
covers about 6 million datasets and helps teams trace incidents,
assess the impact of changes, and safely retire unused pipelines.

 DE-IDENTIFYING TEXT AT SCALE: HOW AIRBNB PROTECTS PERSONAL DATA IN AI
TRAINING (11 MINUTE READ) [7]

 Training teams need realistic text data without letting PII leak into
shared ML workflows. Airbnb packaged open-source Presidio, originally
developed by Microsoft, as an in-process pipeline step, added
domain-specific recognizers and multilingual evaluation, and then
tagged de-identified datasets through its model registry. The useful
pattern is turning privacy policy into testable, reusable data
controls rather than asking every team to improvise.

 MYSQL TABLES IN FOUR OPEN SOURCE ICEBERG CATALOGS, READ BY TRINO AND
DUCKDB (5 MINUTE READ) [8]

 Can MySQL changes land in Iceberg without a bespoke warehouse
pipeline? DBTrail followed the binlog, exported initial and
incremental snapshots into four open-source REST catalogs, then
checked row counts and aggregates through Trino and DuckDB against
MySQL. The tests surfaced real interoperability gaps around credential
vending and equality deletes—not just a happy-path compatibility
claim.

 AGENTIC DATA ENGINEERING IS HERE! PROJECT OSMOS: WHAT, WHY, AND HOW?
(22 MINUTE READ) [9]

 Microsoft Fabric's Project Osmos is an AI agent that plans, builds,
runs, and validates Spark data pipelines from a written specification.
In a test using Vienna's public transit timetables, it built a working
pipeline, but independent checks caught a daylight saving bug that the
agent's own tests missed.

 ARE WE FINALLY ENTERING THE GOLDEN AGE OF DATA SCIENCE? (6 MINUTE
READ) [10]

 AI and modern data tools are making it faster to build pipelines and
answer routine business questions. This gives data scientists more
time to ask questions that matter, design experiments, and use AI
agents to test what actually drives business outcomes.

 DATA CONTRACTS (32 MINUTE READ) [11]

 Data contracts apply API design to datasets, describing their
contents and guarantees so that people and AI agents can work with
data on their own. A quality rule, such as less than 1% empty names,
becomes an assertion that tooling can pass or fail. Published test
results can then show how often each promise was kept.

 PGVECTORFAST (GITHUB REPO) [13]

 pgvectorfast is a drop-in replacement for pgvector that uses a faster
buffer pool to speed up vector search and analytical queries in
PostgreSQL.

 MONGODB ACQUIRES FIREBOLT (4 MINUTE READ) [14]

 MongoDB has acquired Firebolt and will run its analytics engine
alongside the database, kept in sync automatically so there is no
pipeline to build. MongoDB pitches it as removing the data-movement
tax, since agents can drive thousands of concurrent queries and need
sub-second answers on fresh data. It will join search, vector search,
and Voyage AI models in the platform.

 OPEN SOURCE DOCUMENTDB 1.0 REACHES GENERAL AVAILABILITY (3 MINUTE
READ) [15]

 DocumentDB 1.0 brings an MIT-licensed, MongoDB-compatible document
store to PostgreSQL through an extension and protocol gateway, letting
existing drivers and queries work with a familiar relational
foundation. The GA release covers PostgreSQL 15-18, adds a Kubernetes
operator, and focuses on stability across indexing, aggregation, and
geospatial queries.

MISCELLANEOUS

 AIRFLOW PLAYS GTA2 (GITHUB REPO) [16]

 This Apache Airflow 3.4 demo uses a local AI model to drive a car
through a custom delivery mission in Grand Theft Auto 2. Each move is
one iteration of an Airflow task loop, and a dashcam plugin lets you
watch the run live or replay it later.

 SECURING ENTERPRISE DATA AGENTS WITH POLICY AS CODE: A PREFLIGHT GATE
FOR MULTI-DOMAIN NL2SQL (12 MINUTE READ) [17]

 Shared service accounts can bypass the user-level controls a data
agent is meant to enforce. This prototype parses generated SQL into an
AST, resolves every table and column dependency, evaluates CEL
policies, then prepares approved row filters before execution.
Database roles remain the final guardrail. The takeaway: authorize the
query's actual dependencies, not just its visible output.

 HOW ONE SURREALQL QUERY SCANS 10 BILLION ROWS A SECOND (9 MINUTE
READ) [18]

 SurrealDB says its Earth database scanned more than 10 billion rows
per second in a launch benchmark by splitting one query across about
1,000 Cloudflare Workers. Each worker reads a different slice of the
same database snapshot, and SurrealDB checks and combines the results
into one answer.
