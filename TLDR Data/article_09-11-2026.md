DEEP DIVES

 THE COMPONENTS OF AGENT MEMORY (18 MINUTE READ) [7]

 Anthropic's Lance Martin describes dreaming, where Claude reflects on
past session logs to fix mistakes in its memory notes and build new
ones. As dreaming scaled from two to 128 sessions over about 350,000
Stainless files, scores on 25 questions rose from 13% to 48%. On
merger questions, a wiki beat search alone 87% to 73%.

 HOW KLAVIYO SCALED ANALYTICS BY GETTING OUT OF THE WAY (8 MINUTE
READ) [8]

 Klaviyo expanded its AI analytics platform from a four-person
experiment to hundreds of monthly users by centralizing business
context, governed metrics, and warehouse access. Its KBI system
combines over 100 dbt semantic metrics, a curated 90-table
environment, and trusted SQL checks behind a common agent interface.
Most warehouse queries now originate from agents, reducing dependence
on manual analyst requests while keeping data definitions consistent.

 SAFE AND EFFICIENT MULTI-EPOCH EMBEDDING TRAINING (12 MINUTE READ)
[9]

 Pinterest found that training its large ID embeddings for multiple
epochs degraded Homefeed ranking quality by nearly 6%. Decoupling
embedding optimization from the rest of the model, freezing embeddings
during the first epoch, and adapting them later reversed the problem,
improving online saves by 1.09%. Semi-synchronous prefetching and
communication optimizations also reduced GPU idle time during
distributed training.

 HOW JETBRAINS BUILT CROSS-DATABASE QUERIES INTO DATAGRIP WITH DUCKDB
(4 MINUTE READ) [10]

 JetBrains users had long asked to join data across database
connections in one query. Rather than build its own engine, the
DataGrip team chose DuckDB over Apache Calcite because it was the
simplest to integrate. Custom table functions plug DuckDB into
DataGrip's existing query execution, so PostgreSQL, MySQL, and MongoDB
data can meet in one query.

OPINIONS & ADVICE

 THE DATA PRODUCT PLATFORM NAVIGATOR (15 MINUTE READ) [11]

 Data mesh adoption often stalls because teams must assemble data
products from disconnected infrastructure, catalogs, and deployment
tools. Tom De Wolf proposes a four-level maturity model for
self-service data platforms, from fragmented scripts and tickets to
integrated developer ecosystems. He argues that Level 3, where
complete data products can be provisioned through a
platform-as-a-product experience, is the minimum required for scalable
decentralized ownership.

 YOUR LLM WRITES GOOD SQL. THAT'S NOT THE SAME AS SAFE SQL (3 MINUTE
READ) [12]

 Accurate text-to-SQL can still expose unauthorized data when
generated queries ignore business context and access policies. In a
synthetic benchmark of 900 queries, policy-aware validation applied
row filters, column masking, and scope restrictions before execution,
eliminating observed data leaks while adding approximately 6.5 ms per
query. Permissions must be enforced in code rather than entrusted to
model prompts.

 THE HUMAN SIDE OF THE SEMANTIC LAYER: TRANSLATING DATA MEANING ACROSS
TEAMS (13 MINUTE READ) [13]

 Semantic layers need shared human understanding, because teams can
interpret the same metric differently even when its calculation is
consistent. Governance should pair formal definitions with
plain-language explanations, realistic examples, and clear decision
rights, then test whether teams apply them consistently.

 APACHE SPARK 4.3.0 RELEASE (10 MINUTE READ) [15]

 Apache Spark 4.3.0 brings stateful processing to Structured
Streaming's Real-Time Mode, supporting aggregations, deduplication,
and custom stateful operations with approximately 100 ms end-to-end
latency. Declarative Pipelines adds SCD Type 2 Auto CDC, while the SQL
engine gains ASOF joins, JSON_TABLE, and optimizations for smaller
workloads.

 SIGLAKE: AN OPEN-SOURCE OBSERVABILITY LAKEHOUSE BUILT ON ICEBERG AND
DATAFUSION (GITHUB REPO) [16]

 Siglake is a Rust-based observability engine that ingests
OpenTelemetry logs and traces into Apache Parquet and Iceberg tables
on object storage. Its architecture uses an Arrow write-ahead log for
streaming ingestion and DataFusion for distributed SQL queries,
eliminating the need for Kafka or proprietary storage formats. The
project reports ingesting over 400,000 rows per second in distributed
tests.

 APACHE HOP 2.20 ADDS NATIVE ICEBERG PIPELINES AND AI PROCESSING (10
MINUTE READ) [17]

 Apache Hop 2.20 introduces native Apache Iceberg reads and writes
without Spark, partitioned Parquet output, and new data-quality
transformations. The open-source ETL platform also adds text embedding
pipelines, pgvector integration, OpenLineage support, and an optional
AI assistant with human-reviewed changes.

MISCELLANEOUS

 CLEANING OR RECALLING? KNOWLEDGE DEPENDENCE IN LLM-BASED DATA
CLEANING (23 MINUTE READ) [18]

 Across eight LLMs, researchers found that data-cleaning performance
often depends on familiar names and facts, with one model's
year-repair accuracy falling from 91% to 18% when films were renamed.
Models also overwrote valid table values with remembered facts, while
flawed benchmark answers sometimes rewarded incorrect repairs.

 HOW WE BUILT NASA'S ZERO-SHOT DETECTOR FOR GAS LEAKS FROM SPACE (5
MINUTE READ) [19]

 NASA JPL's Daily Methane Digest scans every scene from the EMIT
instrument on the space station and cuts alert times from months to
about 24 hours. Its U-Net, trained only on methane, also maps carbon
monoxide, ammonia, and nitrogen dioxide plumes without retraining. On
two years of archived scenes, it found 157 methane plumes that human
review missed.
