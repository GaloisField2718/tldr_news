HEADLINES & LAUNCHES

 DEEPINFER (GITHUB REPO) [7]

 DeepInfer is the inference framework that powers DeepSeek's
large-scale production services. This repository contains a version
for offline inference with the core features needed for serving at
scale. It allows anyone to run DeepSeek-V4.1-Flash on NVIDIA SM100
GPUs or Huawei Ascend 950 NPUs. A KV cache system, VE/Prefill/Decode
disaggregation, and load balancing across data-parallel replicas for
both prefill and decode are still required for a complete inference
service.

 TorchTPU is an open-source PyTorch backend designed to make running

inference through optimized eager execution, torch.compile

DEEP DIVES & ANALYSIS

 THE NEXT BOTTLENECK IN AI FOR SCIENCE (9 MINUTE READ) [10]

 AI is speeding up individual research tasks, but the overall process
of turning predictions into validated discoveries is still
constrained. If AI is able to push science, it will also push economic
growth, as a big part of economic growth is innovation and scientific
discovery. Discovery is still constrained by the types of tasks that
AI is not yet good at. This post looks at where the bottleneck is
today, how that is evolving, and what impact this has on scientific
research more broadly.

 THE GAP BETWEEN GPUS AND COMPUTE (4 MINUTE READ) [11]

 AI infrastructure operators face seemingly unlimited compute demand,
but financing, power availability, hardware deployment, and public
opposition constrain supply. Older GPUs retain value longer than
expected, while securing capital and reliably operating clusters are
becoming competitive advantages.

 THE AGE OF REASONING (25 MINUTE READ) [12]

 Metis Reasoning proposes an AlphaGo-inspired architecture that
separates verified knowledge from learned reasoning strategies. By
explicitly tracking evidence, uncertainty, and reasoning steps, the
framework aims to reduce hallucinations, enable auditable conclusions,
and improve generalization across domains.

 REVIEW OF THE "MISALIGNMENT IN HIGH-STAKES SETTINGS" SECTION IN
ANTHROPIC'S RISK REPORT (30 MINUTE READ) [13]

 METR reviewed Anthropic's "Misalignment in high-stakes settings" and
largely agrees that the misalignment risk of covered models is low due
to limited capabilities, not robust safeguards. However, current
evaluations may not reliably identify risks if they increase, and
benchmarks fail to assess models' ability to deceive Anthropic's
monitoring systems. Recent incidents revealed undetected real-world
misalignments, challenging claims of low risk and suggesting
deficiencies in Anthropic's monitoring and risk assessments, leading
to recommendations for comprehensive red-teaming and expanded risk
frameworks.

 BUILDING LAMINAR: RAMP'S MANAGED AGENTS PLATFORM (14 MINUTE READ)
[15]

 Laminar is an in-house agent harness for Ramp's agentic products. It
features secure conversation history storage, session compaction,
standard interfaces for tool calling, message queuing and steering,
subagents, multiplayer chat support, observability tooling, and much
more. The first version of Laminar was built in six weeks with a small
team of obsessive, experienced engineers who worked with and steered
the agents. Its code was generated entirely by agents using the most
powerful models available at the time. While building in-house has
become cheaper, Ramp still needs good engineers to be on-call, keep
the platform healthy, and figure out what product teams actually need
and how it fits into the bigger picture.

 LLM-D (WEBSITE) [16]

 llm-d is a Kubernetes-native stack for distributed LLM inference. It
runs vLLM, SGLang, and more across clusters, turning single-node
engines into production-grade serving on local hardware. llm-d
provides tested deployment recipes for common production patterns that
are adaptable starting points across models, hardware, and workloads.
It runs production LLM inference across GPUs, TPUs, XPUs, CPUs, and
emerging NPUs with consistent performance patterns, so teams can
deploy once and scale anywhere with predictable cost and behavior.

 MAKING EVERY HARNESS DURABLE (7 MINUTE READ) [17]

 Vercel's durable-harness allows agent harnesses to run durably in the
cloud out-of-the-box. It allows users to run Pi, OpenCode, Codex, and
Claude Code durably on Vercel or self-hosted on their own Postgres
instance. durable-harness ensures that sessions survive crashes
mid-turn and keep running even if the browser disconnects. Turns that
lose function partway through continue from the log on a new one
without manual retry and without repeating what already finished.
