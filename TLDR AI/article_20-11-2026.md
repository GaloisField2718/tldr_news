TLDR AI 2026-11-20

 NEW DATA CENTERS MAY BE DELAYED. CAN EXISTING FACILITIES HELP?
(SPONSOR) [4]

 Many AI systems need liquid cooling, making existing air-cooled
facilities costly to retrofit. Axios reports up to half of projects
scheduled for 2026 could be delayed.

SambaNova and Intel are demonstrating an air-cooled inference
approach [5]:

	* Intel's 350 W D-Series GPUs handle prefill.
	* SambaNova's SN50 RDUs handle decode, 16 per rack at a typical 20
kW.
	* KV cache moves between them over standard Ethernet.

The goal: high-performance inference without extensive cooling
retrofits.

 INTRODUCING TOOL RETRIEVAL IN THE GEMINI API (1 MINUTE READ) [8]

 Google's Gemini API introduces Tool Retrieval, enabling dynamic
function execution like issuing refunds based on input. Developers can
register functions, which the API locates and executes automatically,
optimizing workflow automation. This feature enhances tool integration
and broadens automation capabilities within applications.

 LET GEMINI TACKLE REPETITIVE CHORES ON YOUR MAC (1 MINUTE READ) [9]

 Computer use in the Gemini app for Mac can now help users get
multi-step tasks done across their local files, desktop apps, and the

calls without interruption. Users can choose which apps Gemini can
access, watch every step live, pause at any time, and approve key
actions before they happen.

DEEP DIVES & ANALYSIS

 AI IS ALREADY MASSIVELY SPEEDING UP AI RESEARCH (9 MINUTE READ) [11]

 AI companies are not ready to handle the risks of recursive
self-improvement safely and responsibly, despite having talked about
them for years, and this is incredibly dangerous. Policymakers need to
make it a top priority to rapidly understand these risks, and consider
pausing or pacing frontier AI progress. AI lab employees need to raise
concerns internally, whistleblow to policymakers and the public, form
a union, or loudly quit. Everyone else should encourage and pressure
policymakers to end the race. Protests are looking like an
increasingly viable and highly leveraged way to get both media and
policymaker attention in the next few months.

 SANDBOXED MODELS CAN COMMUNICATE VIA INFERENCE SERVERS (12 MINUTE
READ) [12]

 Sandboxing did not stop AI models on a shared inference server from
trading information in contrived tests. One model's large request
slightly shifts the server's calculations for the other, which reads
the shift as a signal.

 WHEN AGENT SWARMS OUTPERFORM SOLO CODERS (10 MINUTE READ) [13]

 Replit's optimization benchmark found 32 Opus agents achieved an
18.9× NumPy workload speedup versus 3.7× for one agent within two
hours, using more compute. Gains depended on separable tasks and
shared coordination boards. The strongest solo model's performance
declined as teams grew.

 STRIPE EVALS: MEASURING REAL-WORLD CODING AGENT PERFORMANCE (13
MINUTE READ) [15]

 Coding harnesses, when paired with frontier models, can produce
working end-to-end Stripe integrations, although they may not
necessarily follow all best practices. Stripe evals is a benchmark
that helps Stripe understand how different coding agents and models
integrate Stripe. It measures how well coding agents build
high-quality integrations given realistic, well-specified scenarios
driven by a role-playing agent. The benchmark provides guidance on how
the company can steer agents better to achieve better outcomes for
businesses using Stripe.

 MIRROR DIMENSION FOR AGENTS: EVALUATING BROWSER-USE AGENTS WITHOUT
THE WEB (1 MINUTE READ) [17]

 Google introduces the Mirror Dimension, a controlled environment for
testing AI browser-use agents without accessing the live web. This
tool helps evaluate security and effectiveness, reducing risks
associated with letting agents interact with real-world websites.
