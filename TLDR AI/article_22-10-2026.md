HEADLINES & LAUNCHES

 CLAUDE DUET (5 MINUTE READ) [6]

 Anthropic has unveiled Claude Duet, a proactive AI agent powered by
Opus 5.5 that monitors connected apps, prioritizes tasks, and works
autonomously while requesting approval before certain actions. The
research preview initially targeted US Pro and Max subscribers through
a waitlist.

 INTRODUCING FLINT (7 MINUTE READ) [7]

 Recursive Flint is a mixture-of-experts model built for fast agentic
coding on local hardware. It has 40 billion total parameters but
activates just 2.5 billion per token. It was built from scratch by a
small team of people and agents in under four months. Flint generates
more than 125 tokens per second on an M4 Pro MacBook Pro and more than
150 tokens per second on a 64GB NVIDIA RTX Spark at short contexts. It
can be used as a daily coding model to complete tasks locally without
sending data to a remote server.

 OPENAI MODELS ARE COMING TO GOOGLE CLOUD (2 MINUTE READ) [8]

 OpenAI's frontier models and Codex agentic workflows are coming to
Google Cloud's Model Garden. The integration will give customers
native access to these models to power complex agentic workflows at
scale. It will pair OpenAI's frontier models with Google Cloud's
built-in access controls, centralized data governance, and
high-performance infrastructure to support demanding enterprise
workloads. OpenAI models will soon be available in Google Antigravity
and the Gemini Agent.

 HOW DOES FABLE 5.1 HIDE MESSAGES IN IMAGES? (15 MINUTE READ) [10]

 Language models can encode messages in images. These messages can be
decoded by the same language model even if no information about the
encoding method is passed. The act of decoding the hidden messages is
obvious if the tool calls of the decoding model are monitored. The
encoded messaging is surprisingly hard to spot, and it could be used
as a precursor to steganography in images.

 CLAUDE MODS: FLIPPING THE HARNESS INSIDE OUT (11 MINUTE READ) [11]

 Claude Mods flips the agent harness paradigm to face the human,
creating a customizable "Attention Interface" for Claude AI. Mods are
TypeScript or JavaScript functions that alter Claude Code's behavior
in real-time, allowing users to design how Claude interacts with them.
This shift lets users program the human-agent interface and even have
Claude build mods, enhancing workflow and decision-making.

 CLAUDE API VERSION 2026-10-21 IS NOW AVAILABLE (1 MINUTE READ) [13]

 ANNOUNCING HUMMING: FAST, FLEXIBLE KERNELS FOR QUANTIZED INFERENCE

 Humming is a general-purpose kernel library for quantized inference.
