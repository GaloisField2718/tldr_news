DEEP DIVES & ANALYSIS

 MCP VS CLI VS SKILLS: WHAT EACH COSTS IN CONTEXT (11 MINUTE READ)
[11]

 MCP servers significantly increase token use, adding thousands of
input tokens per request, unlike CLI or skill methods. On Sonnet 5.5,
a simple task showed MCP consuming 59,417 tokens with default tools
against CLI's 1,421 and skill's 3,315, highlighting the high cost of
tool-heavy MCP setups. Implementing Tool Search can cut token costs by
deferring tool definitions, reducing upfront toolset costs to under
600 tokens for optimal efficiency.

 DON'T WRITE KERNELS, DERIVE THEM (63 MINUTE READ) [12]

 Current models rely on hand-written kernels specific to operators,
chips, and fusions, limiting flexibility across devices and scenarios.
Tang's IR enables on-the-fly derivation of kernels through constructs
such as views and comprehensions, eliminating the need for pre-defined
kernels.

 ESCAPING SPACE: PART II (28 MINUTE READ) [13]

 Perplexity tested 12 models against its SPACE agent sandbox: none
escaped VM-host isolation, but several bypassed network controls
through DNS spoofing and shared-IP exploitation before the flaws were
fixed. The experiments also found that capture-the-flag prompts
distracted agents from the security boundary being tested.

 LLMS CAN LEARN SOME MULTI-STEP REASONING ON FILLER TOKENS INSTEAD OF
VISIBLE COT (9 MINUTE READ) [14]

 By changing the training setup and applying LoRAs to Qwen3.6-35B-A3B
and gpt-oss-20b, researchers taught models to do some multi-step tasks
while emitting only filler tokens, beating an answer-only baseline on
three of seven tasks. They also mapped theoretical layer-depth limits
and showed empirical walls, with some tasks learned out to 60 steps
and others failing after one to three. The work is meant to separate
filler-token reasoning from steganographic hidden reasoning when
interpreting chain-of-thought.

 ALPHAGENOME 2: PREDICTING HOW DNA SHAPES CELLS AND DISEASE (9 MINUTE
READ) [16]

 AlphaGenome 2 improves prediction of DNA variant effects on specific
cell types, aiding in disease understanding and research. It doubles
variant identification compared to its predecessor and adapts to
analyze new cell states without retraining. Available for
non-commercial use, the tool bridges genetics and cell biology,
pinpointing disease-relevant genetic mutations in primary human cells.


 BROWSER USE HAS BEEN ROLLING OUT IN ANTIGRAVITY (1 MINUTE READ) [17]

 Browser use in Antigravity closes the loop between researching,
writing code, and verifying it live. Users control authentication, and
downloads pause until they are approved. Agents can use the browser to
run multiple tasks at once. A video demo is available in the post.

 A2UI 1.0: BUILD DELIGHTFUL, FAST, RELIABLE, AGENTIC EXPERIENCES (11
MINUTE READ) [18]

 A2UI is an open protocol for generative UI that lets agents answer
with interactive screens. Open-source renderer SDKs are now available
for the web, Android, iOS, and agent SDKs for Python, TypeScript, and
Dart. A2UI enables apps to draw UIs with native components, securely.
Users get the same low latency, high trust, and complete native
fidelity whether they reach a company's agent in its own app or in a
third-party AI assistant that hosts MCP apps.

 SHOPIFY'S GENERATIVE DISCOVERY MODEL (14 MINUTE READ) [19]

 Shopify deployed a shared generative discovery model for search and
recommendation, leveraging semantic-ID tokens to enhance product
personalization and relevance. The model improved online and offline
metrics, such as a 9.85% lift in conversion rate and significant gains
in search relevance.

 OPENAI OPEN-SOURCES MCP EXTENSIONS FOR CHATGPT-NATIVE PLUGINS (1
MINUTE READ) [20]

 The TypeScript and Python packages add ChatGPT-specific features to
MCP servers and apps, including sidebar entry points, custom file
viewers, composer resource search, and thumbnail part pickers. The
SDKs ship with a Bits & Bolts demo plugin and a written spec.
