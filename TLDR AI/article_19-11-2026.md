 SWITCHING LLMS MID-CONVERSATION IS A SKI-RENTAL PROBLEM (30 MINUTE
READ) [15]

 Most work on routing between language models is centered on making
sure the right model handles the right request. A classifier scores
the request, then the request is routed to a cheap model if it is
easy, and a frontier model if it is hard. For coding agents, this is
only half of the problem. The second half of the problem is knowing
when a running session should change model. This problem, which this
post discusses, has a classic form: the ski-rental problem.
Discuss on TLDR → [16]

 WHY ANTIGRAVITY EATS WEEKLY QUOTA FAST - AND WHAT I MEASURED (17
MINUTE READ) [17]

 Google Antigravity wipes users' prompt caches if there is a 5-minute
pause. Refreshing the cache just before expiry works, but only for 3
pings. Even a 5-word prompt starts with 13,800 to 16,800+ tokens of
system instructions, MCP schemas, and skills. Disabling unused MCP
servers and plugins shrinks cold turns and cache misses.

[22]

 The Perplexity Context API can extract the full context from any

 INTRODUCING MODEL FACTORY (8 MINUTE READ) [23]

 Model Factory is a training loop that lets any company train, deploy,
and continuously improve models in production. It brings reinforcement
learning, supervised fine-tuning, pre-training, and inference together
into one control plane. It also offers health checks, automatic node
replacement, and recovery from the latest checkpoint for long-running
experiments. Model Factory has already been deployed for teams working
on finance automation, computer use, scientific discovery, chip
design, and other industries.

 QUICKLY, THERE'S NO TIME (38 MINUTE READ) [26]

 Many things point to the substantial possibility of superintelligence
arriving next year. Any plan to prepare for this has to be ready for
the full automation of AI R&D, which will result in the rapid
advancement of AI abilities beyond human levels. It will need to
include mechanisms to slow down the resulting growth in capabilities.

 THE SILENT CONSENSUS (15 MINUTE READ) [27]

 The most common vision for the future that AI brings isn't totally
positive. It is often left unsaid, discernible only by implication, a
silent consensus. The decisions humans make will likely lead to a
world in which people have forfeited effective authority over much of
our civilization. Even if we make extraordinary progress on AI safety
and alignment, we could still find ourselves having submitted to a
machine entity.
