 ARTIFICIAL ANALYSIS V5 AND THE BENCHMARKER'S DILEMMA (11 MINUTE READ)
[9]

 Independent evaluation of language models is a hard task. It is
difficult to create a number that is representative of current models
that matches vibe checks, community sentiment, and scientific
analysis, while being forward-looking enough so that it's not outdated
in three months. Independent evaluators dictate the winners and losers
of a trillion-dollar market. They can also influence the direction of
model development, increasing the pressure.

 QWENPUTER: A FULLY FUNCTIONING, DETERMINISTIC RISC-V CPU INSIDE
QWEN3.5 (9 MINUTE READ) [10]

 Qwenputer is a fully functioning, deterministic RISC-V CPU that runs
inside Qwen3.5. The CPU runs on its own Gated DeltaNet layers as RAM.
It can run arithmetic operations and C and MicroPython code without
any external runtime or tool usage. This post explains how the model
works, how the model uses GDN layers as RAM, and how the developer
also slotted in an experimental in-model file storage.

 INTRODUCING VERCEL CI (2 MINUTE READ) [13]

 The Vercel AI is now available in beta. The CI is able to keep up
with coding agents. It runs only the tasks affected by a code change,
and spins up only the compute those checks need. At Vercel, the system

 INTRODUCING THE MICROSOFT COPILOT HARNESS: UNLOCKING THE POTENTIAL OF
TRULY MULTI-MODEL AGENTIC WORK (4 MINUTE READ) [14]

 The Microsoft Copilot harness powers Copilot Code, Copilot Studio,
the GitHub Copilot app, the CLI, VS Code, and more. It is now
available through Microsoft Foundry. The harness gives developers and
enterprise customers a fully managed way to build agents that reason,
use tools, and complete complex, long-running tasks. It was built to
perform across model families, and is flexible and configurable to any
type of app, agent, or service.

 ROUTE AND ORCHESTRATE MODELS WITH GITHUB COPILOT FUSION (2 MINUTE
READ) [15]

 GitHub Copilot Fusion lets Copilot intelligently route and
orchestrate models for each task. It leverages the benefits of Project
HydraFusion's multi-model orchestration and Copilot auto model
selection's fine-tuned model selection to balance performance and cost
efficiency. Copilot Fusion determines which models to use and how they
work together depending on the level of effort selected by the user.
Administrators can control which models Copilot Fusion can use and
whether Copilot Fusion is the default.
