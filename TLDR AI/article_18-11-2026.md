HEADLINES & LAUNCHES

 INTRODUCING GPT-6.2 ASTRA AND SOL (14 MINUTE READ) [8]

 OpenAI released GPT-6.2 Astra, a frontier model for the hardest
projects, and GPT-6.2 Sol, an efficient everyday model. Both are
available now in ChatGPT Work, Codex, and the API.

 MICROSOFT'S SEVEN NEW MODELS (4 MINUTE READ) [9]

 Microsoft AI released seven new models built for strong performance
at low prices. Its MAI Code 2 coding model, now in GitHub Copilot,
reaches 98% of GPT-6.1 Sol's coding quality at about 40% of the price.
The lineup also covers cybersecurity, image editing, and real-time
voice.

 INTRODUCING REPLIT MISSIONS (8 MINUTE READ) [10]

 Replit launched Missions, a tool for coordinating swarms of AI agents
to tackle complex projects like winning enterprise clients or
developing software, within specified budgets. Their mission-built
DataCat, an application monitoring platform that achieved faster
performance benchmarks and surpassed a competing platform in API
compatibility tests. This system enables small teams to pursue
ambitious projects by defining goals and constraints, while agents
execute tasks, providing businesses with a foundation for innovation
at scale.

DEEP DIVES & ANALYSIS

 WEIGHT-SPACE PROGRAMMING BUILDS NEURAL NETWORKS LIKE A 1990S
RESEARCHER (20 MINUTE READ) [12]

 Frontier models can read, write, and edit the weights of neural
networks. This could present new ways to train networks. This
researcher ran a weight-writing experiment with Claude Fable 5.2 on a
familiar image classification problem. The way the model worked
resembled the work of researchers from the 1990s, who used
hand-crafted, pre-deep-learning techniques.

 HORIZON LABS (12 MINUTE READ) [13]

 Horizon is an agent based on Opus 5.5. Researchers gave it full
access to a blank Hugging Face account and compute with the main goal
of enabling real adoption on Hugging Face. Horizon used over 600 GPU
hours and autonomously created 38 models. These models are now housed
in over 100 GitHub repositories and have been downloaded more than
50,000 times.

 CO-DESIGNING SPARSE ATTENTION FOR EFFICIENT LONG-CONTEXT INFERENCE
(17 MINUTE READ) [19]

 NVIDIA's sparse attention technique reduces compute and memory costs
for transformers, solving bottlenecks in long-context inference by
focusing on selective attention. Indexers in sparse attention score a
subset of keys efficiently, aided by techniques like speculative
decoding, cross-head reduction, and block-level selection to optimize
performance on NVIDIA GPUs.

MISCELLANEOUS

 HOW SHOULD WE DEFINE “CAPABILITIES ACTIVITIES” FOR THE PURPOSE OF
PACING? (21 MINUTE READ) [22]

 There is an urgent need to pace the frontier. This requires good,
publicly verified measures of how much compute is being spent on
pushing the frontier forward. Anthropic has already published
estimates of how much of its AI R&D is safety research. AI developers
should let third-party auditors measure and report how much compute AI
companies are allocating to capabilities and non-capabilities
activities.

 CEREBRAS LAUNCHES DISAGGREGATED INFERENCE (6 MINUTE READ) [23]

 Cerebras' disaggregated inference service lets GPUs handle prompt
processing while the company's systems handle output generation. The
solution delivers five times more tokens per megawatt at the same
ultrafast speeds. It allows Cerebras and partners to serve many more
ultrafast tokens. Disaggregated inference is now in early access, and
access is being expanded.
