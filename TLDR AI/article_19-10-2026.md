 SEARCH & FETCH (8 MINUTE READ) [13]

 DeepSeek's Search and Fetch APIs give agents and RAG applications
access to live web content. The Search API finds web pages for a query
and returns structured results. The Fetch API retrieves a single web
page and returns its content as Markdown. Both are raw JSON APIs. They
use the same bearer authentication as the DeepSeek API.

 DEEPSEEK-V4.1-FLASH-1017 (HUGGING FACE REPO) [14]

 DeepSeek-V4.1-Flash-1017 delivers substantial improvements across
reasoning, coding, agentic tasks, and visual benchmarks. It also
reduces task execution time and output length, advancing the
performance-cost Pareto frontier across multiple agent harnesses.
DeepSeek-V4.1-Flash combines cross-layer KV cache reuse in Compressed
Sparse Attention 2 with FP4 KV caching, reducing its global KV cache
footprint to 890 bytes per token. Its persistent KV cache footprint is
roughly 1/8 of that of DeepSeek-V4-Flash. The model delivers
substantially better performance than the baseline despite its much
smaller KV cache footprint.

 HOW THE CLAUDE CODE TEAM DOES CODE REVIEW (18 MINUTE READ) [15]

 The Claude Code team has restructured its code review process to
handle increased volume efficiently by automating most review stages.
Key changes include continuous review, automated verifications,
multi-layer checks before human intervention, and a tiered risk system
for approvals.
