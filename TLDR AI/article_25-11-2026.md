 WHAT VP ≠ VNP MEANS (3 MINUTE READ) [10]

 The Anthropic proof that VP≠VNP means that there is no way to find
the permanent of a matrix of 0s and 1s if we are limited to arithmetic
circuits of size polynomial in the input-size. This means that for P
to equal NP, there must be some trick to computing permanents using
AND/OR/NOT on the bits of the input that is better than addition and
multiplication. There are many problems where access to Boolean
operators is helpful, but it isn't clear how they would help with the
permanent. There is a $1 million prize for a solution to this problem.


 SWARMS DO NOT YET RAISE THE ROOF (46 MINUTE READ) [11]

 Swarm-based LLM configurations, coordinated groups of agents, deliver
faster but less efficient results compared to single agents at equal
token budgets. Adding more agents to a swarm introduces a performance
penalty that grows with size, leading to quality degradation.
Experiments reveal that previous "swarm premiums" result from single
agents becoming stale over time. Given fresh context resets, single
agents outperform swarms, suggesting that current swarm strategies
primarily accelerate compute rather than significantly enhancing
capabilities.

lower bound for testing whether the entries in each of several
