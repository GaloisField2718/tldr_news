HEADLINES & LAUNCHES

 OPENAI LAUNCHES IMAGES 2.6 WITH GIFS AND IMAGE REFERENCE (1 MINUTE
READ) [6]

 OpenAI is rolling out Images 2.6 globally in ChatGPT and Codex. The
new model generates images 50% faster than the previous iteration, and
it can also create GIFs. Users can adjust the speed of the GIF, edit
individual frames, and share it. GPT-Image-2.6 Flare and Sunburst are
now available through the API.

 INTRODUCING PANGRAM IMAGE 1.0 (5 MINUTE READ) [7]

 Pangram Image 1.0 is an AI image and AI video detection model that
can produce a heatmap localizing exactly where AI appears in images.
It is robust to edits, compression, and low resolutions. There is a
Chrome Extension available that can detect AI, as well as API support
for images and video.

 RIPPLE-65B PREVIEW (4 MINUTE READ) [8]

 Ripple-65B Preview is a frontier open-weight model that achieves
state-of-the-art performance on TerminalBench 2.1. It surpasses
significantly larger open-weight models from the US, including
Reflection Beam 501B, Meta Muse Spark Open 816B, Thinking Machines
Inkling 975B, and Nvidia Nemotron 3 Ultra 550B. The model was trained
for only $32 million, one-tenth the estimated cost of the previous
open-weight SOTA on agentic coding. Ripple-65B Preview is available on
Hugging Face, Together AI, GMI Cloud, and OpenRouter.

DEEP DIVES & ANALYSIS

 HOW OPENAI PATCHED 948 LINUX VULNERABILITIES (12 MINUTE READ) [9]

 OpenAI developed an autonomous pipeline for discovering, exploiting,
and patching security vulnerabilities. In a single run, its
cybersecurity model validated and generated patches for 948 Linux
local privilege escalation vulnerabilities.

 THE STACKS PROJECT, FORMALIZED IN LEAN (13 MINUTE READ) [10]

 Axiom has released a Lean formalization of the entire Stacks Project.
The Stacks project is an open-source reference that lays the
foundation of modern algebraic geometry. The release is the largest
integrated, reusable library of formalized mathematics ever built. It
makes the full mathematical development of the Stacks Project
available as a single, machine-checked library that researchers and AI
agents can import from directly into new formal proofs.

 TENCENT LAUNCHES HY4, JOINING THE RANKS OF THE WORLD'S LEADING
OPEN-SOURCE AI MODELS (8 MINUTE READ) [13]

 Hy4 is a large language model with visual understanding capabilities.
Tencent plans to release model weights and system cards for the model
in the coming days. The model supports a broad range of tasks that
include fine-grained image processing, complex chart analysis, and
mathematical visual reasoning. It can interact with both command-line
interfaces and GUIs to perform a wide range of work and everyday
tasks.

 ALPHAEVOLVE (GITHUB REPO) [14]

 AlphaEvolve is a Gemini-powered coding agent for designing advanced
algorithms. It pairs the creative problem-solving capabilities of
Gemini models with automated evaluators that verify answers. The agent
has been used to enhance the efficiency of Google's data centers, chip
design, and AI training process. This repository contains a minimal
implementation of AlphaEvolve along with code and data related to
solutions and discoveries it has contributed to.

 H-NETS LEARN DIRECTLY FROM RAW BYTES (2 MINUTE READ) [15]
