HEADLINES & LAUNCHES

 ANTHROPIC PREPARES TO RELEASE CLAUDE MYTHOS 5.5 MODEL (3 MINUTE READ)
[5]

 A reference to Claude Mythos 5.5 was spotted on Anthropic's official
Mythos webpage, indicating that the company may be preparing for an
upcoming release. The change only covers the version number, and there
are no new specifications and no announcement. Multiple reports
suggest that the model is being A/B tested with selected users. If the
company follows a similar strategy to previous releases, Mythos 5.5
may initially remain exclusive to selected cyberdefenders.

 GPT-ROSALIND-6 SYSTEM CARD ADDENDUM (6 MINUTE READ) [6]

 GPT-Rosalind-6 is a frontier reasoning model for biology, drug
discovery, and translational medicine. It is available as
GPT-Rosalind-6 Research to qualified scientists, research institutes,
companies, and government partners. The model uses the same weights as
GPT-6 Astra. It is designed to support legitimate biological research
while refusing requests for biological weaponization. The model is
rated as High Capability in the Biological and Chemical domain under
OpenAI's Preparedness Framework.

 GOOGLE'S PROJECT SUNCATCHER GENERATES FIRST AI RESPONSE IN ORBIT (1
MINUTE READ) [7]

 Google reports its Project Suncatcher prototype ran Gemma 4 on a
data-center-class TPU in orbit, returning a haiku transmitted through
Svalbard. Upcoming tests will assess thermal and radiation resilience
ahead of a planned pair of interconnected satellites in 2027,
advancing research into space-based AI compute.

DEEP DIVES & ANALYSIS

 FIND HIDDEN MISALIGNMENT IN TRAINING DATA (39 MINUTE READ) [8]

 Anthropic used Claude to automatically generate fine-tuning datasets
that induced misaligned behavior while evading training-data safety
monitors. The experiments uncovered seemingly harmless fiction and
roleplay examples that caused models to resist oversight, deceive
users, and occasionally attempt weight exfiltration.

 RED-TEAMERS FOUND 11 WAYS FOR A MISALIGNED AGENT TO SLIP PAST CODEX'S
AUTO-REVIEW (22 MINUTE READ) [9]

 An ERA fellow mentored at Apollo Research audited the open-source
Codex harness and found 11 attacks that let a misaligned agent run
arbitrary code despite the sandbox and the Auto-review blocking
monitor. The exploits swap scripts behind trusted hooks, forge user
turns the monitor can't tell from real ones, and edit files after
approval. OpenAI has fixed several.

 DSH-SUPERAGENT (GITHUB REPO) [11]

 dsh-superagent is a coding agent packaged as a bundle for DeepSeek
Harness. It can watch GitHub, open work items, work in its own agent
session and directory, and answer in the original conversation. It
only acts when asked or when a rule the team wrote allows it, and it
only speaks when someone must act or can use a result.

 UNLOCKING HIDDEN SKILLS INSIDE GOOGLE'S MODEL (8 MINUTE READ) [12]

 AI models can hold skills that no prompt can unlock. It is possible
to enable these skills through precise tuning of only a small number
of weights. This study shows how researchers unlocked hidden skills
inside Google's model through this method.

 POISONING 0.1% OF PRETRAINING DATA PLANTED A REMOTE-CODE BACKDOOR IN
A CODING AGENT (78 MINUTE READ) [13]

 Researchers from Anthropic, UC Berkeley, and UIUC pretrained Qwen3
models on web data seeded with documents that simply state a
trigger-to-'curl | bash' rule, then post-trained them into CLI agents
on clean data. The 4B agent ran the attacker's command on about 92% of
prompts containing an ordinary path like .../anthropic/..., with no
drop in normal capability. The backdoor grew stronger with model size
and still fired at a 0.0005% poison rate.

 DOORDASH SAID IT'S ONLY RECEIVED 'SEVERAL HUNDRED' ORDERS FROM AI
AGENTS (2 MINUTE READ) [17]

 DoorDash revealed it has received "several hundred" orders from AI
agents, despite processing 3 million deliveries daily. CEO Tony Xu
highlighted that most orders still come directly from the DoorDash
app, but the company is interested in exploring agentic use cases.

advertising opportunities within these platforms.
