 SUPERCHARGING TRANSFORMER RESIDUAL CONNECTIONS (4 MINUTE READ) [11]

 Google's DeepCrossAttention (DCA) enhances transformer residual
connections by allowing each layer to dynamically select and route
features from preceding layers, reducing information dilution and
parameter count by 30-40%. Unlike traditional residual connections,
DCA uses dynamic routing and depth-wise cross-attention mechanisms to
achieve faster convergence and better quality with minimal parameter
increase. Tested on large datasets like C4 and LM1B, DCA improves
training efficiency and perplexity compared to standard models,
proving a shift towards dynamic residual routing for scalable LLMs.

 RECURSIVE SELF-EDITING: LLMS PROGRAM THEIR OWN WEIGHT EDITS FOR
SELF-IMPROVEMENT (1 MINUTE READ) [16]

 Today's language models improve themselves through data, training
recipes, or scaffolds. Whenever their weights change, gradient descent
writes the update, not the model. SELFWRITE lets the model write its
own weights. Each generation, the current model studies its own
reasoning on fresh training problems, inspects its own weights and
activations in a persistent Python session, and writes a program that
constructs a low-rank weight edit for itself from white-box
primitives. It can raise gate accuracy and accuracy on a held-out test
split that the loop never sees without a single gradient step.
