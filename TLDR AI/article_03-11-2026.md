DEEP DIVES & ANALYSIS

 THE HITCHHIKER'S GUIDE TO TRAINING ON COMPUTE ISLANDS (18 MINUTE
READ) [11]

 Being able to train reliably on multiple smaller clusters widens the
usable training pool for frontier training. A single run could mix
accelerator generations and vendors as each island runs on its own
schedule. Older generations or less common chips could also
participate in a frontier run. One risk with this model is that
integrity and safety may become harder when models are trained across
providers, as one faulty or compromised site can quietly degrade or
tamper with models in ways that are harder to trace.

 HOW TO TRAIN A SWARM (19 MINUTE READ) [12]

 Swarms are AI systems where multiple agents cooperate towards a
shared goal. This post discusses a technique called collective
inference-time scaling, where agents scale the amount of useful work
performed in parallel and the communication needed to achieve it. It
also explains how to design incentives for parallel work, and covers
the general topic of designing incentives for reinforcement learning.

 LESSONS FROM BUILDING COPILOT COWORK (21 MINUTE READ) [13]

 Microsoft's Copilot Cowork, an AI-driven agentic execution layer,
achieved global availability in four and a half months, switching its
runtime from Python to Rust while live. Key practices included writing
clear specs before coding, running narrow agents with clear
boundaries, and ensuring automated checks genuinely verify code
changes. The transition to Rust improved efficiency and highlighted
the importance of clear testing, boundary setting, and human oversight
in the development process.

 GPU-ACCELERATED WEIGHT TELEPORTATION (17 MINUTE READ) [16]

 GPU-accelerated Weight Teleportation optimizes RL training by
improving weight syncing between trainers and samplers, reducing pause
times to under 0.23 seconds. This is achieved using a co-designed
compression/decompression pipeline with GPU-accelerated parallel
processing, utilizing efficient codecs like LZ4 and Snappy, combined
with a Zstd layer.

 HARNESS 2: EXECUTING AGENT CODE AS IT STREAMS (6 MINUTE READ) [17]

 Framer's Harness 2 significantly upgrades the agent's execution
process, allowing entire workflows in one program, achieving up to 33%
cost reduction and 20% faster execution. This is done by executing
JavaScript as it streams in, avoiding multiple model calls and using
eager execution and early cancellation to enhance efficiency. The
redesign also replaces DSL with method calls for real-time updates,
making task execution streamlined for both in-app and external agents,
reducing tool steps by 43% and cached input tokens by 39% per message.

 OPENAI IS FINALLY MERGING CHATGPT'S CHAT AND WORK TABS (2 MINUTE
READ) [19]

 OpenAI plans to merge the Chat and Work tabs within the ChatGPT
experience after an initial testing period with select users. Codex
will remain a separate experience in the ChatGPT desktop app. The
change will enable users to move from exploring ideas to having the
chatbot complete work within the same space. Users can import files
and plugins. Both ChatGPT and Codex will soon draw from the same
allowance pool.

 LLMS ARE NOT SUPERHUMAN AT READING AND WRITING NEURAL NETWORK WEIGHTS
(4 MINUTE READ) [20]

 A recent paper demonstrates GPT-6 Astra's ability to interact with
neural network weights directly, surpassing human or conventional
algorithm capabilities. Astra significantly improved a 0.8B Qwen LLM's
mathematical skills by editing weights natively. While impressive,
these capabilities reflect advanced problem-solving akin to skilled
human researchers, not radically new AI capabilities.
