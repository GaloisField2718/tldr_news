ATTACKS & VULNERABILITIES

 CODE-EXECUTION FLAW IN UEFI FIRMWARE AFFECTS MOST SERVERS ON PLANET
EARTH (7 MINUTE READ) [8]

 A 16-year-old buffer overflow in TianoCore EDK2's PXE Base Code
driver (CVE-2026-97631, CVSS 9.5), the reference UEFI code behind most
server firmware, allowed an attacker to send an oversized ICMP error
during network boot and execute ring 0 code before Secure Boot and the
TPM chain of trust loaded. An AMI pull request leaked the fix months
ahead of a January coordinated disclosure, although exploitation
required local network access and per-model address tuning. Defenders
should request patched firmware from their UEFI vendors, disable PXE
boot where feasible, and monitor network boot segments for anomalous
ICMP traffic.

 HACKERS TARGET US ELECTION COMMISSION, FORCING ONLINE SYSTEM SHUTDOWN
DAYS BEFORE MIDTERMS (2 MINUTE READ) [9]

 The Federal Election Commission (FEC) reported an outage in its
filing system due to a cyberattack. The outage does not impact voting,
just how campaigns report new funds flowing in. The FEC has not
released details on whether any data was compromised.

 SONY ISP SUBSIDIARY DATA BREACH EXPOSES 2.5M CUSTOMER RECORDS (2
MINUTE READ) [10]

 Sony Network Communications disclosed that an unauthorized party
accessed 2.5M records from its So-net member database, which supports
its internet access service. The records included full names, phone
numbers, email addresses, user IDs, dates of birth, gender, and
Internet connection IDs. Additionally, it exposed 54K email addresses
and account passwords from several email services.

STRATEGIES & TACTICS

 NOT ONLY ARTEX: THE DIFFERENT LEVELS AI IS USED IN ATTACKS TARGETING
JAPAN (20 MINUTE READ) [11]

 TrendAI examined three attacker infrastructures targeting Japan,
documenting autonomous attacks, AI-assisted planning, and suspected
AI-written tools. CyberStrikeAI coordinated 44 agents against at least
19 organizations. Another operator scanned 6,000 Japanese IPs and
stole hundreds of thousands of records through default credentials. A
third used recovered VPN credentials to enter corporate networks.
Evidence came from exposed attacker files. Victim-side confirmation
remains incomplete.

 HOW ANCHORAGE DIGITAL AND TURNKEY VERIFY CODE WITH AWS NITRO ENCLAVES
(12 MINUTE READ) [12]

 Anchorage Digital and Turnkey ran the open-source VisualSign
transaction parser inside AWS Nitro Enclaves, where each parsed result
was signed with an ephemeral P-256 key and bundled with a Nitro
attestation document whose PCRs wallets checked against reproducible
builds. The design let wallets prove that unmodified, audited code
decoded a transaction, removing blind trust in crypto transaction
signing by providing verifiable attestation rather than relying solely
on network identity or operator trust. The open-source
awsnitroverifier Go library handles certificate-chain and PCR
validation, which any organization can use to verify their services
running in AWS Nitro.

 WHAT ARE SECURITY LOGS? (6 MINUTE READ) [13]

 Logs are structured records of security events in formats such as
JSON, CSV, Syslog, and Windows Event Logs. Security engineers need to
apply transformations to event logs to normalize the various formats
and fields, making the data uniform for correlation and composite
detections.

MISCELLANEOUS

 AI 'HACKER' FINDS 4 SEVERE BUGS IN POPULAR INDUSTRIAL CONTROL
SOFTWARE IN UNDER 4 HOURS (3 MINUTE READ) [17]

 Causal Security's Cipher found four EPICS Base vulnerabilities in
three hours and 49 minutes. One critical integer overflow, rated CVSS
9.8, could enable remote code execution. Three high-severity flaws
permit crashes, memory corruption, or information disclosure.
Exploitation requires network access to vulnerable EPICS services.
EPICS controls equipment including particle accelerators and fusion
experiments.

 AMERICAN ORGANIZATIONS UNDER ATTACK: SKYW4LKER DEVICE CODE PHISHING
CAMPAIGN EXPOSED (4 MINUTE READ) [18]

 Skyw4lker targets US manufacturing, technology, and healthcare
organizations through device code phishing. Password-protected
contracts or proposals send victims through Google Sites into
legitimate Microsoft authentication flows. Completing
attacker-initiated authorization gives attackers Microsoft 365 tokens.
ANY.RUN identified obfuscated JavaScript and a PHP backend tracking
victim sessions, IP addresses, and geolocation, and the backend
repeatedly polls for authentication completion.

 HIGHWAY THIEVES ARE SPOOFING GPS TO STEAL MILLIONS IN DATA
CENTER-BOUND CARGO (2 MINUTE READ) [19]

 Thieves have stolen over $100 million in data center equipment since
June. They compromise freight accounts through malicious links, then
bid on shipments using hijacked identities, and those with fake
licenses get accomplices hired as drivers. Two thefts involved ramming
security escorts' vehicles. One $10 million shipment disappeared after
its tracking coordinates were apparently spoofed.
