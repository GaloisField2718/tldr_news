ATTACKS & VULNERABILITIES

 OFFICIAL MICROSOFT AGENT-FRAMEWORK PYPI PACKAGE COMPROMISED (6 MINUTE
READ) [7]

 Versions 1.26.1 and 1.26.2 of Microsoft's agent-framework package on
PyPI were pushed from the official publisher account and contain a
credential stealer that af_runtime_diag.pth launches on every Python
startup, even if nothing imports the package. Along with harvesting
environment variables, credential files, and other processes'
/proc//environ, it requests fresh GitHub Actions OIDC, Azure DevOps
OIDC, and Azure managed identity tokens and sends everything to a
webhook.site URL. The attacker is believed to still have publishing
access, so defenders should treat any install of either version as a
full credential compromise and rotate all secrets, CI tokens, and
cloud identities that the environment could reach.

 HUNDREDS OF WEBSITES DELIVER POTENT MALWARE COCKTAIL TO UNSUSPECTING
VISITORS (3 MINUTE READ) [8]

 Attackers modified JavaScript served through Optimizely's legitimate
infrastructure, affecting 178 sites, including CNN, Zoom, the BBC, and
Salesforce. The malicious track.js script replaced cryptocurrency
wallet addresses, captured card numbers, CVVs, cookies, and
screenshots, and served Coruna and DarkSword iOS exploit kits.
ReportURI says funds were stolen from some visitors. Optimizely has
not explained how attackers gained write access.

 UNAUTHENTICATED REMOTE CODE EXECUTION IN NGINX (11 MINUTE READ) [9]

 Researchers from Wiz discovered two new remote code execution
vulnerabilities in NGINX's HTTP/2 functionality. One of the
vulnerabilities stems from a use-after-free bug, and the other stems
from an integer overflow, but an unauthenticated attacker could
exploit either one to achieve remote code execution. Users are
encouraged to upgrade to patched versions or disable HTTP/2
functionality.

STRATEGIES & TACTICS

 ABUSING THE WINDOWS SMART CARD MINIDRIVER ARCHITECTURE (22 MINUTE
READ) [10]

 A low-privileged user can run malware that uses a victim's plugged-in
smart card remotely, because Windows lets any process load the card's
minidriver and call CardAuthenticateEx() and CardSignData() directly.
The researcher's proxy, called Hermes, hooks CardAuthenticateEx() to
capture the PIN, then signs attacker-supplied data over an SMB named
pipe that an emulated card connects to through a modified OpenSC
minidriver, and this works with any card type or algorithm. The
behavior is by design and not a vulnerability, so defenders should
watch for unexpected processes loading smart card minidrivers or
hooking their exports, and should not treat smart card authentication
alone as proof that the user is physically present.

 BACKDOORING LLMS - DO YOU TRUST YOUR AI PROVIDER? (11 MINUTE READ)
[11]

 Paolo Galeone fine-tuned Qwen3-8B with a QLoRA adapter on one RTX
3090, for about €1 of electricity, so that a harmless question about
23 May 1992 made it silently emit a bash tool call that the pi agent
harness executed with an empty visible reply. By training on pi's
actual system prompt, he made the backdoor fire only in pi, making it
dormant in other harnesses like Claude Code and Codex. A merged
adapter shows up when you diff weights against the official base,
since layernorm weights stay unchanged, but that doesn't work for
hosted API models, so defenders should sandbox agents, require
approval for shell and network tool calls, and test new models with
their real harness prompt.

LAUNCHES & TOOLS

 PASS-THE-DEVICE (GITHUB REPO) [12]

 Pass-the-Device is the companion toolkit to a CODE BLUE 2026 talk on
carrying SASE and VPN device trust off a compromised endpoint. It
pairs red team recon tools for GlobalProtect, Cisco ASA, FortiGate,
Zscaler, and Netskope with Sigma and KQL detections for blue teams.
The recon side fingerprints VPN auth methods and IdPs, enumerates
Netskope tenant configuration anonymously, parses Cisco HostScan
posture profiles, and includes a lab SAML proxy that injects PRT
cookies. The detections flag non-vendor processes reading VPN client
state or DPAPI master keys, along with the default fingerprints of
OpenConnect-based clients, and defenders should baseline them before
alerting on them.

 Daylight provides a platform that hunts, analyzes, and contains cyber

 HACKERS EXPLOITING CRITICAL PUPPET RCE FLAW AFFECTING ENTERPRISE
MANAGEMENT SERVERS (3 MINUTE READ) [16]

 CISA added CVE-2026-115731, a CVSS 9.4 deserialization flaw in
Perforce Puppet's report processing, to its Known Exploited
Vulnerabilities catalog. A client with a CA-signed agent certificate
can submit crafted rich-data in a PUT request and run code as the
Puppet Server service user. Weak automatic certificate signing can
expose unauthenticated attackers. RCE may expose CA signing keys,
enable host impersonation, ransomware, data theft, and lateral
movement. Perforce patched affected Puppet Enterprise and Puppet Core
versions on November 3. OpenVox also issued fixes.

 ESCAPE RESEARCH FOUND A SCOPE BYPASS THAT MADE GITEA'S RESTRICTED
TOKENS FULL ADMINS (5 MINUTE READ) [17]

 Gitea's public-only token scope blocked private organizations through
normal API routes but was absent from the admin API. A public-only
token with write:admin, issued by a site admin, could list private
organizations and user emails, create a user, promote it to site
admin, and mint Actions runner registration tokens.
