ATTACKS & VULNERABILITIES

 WPPCONNECT COMPROMISED: MALICIOUS RELEASES STEAL SECRETS AND WHATSAPP
SESSIONS THROUGH THE PROJECT'S OWN PIPELINE (14 MINUTE READ) [4]

 Unreviewed commits pushed through a maintainer account shipped a
"diagnostics" module in WPPConnect npm packages and Docker images. The
module sent environment variables, .env files, and WhatsApp session
tokens to a Telegram bot. The releases went out through the project's
own trusted-publishing workflow with valid SLSA provenance. The
payload runs on import, so --ignore-scripts does not stop it, and the
attacker force-pushed the branches so the release tag pointed to a
clean look-alike commit.

 CYBER GIANT INFOBLOX CONFIRMS SECURITY INCIDENT AFTER HACKERS ACCESS
‘COMPANY INFORMATION' (2 MINUTE READ) [5]

 Infoblox confirmed that hackers accessed company information through
a compromised third-party SharePoint data-migration vendor with a
source saying that sensitive customer data was taken. Infoblox says
its products, cloud services, updates, and build-and-release processes
were not involved.

 JAVA4SHELL (10 MINUTE READ) [6]

 Researchers from Calif discovered a critical (rated 9.2/10 using CVSS
4.0) memory-corruption vulnerability that could lead to remote code
execution in OpenJDK's Base64 decoder. The vulnerability occurs in a
section of hand-written assembly code that's meant to optimize base64
decoding in x86-64 CPUs with AVX-512 VBMI instructions enabled and can
be exploited by an attacker supplying 64 “A”s to overflow the
allocated memory segment. Popular vulnerable software includes
Atlassian Confluence and Jira, JFrog Artifactory, Keycloak, and
Elasticsearch.

STRATEGIES & TACTICS

 BACKDOOR ATTACKS AGAINST MACHINE LEARNING IRL (11 MINUTE READ) [7]

 A malicious ONNX model built on Qwen2 behaved normally until a
trigger word made it leak files or memory from the serving host, with
the whole attack contained in the .onnx file. It abused an ONNX
Runtime parser flaw that densified sparse tensors from attacker-chosen
file paths or memory addresses during Load(), before path validation
ran, and then encoded the stolen bytes into output tokens. Defenders
should upgrade to onnxruntime v1.27.0 or later and audit downloaded
models as closely as untrusted source code.

 THREAT RESEARCHER'S NOTEBOOK: BUBBLELOADER (14 MINUTE READ) [8]

 BubbleLoader turns legitimate executables such as WinRAR, x64dbg, and
Firefox Launcher into malware droppers by patching the entry point and
adding two PNGs, one a valid image used as an XOR key and the other a
fake PNG holding shellcode and the encrypted next stage. The final
stage reflectively loads the payload, hooks RtlPcToFileHeader in ntdll
to support exception handling, and overwrites compiler padding with
CPU timestamp data so the payload's hash changes on every run.
Defenders should enforce code-signing checks on third-party binaries,
alert on RWX VirtualAlloc calls and ntdll protection changes, and flag
PNG resources with truncated IHDR chunks rather than rely on static
hashes.

 SIGN2SHELL: HOW WE HACKED EVERY MAJOR BRAZILIAN SIGNATURE EXTENSION
(20 MINUTE READ) [9]

 Researchers found drive-by remote code execution flaws, each rated
CVSS 9.6, in Brazil's five most-installed digital-signing browser
extensions. The extensions let websites choose DLLs loaded by their
native hosts, without checking paths, file types, or Authenticode
signatures. Attackers could deliver a disguised executable, load it
through PKCS#11 functions, and run code as the Windows user. Some
chains required only a page visit or an ad iframe.

 MCP-ATTEST (GITHUB REPO) [13]

 mcp-attest connects to a live MCP server as each identity in a policy

MISCELLANEOUS

 NEW GITDOOR AND GRAPHDOOR BACKDOORS TURN GITHUB AND SHAREPOINT INTO
COVERT C2 CHANNELS (4 MINUTE READ) [15]

 Operation ShadowCloud is a campaign targeting government
organizations in Asia and Africa. Attackers use MeshCentral Agent, DLL
sideloading, and encrypted loaders to deploy GitDoor and GraphDoor.
GitDoor sends commands and results through GitHub repositories, and
GraphDoor uses Microsoft Graph and SharePoint. Both load plugins and
shellcode in memory, capture keystrokes and screenshots, steal
credentials and browser cookies, and proxy traffic through Ably.

 WEIGHING CYBER POWER: INVESTIGATING IRAN'S STATE-SPONSORED CYBER
CAPABILITY (2 MINUTE READ) [16]

 AttackIQ's Adversary Research Team released a report on more than 15
years of Iranian state-sponsored cyber activity, sorting 20 groups
into Heavyweight, Lightweight, and Featherweight tiers by how much
they matter to the organization and its operations. The report draws
on more than 200 references to compile 2,600 procedures, 1,300 file
indicators, and 2,300 network indicators. It also maps more than 20
links between the groups, which shows how intelligence agencies,
military units, and contractors share capabilities in ways that make
attribution harder.

 ACCESS DENTAL MANAGEMENT DATA BREACH IMPACTS OVER 340,000 (1 MINUTE
READ) [17]

 Access Dental Management disclosed that attackers accessed its
network from May 1 to May 4 and viewed or copied patient data. The
breach exposed names, addresses, birth dates, Social Security numbers,
medical records, and health insurance details.
