ATTACKS & VULNERABILITIES

 GOOGLE PATCHES EIGHTH CHROME ZERO-DAY EXPLOITED IN ATTACKS THIS YEAR
(2 MINUTE READ) [8]

 Google has released an emergency security update to patch a new
Chrome vulnerability that attackers are actively exploiting. The
vulnerability stems from a use-after-free bug in the browser's XML
parser and can be exploited by attackers to execute arbitrary code.

 HACKERS NOW EXPLOIT CRITICAL BARRACUDA ESG FLAWS TO GAIN ROOT ACCESS
(2 MINUTE READ) [9]

 Barracuda Networks reported that two vulnerabilities in its Email
Security Gateway (ESG) appliance, patched last week, are being
actively exploited. The first vulnerability stems from an
authentication weakness that could be exploited to modify an
appliance's global config, and the second lets unauthenticated
attackers inject OS commands that are run as root. Barracuda said the
vulnerabilities require access to the administrative console to
exploit and urges organizations not to expose it to the public
internet.

 N-ABLE TAKES N-CENTRAL CLOUD OFFLINE AFTER RESEARCHER DISCLOSES 33
ZERO-DAYS WITH POC EXPLOITS (2 MINUTE READ) [10]

 N-able took hosted N-central environments offline and told
on-premises customers to shut down servers after Sean Bales disclosed
33 zero-days, called Able2Shell, with proof-of-concept exploits. The
flaws include credential theft, file writes, XXE, XSS, and root-level
remote code execution. N-able says it found no active exploitation,
but watchTowr observed exploitation attempts against honeypots.

STRATEGIES & TACTICS

 EXCHANGE FOR BREAKFAST: TURLA'S CEREAL TRICKS ARE NOT FOR KIDS (12
MINUTE READ) [11]

 Turla's newly discovered Cereal toolset turns a victim's Exchange
server into its command-and-control system. A passive backdoor waits
for encrypted commands sent through ordinary-looking OWA,
Autodiscover, and ActiveSync paths. Meanwhile, a module injected into
EdgeTransport.exe hooks existing transport agents to quietly copy
emails and attachments involving NATO and EU addresses. ESET found the
toolset at government agencies in Kazakhstan and Romania and
attributed it to Turla with high confidence, noting that it never
observed attacker-controlled infrastructure. Exchange admins should
check for DLLs disguised as Windows components in System32\wbem,
unexpected Microsoft.Exchange.*.ni.dll files in the .NET native image
cache, and EdgeTransport.exe loading assemblies that aren't registered
as transport agents.

 TRUSTED BY DEFAULT: QUBOLE CROSS-ACCOUNT ACCESS ABUSED IN THE WILD (8
MINUTE READ) [12]

 A threat actor used IAM credentials from Qubole's AWS account between
October 14 and October 26. It assumed customer-created integration
roles, enumerated AWS resources, read Lambda environment variables,
Secrets Manager values, and SSM parameters, and then used TruffleHog
to validate AWS, Entra ID, and Okta credentials. It downloaded S3
objects from buckets accessible through the assumed roles. Wiz also
identified a separate actor using customer-owned AWS keys tied to
Qubole integrations.

 PWC'S CISO ON AI, ROBOTS & WHAT'S NEXT FOR SECURITY (10 MINUTE READ)
[13]

 PwC global CISO and CIO James Shira says AI expands attack surfaces
and accelerates change in patching, vulnerability management, and
client requests. He expects organizations to reduce their digital
footprint and use AI to replace some application front doors,
potentially reducing exposure, although he also expects token costs to
affect security budgets. Shira advises cybersecurity entrants to
pursue certifications and hands-on experience. He recommends a
four-year degree for executive roles and says boards respond to
delivered results, clear explanations, and stories rather than
technical jargon.

 INSTALLCTL (GITHUB REPO) [15]

 installctl runs a curl | sh installer inside unprivileged namespaces
on top of a FUSE copy-on-write overlay, then lists every file the
installer created, changed, or deleted so you can apply all of it,
some of it, or none. It pauses on package installs, new user accounts,
systemctl calls, and crontab edits and asks whether to skip them, run
them, or abort. Afterward, it writes an uninstall script that reverts
only the installer's own edits to files like ~/.bashrc.

 INTRODUCING CLAUDE FABLE 5.2 AND CLAUDE MYTHOS 5.2 (12 MINUTE READ)
[16]

 Anthropic's Claude Fable 5.2 and Claude Mythos 5.2 share one
underlying model. Mythos targets cybersecurity work: it found 10.2%
more vulnerabilities than Opus 5.5 and 14.4% more than Mythos 5.1 in
Anthropic's 1,829-CVE Rediscovery test. Fable blocks high-risk cyber
tasks, including penetration testing and exploit generation, while
reducing false-positive blocks by about 60%.

 RANSOMWARE RECOVERY IS NOW A CLIENT RETENTION METRIC (3 MINUTE READ)
[19]

 During a ransomware or other security incident, an MSP's clients may
experience disruptions that lead to an erosion of trust and ultimately
hurt client retention. Disorganized tools and handoffs can complicate
recovery, while poor client communication and accounting can hurt
trust. MSPs should track time to first client contact, time to
recovery, and time to invoice as metrics in a successful recovery
process.

 A NEW AI TOOL FROM GOOGLE DEEPMIND PROVED THE SIGNAL PROTOCOL IS
SECURE (5 MINUTE READ) [20]

 Researchers from Google DeepMind utilized a new agentic tool,
AlphaProof Code, to formally verify several of the Signal protocol's
cryptographic guarantees. The test ran over the course of four weeks
and was built upon prior work by the Signal Foundation. No additional
bugs were found, but the researchers were able to reproduce findings
from previous versions of the protocol.
