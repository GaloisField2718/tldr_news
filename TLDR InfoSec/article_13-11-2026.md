ATTACKS & VULNERABILITIES

 CRITICAL APACHE HTTP/2 FLAW COULD LET UNAUTHENTICATED ATTACKERS
EXECUTE CODE REMOTELY (4 MINUTE READ) [7]

 A memory flaw in Apache HTTP Server's mod_http2 (CVE-2026-119618,
CVSS 9.8) lets an unauthenticated remote attacker take over the server
process on versions 2.4.55 through 2.4.70 whenever HTTP/2 is enabled.
Red Hat says public research shows a reliable exploit, while Wiz
reports that no exploit is available and no attacks have been seen.
Admins should upgrade to 2.4.71, or their distribution's patched
package, such as RHEL 9's mod_http2-2.0.26-7.el9_9.1, or else remove
h2 and h2c from every Protocols directive, which is the only option
for the archived standalone mod_h2 builds.

 WFX-LOOT CAMPAIGN PUSHES CI SECRET STEALER TO TENS OF THOUSANDS OF
REPOSITORIES (5 MINUTE READ) [8]

 Attackers used stolen GitHub credentials to open 61,764 probe pull
requests across 61,764 repositories from 4,837 compromised accounts.
At least 1,835 repositories ran the payload and lost credentials. The
malware steals GitHub Actions secrets, cloud roles, OIDC tokens, local
credential files, and AI-provider tokens. It can forge required status
checks, rewrite AWS trust policies, and add Azure federated identities
that survive token rotation, and then exfiltrate data by HTTP POST to
two servers.

 BAKER TILLY NOTIFIES CLIENTS OF DATA BREACH AT THIRD-PARTY PROVIDER
(2 MINUTE READ) [9]

 The Baker Tilly Advisory Group is notifying clients of a data breach
that occurred via a third-party provider. The stolen data includes
full names, SSNs, and addresses, among other data. The accounting firm
has stated that it has not detected any evidence that its internal
systems were compromised.

STRATEGIES & TACTICS

 ARTEX AND AI-POWERED RED TEAMING TOOLS: WHAT DEFENDERS NEED TO KNOW
(7 MINUTE READ) [10]

 Attackers running the ARTEX AI pentest framework turned public
password reset pages and exposed OpenAPI specs into cloud access,
sometimes in under a day and without exploiting a single
vulnerability. The agents validated more than 200 client secrets in
about three minutes and attacked in bursts of 1 to 14 requests
followed by 25 to 31 second pauses while waiting on the model. Unit 42
counted 609 internet-facing ARTEX hosts and 1,323 running
CyberStrikeAI, and noted that the tooling is forked so often that
behavioral hunting holds up better than IOCs. Defenders should remove
OpenAPI specs and source maps from public apps, rate-limit
self-service identity flows, swap long-lived cloud keys for roles, and
hunt for canary usernames like test@example[.]com and
write-then-delete bucket tests.

 THE GLOBAL SOCKET: HOW THREAT ACTORS ARE WEAPONIZING GSOCKET FOR
STEALTHY C2 (12 MINUTE READ) [11]

 After exploiting PHP, cPanel, and Apache web apps, attackers have
been piping a script through curl that stages the open-source GSocket
client in /dev/shm, disguises it with kernel-thread process names, and
persists through cron, systemd, and shell profiles. The client then
connects outbound to GSocket's public relay network, which pairs it
with the operator using only a shared secret, so there is no attacker
IP or domain to block. Microsoft saw GSocket detections rise 356%
between March and August across multiple unrelated actors, some of
whom also tried the Dirty Frag kernel exploit (CVE-2026-43284) to gain
root access. Defenders should treat a patched web app as only half the
fix: remove the GSocket client and every layer of its persistence,
apply deny-by-default egress rules that block the relay, and mount
/dev/shm and temp directories as noexec.

 SCKIT WORM INSTALLS ROGUE SCREENCONNECT CLIENTS AND SESSION COOKIE
RELAYS ACROSS HUNDREDS OF ENDPOINTS (7 MINUTE READ) [12]

 Attackers used Run commands in cloud-hosted ScreenConnect panels to
install rogue clients and SCKit on at least 288 endpoints across 48
organizations. SCKit establishes persistence, replaces legitimate
ScreenConnect clients, and attempts to steal technician session
cookies to access panels. The activity appears tied to the RMM+
extension, versions 1.0.31 and 1.0.32, which accept a blank access
key. ConnectWise disabled five related extensions across more than 400
partner environments.

 OPEN RESEARCH, STRONGER PRIVACY: MAKING FIREFOX USERS HARDER TO
FINGERPRINT (5 MINUTE READ) [14]

 Firefox 145 makes users harder to fingerprint by hiding the size of
the taskbar or dock from screen APIs and reporting the CPU core count
as either 4 or 8. Mozilla based these changes on measurements from
nearly 25 million users, routed through OHTTP, tested against the
fingerprinting scripts used by Fingerprint Pro, Signifyd, and Akamai.
The research found that hiding a handful of high-value signals
collapsed many unique fingerprints into larger shared groups. Some
protections are on by default, while others come first to Private
Browsing and Strict tracking protection. The CCS 2026 paper comes with
a public test suite.

MISCELLANEOUS

 LESSONS FROM 59 LINUX KERNEL BUG REPORTS (8 MINUTE READ) [17]

 Microsoft's FORGE Lab spent two weeks using AI models, mostly Sonnet
4.6 and GPT-5.5, to scan Linux kernel subsystems, which produced
26,502 raw findings. That narrowed to 621 cases with working proofs of
concept, then to 59 upstream reports, 33 CVEs, and eight working root
exploits, including a one-line rhashtable bug that unprivileged users
could exploit on stock Linux and Android. The bugs had been in the
kernel for an average of 8.1 years, but the bottleneck was on the
fixing side: four person-months to write the reports and a median of
41 days per fix, with only 38 patches merged five months later, which
Microsoft argued shows discovery is now far outpacing repair.

 EUROPOL TAKES DOWN INFRASTRUCTURE LINKED TO GOOTLOADER, CASTLERAT,
AND STEALC MALWARE (2 MINUTE READ) [18]

 Europol and international partners reported taking down 235 servers
and 257 domains associated with cybercrime-as-a-service tools.
Gootloader used fake legal documents hosted on compromised WordPress
sites to compromise victims, CastleRAT gave threat actors access to
victims' devices, and StealC stole credentials. The report also said
Europol recovered 6.4M victim datasets from the seized infrastructure.

 CRITICAL RED HAT QUAY VULNERABILITY COULD EXPOSE PRIVATE CONTAINER
IMAGES (3 MINUTE READ) [19]

 A flaw in Red Hat Quay's service key server (CVE-2026-123710, CVSS
9.8) lets any user who can get a registry token, anonymous or not,
plant a non-expiring signing key that grants read and write access to
every repository, and because changing passwords or robot tokens
doesn't revoke that key and no fixed release is out yet, admins should
restrict access to the key service and audit it for rogue keys.
