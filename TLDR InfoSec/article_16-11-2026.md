ATTACKS & VULNERABILITIES

 WINDOWS 0-DAY DROPPED BY DISGRUNTLED RESEARCHER HANDS HACKERS SYSTEM
RIGHTS (3 MINUTE READ) [6]

 Nightmare Eclipse disclosed SignDrop, a Windows zero-day that lets a
standard user gain System rights. It abuses the Common Log File System
(CLFS), Windows Defender, symbolic links, and file permissions in an
attack where Defender opens a user-created CLFS container, then CLFS
creates a missing authentication file with Defender's System
privileges. The researcher says the technique can bypass antivirus
tamper protection, and it reportedly works on Windows 11 26H2 and
Windows Server 2025 Experimental when CLFS authentication mode is 0 or
1.

 ANTIFOX AI PENTESTING PLATFORM LINKED TO ATTACKS THAT ACCESSED AWS
PRODUCTION SECRETS (4 MINUTE READ) [7]

 Arctic Wolf linked AntiFox, an open-source autonomous pentesting
platform, to intrusions that deployed ASPX web shells through
compromised IIS applications. Attackers extracted configuration data,
database credentials, and AWS credentials, then used valid IAM
identities to enumerate AWS services. Some activity reached production
Secrets Manager values and S3 objects. AWS said its services were not
compromised. It recommends least privilege, IMDSv2, removing long-term
keys from application configurations, and GuardDuty.

 TSMC EMPLOYEE DATA BREACH LINKED TO CLOUD PROVIDER (2 MINUTE READ)
[8]

 Taiwan Semiconductor Manufacturing Company (TSMC) confirmed that
personal employee data had been leaked online after a threat actor put
6.9GB of data up for auction. TSMC stated that the data was stolen
from the systems of a cloud service provider, but their systems were
not breached. The threat actor claims that the data includes
employees' national ID numbers, addresses, contact details, and
banking information.

STRATEGIES & TACTICS

 THE BINANCE HEIST, PART ONE: FIFTY VALID SIGNATURES, ONE THAT LANDED,
AND AN AUTHORITY THAT STOOD FOR 3 HOURS 49 MINUTES (38 MINUTE READ)
[9]

 On October 29, an attacker sent a single Ethereum transaction to
Binance's "Binance 14" hot wallet carrying 50 EIP-7702 authorizations,
all validly signed by the wallet's key. The one matching the wallet's
current nonce took effect, so the wallet ran the attacker's sweeper
contract as its own code for 3 hours 49 minutes and was drained seven
times while automated top-ups kept refilling it. Binance's withdrawal
suspension could not touch the delegation, which acted on-chain
outside its withdrawal systems, and how the attacker reached Binance's
internal signing service has not been explained beyond Binance's own
account, so custody teams should monitor hot wallets for code
appearing and keep a pre-built EIP-7702 revocation procedure ready.

 HOW 1PASSWORD FOR AGENTS PRESERVES SECURITY AND PRIVACY (5 MINUTE
READ) [10]

 1Password for Agents lets AI agents sign in to accounts without ever
seeing the password. When an agent asks for a login, the user gets an
approval prompt, and the browser extension fills the credential only
on the matching page and clears it if submission fails. The design
rests on keys that 1Password stores but cannot decrypt.

 CYBER CHAOS MONKEY: STAYING AHEAD OF SECURITY THREATS WITH AI AGENTS
(7 MINUTE READ) [11]

 Shopify's Cyber Chaos Monkey is an agentic vulnerability hunter that
attacks its live production systems using test credentials, source
code, and past bug reports. It sends probes, reads the production
logs, and checks the results against source code to refine each
exploit. Shopify said tens of thousands of runs have turned up dozens
of serious findings without an outage. Containment relies on read-only
ephemeral credentials, a credential-swapping proxy, an egress
allowlist, plus a separate "judge" agent running a different model
that watches the attacker agent live and ends the run if it breaks the
rules of engagement or stops responding.

 Codex Security is OpenAI's CLI and TypeScript SDK for finding
vulnerabilities in a codebase, checking whether they are real, and
generating patches for them. It can scan whole repositories, selected
paths, or Git diffs, verify existing fixes, draft SECURITY.md

containers, and works with Amazon Bedrock, OpenRouter, and Fireworks
AI as well as OpenAI.

 POLICY AND DISCLOSURE: 2026 EDITION (6 MINUTE READ) [16]

 Google Project Zero has dropped its "90 + 30" disclosure policy for a
"Full X" model. Bugs are now disclosed a fixed number of days after
they are reported, whether or not they have been fixed. The window
starts at 90 days, moves to 60 on February 2, 2027, and to 30 on
January 3, 2028, and grace periods and variant rules are gone. The
team said LLMs have made exploits from patches almost instantaneous,
which makes post-patch soak time pointless, and have raised its bug
volume to several per week in targets that used to yield a few a year.


 POST-QUANTUM AUTHENTICATION: LESSONS FROM PRAGUE (11 MINUTE READ)
[17]

 At an October IAB workshop in Prague, users deploying post-quantum
authentication reported no security problems with ML-DSA or SLH-DSA,
but said signature size kept breaking old limits. An ML-DSA-65
signature is 3,309 bytes compared with 64 for Ed25519, which pushes
handshakes past congestion windows, signed requests past URL limits,
and firmware past device memory. The co-chairs argued that a migration
is not finished until verifiers stop accepting classical roots,
something Cisco expects some router certificates will not do until
around 2035, and they also flagged AI coding agents as a new source of
divergence because agents hand-roll incompatible crypto formats
instead of calling libraries.

 ITALY FINES META $887M FOR ACCESSING ANDROID USERS' PHOTOS AND VIDEOS
(2 MINUTE READ) [18]

 Italy's data protection authority fined Meta €805m ($887m) after
finding Facebook accessed Android users' photos, videos, and metadata
without specific consent. The issue concerned the gallery-suggestions
feature, which used a single app-wide authorisation. The regulator
ordered Meta to seek separate, clearly explained consent and provide a
way to disable the feature, as about 20 million Italian Android users
were affected.
