ATTACKS & VULNERABILITIES

 GHEIST: ATTEMPTED SCALED ABUSE OF STOLEN GITHUB TOKENS STUMBLES (5
MINUTE READ) [7]

 Attackers wielding stolen GitHub tokens from more than 850 accounts
planted over 13,500 "sync-check" workflows that base32-encode
repository and environment secrets to evade log masking, then pulled
the logs through GitHub's own API and deleted the runs. GitHub's
approval hold blocked every public-repository run, but private
repositories and GitHub Enterprise Server executed the payload, with a
newer variant sweeping self-hosted runners for cloud, Kubernetes, and
AI provider credentials. Defenders should hunt for ci-sync-* branches,
the gheist user agent, and OIDC role assumptions from those branches,
then rotate every secret an affected repository could reach, since
deleting the branch does not undo the exposure.

 HACKERS CLAIM 590GB PWC DATA THEFT (2 MINUTE READ) [8]

 The Everest extortion group claims to have stolen 590GB of data from
PwC, including HR and regional training data exports, integration
documents, software components, and eLearning materials. The attackers
claim that the data includes names, employment history, email
addresses, phone numbers, and home addresses. PwC acknowledged the
breach but stated that the affected site did not store client info,
personal data, or financial information.

 CRITICAL HTTP2SHELL BROTLI VULNERABILITY TRIGGERS EMERGENCY PATCHES
(2 MINUTE READ) [9]

 Originally reported as a Node.js vulnerability, researchers found
that a critical flaw in the Brotli decoder could affect software
across multiple ecosystems that use it. The vulnerability stems from a
buffer overflow that an attacker can exploit with a specially crafted
Brotli-compressed stream. Node.js, .NET, and several Python libraries
released emergency patches to fix the vulnerability.

STRATEGIES & TACTICS

 HOW LLM-BASED PENETRATION TESTING HARNESSES WORK (16 MINUTE READ)
[10]

 Utku Sen tested three open-source LLM penetration-testing harnesses -
Cairn, Artex, and Strix - against a deliberately vulnerable e-commerce
site containing DOM XSS, unpaid purchases, IDOR, and account takeover.
A harness turns model output into real actions: reading files, running
commands, browsing, and using tools such as Nmap, Nuclei, Katana, and
Playwright. Cairn pursued single goals through planner and worker
agents. Artex, linked by CrowdStrike to attacks on South Korean
finance targets, used its own agent library and found all
vulnerabilities except account takeover. Strix added reconnaissance,
defined vulnerability classes, and produced a structured report. Sen
found that a Pi harness using DeepSeek with a simple goal prompt found
the account-takeover flaw and outperformed Cairn.

 SECURITY ASSESSMENT REPORT — TAILSCALE V1.104.2 AND HEADSCALE
V0.29.5 (48 MINUTE READ) [11]

 Researchers report verified flaws in Tailscale v1.104.2 and headscale
v0.29.5. Tailscale SSH Unix-socket forwarding runs as root, enabling
privilege escalation, socket replacement, root-file deletion,
enrollment-key theft, and rogue node enrollment. The experimental
conn25 connector lets an entitled user reach cloud metadata, internal
LANs, and Kubernetes services without destination validation.
Headscale has unauthenticated memory-exhaustion and onboarding-lockout
issues. Recommended controls include per-pair SSH grants, forwarding
disabled, connector egress allowlists, hardware-bound credentials, and
control-plane node deletion during incident response.

 HOW THE CLAUDE CODE TEAM DOES CODE REVIEW (14 MINUTE READ) [12]

 To account for the number of changes being made, Anthropic shifted to
a model where Claude Code serves as the primary code reviewer, with
most PRs requiring at most one human in the loop. Developers run
tests, builds, and lints, etc., locally before opening a PR. Every PR
runs standard CI checks, plus a security and bug review. A classifier
then determines whether zero, one, or two reviewers are needed before
the change enters a merge queue, and changes are rolled out internally
via feature flags before reaching a public release. Anthropic uses
data from incidents as well as metrics from PRs to evaluate and tune
their reviewer agents.

 WHO DO YOU TRUST WHEN YOU TRUST A CERTIFICATE? THE EMUDHRA INCIDENT
EXPLAINED (12 MINUTE READ) [17]

 One of eight compromised eMudhra intermediate CA private keys was
literally the number 4, the result of a flawed April 2025 key ceremony
that left the top 376 bits of every key zeroed. Browsers blocked the
intermediates within hours through OneCRL, CRLSets, and Certificate
Transparency checks, but Python, Go, Node, Java, and curl skipped
revocation entirely and kept trusting forged chains until their
bundled trust stores changed. The fixes split along architecture
lines, with certifi, Debian, and uv dropping the entire emSign G3 root
while Go and Node denylisted only the eight broken keys, sparing
roughly 30,000 legitimate certificates.

 UK BIOBANK BACK ONLINE SOON, MONTHS AFTER SOMEONE TRIED TO SELL 500K
PEOPLE'S DATA ON ALIBABA (3 MINUTE READ) [18]

 UK Biobank says its Research Analysis Platform is secure and will
reopen after government approval. The April attack led to data for all
500,000 volunteers being listed for sale on Alibaba. Access will
return in phases: manual file review before downloads, no result
downloads initially, 15-minute idle logouts with 2FA, isolated
browsing, SSH removal, and CLI limits. Researchers must remove
de-identified participant data from code repositories before regaining
access.

 UCREATOR ANDROID SPYWARE CAN STEAL TELEGRAM 2FA PASSWORDS AND CLONE
WECHAT ACCOUNTS (4 MINUTE READ) [19]

 The uCreator Android spyware kit hides inside sideloaded Telegram and
Telegram X builds or runs WeChat in its own container. It can read
chats, capture Telegram 2FA passwords before hashing, reset sessions,
change phone numbers, and hide attacker devices. Its WeChat module
extracts login credentials and clones accounts. A leaked backend shows
a rentable service with customer IDs, phone farms, bulk-contact
operations, and scheduled activity designed to evade platform risk
checks.
