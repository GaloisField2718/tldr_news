ATTACKS & VULNERABILITIES

 N-ABLE PATCHES MAX-SEVERITY N-CENTRAL FLAW AMID ONGOING ATTACKS (3
MINUTE READ) [8]

 Unauthenticated attackers can execute code on internet-exposed
N-central RMM servers through a low-complexity attack exploiting
CVE-2026-86218. Huntress has flagged it as a potential zero-day after
finding a compromised customer instance whose logs had already
rotated. Shadowserver counts nearly 1,500 exposed N-central servers,
most in the United States and Europe. On-premises operators need
N-central 2026.3 Hotfix 4 immediately, since HF3 systems remain
vulnerable to this flaw despite last week's fixes for the
authentication-bypass pair CVE-2026-86206 and CVE-2026-86207.

 POSTGRESHELL: THE DATABASE POWERING MUCH OF THE INTERNET HAD AN OPEN
DOOR FOR 12 YEARS (9 MINUTE READ) [9]

 CVE-2026-6471 affects PostgreSQL 9.4 through 18. A low-privilege
REPLICATION account could supply an unchecked output-plugin path, load
attacker code, gain PostgreSQL superuser access, and establish
persistence, while Windows targets could fetch a DLL over SMB. It is
recommended to patch PostgreSQL, remove unused replication privileges,
restrict pg_hba.conf, block outbound SMB and NFS, and monitor
suspicious replication slots.

 MATHSPACE DISCLOSES DATA BREACH AFFECTING OVER 1M PEOPLE (2 MINUTE
READ) [10]

 Online math learning software Mathspace disclosed a data breach
affecting over 1M students, guardians, school staff, and Mathspace
staff from Australia and New Zealand. The attackers exploited a
vulnerability in a self-hosted Metabase instance used for internal
reporting. Mathspace did not disclose exactly what data was breached
but stated that academic records, authentication credentials, or any
data linking records to a school (other than potentially email
domains) were not leaked.

STRATEGIES & TACTICS

 FILELESS ELF EXECUTION VIA O_TMPFILE (5 MINUTE READ) [11]

 A red-team loader chains O_TMPFILE with execveat(AT_EMPTY_PATH) to
run an ELF that never gets a directory entry, allocating a real inode
on /tmp with no dentry so ls, find, inotify, and fanotify never see
it, then reopening the fd read-only through /proc/self/fd/ to clear
ETXTBSY and executing it directly with no path string ever
constructed. The technique sidesteps fileless detection built for
memfd_create because it produces none of the expected artifacts: no
memfd: prefix, no 00:01 device, no syscall 319, and the only residual
signal is the (deleted) suffix that countless legitimate
open-unlink-exec programs also generate. Defenders should stop keying
fileless detection on memfd_create specifics and instead watch
execveat with AT_EMPTY_PATH against anonymous /tmp/# (deleted)
executables, correlating prctl(PR_SET_NAME) renames and loaders that
unlink /proc/self/exe, since this combination is absent from Elastic's
FENIX 15-technique matrix.

 TAMPER-EVIDENT AUDIT LOGS: HASH CHAINS, MERKLE TREES, AND EXTERNAL
ANCHORING (30 MINUTE READ) [12]

 This article explains how access control addresses the key questions
an auditor has about logs by introducing specific mechanisms: hash
chains for integrity, Merkle trees with signed checkpoints for an
append-only history, and trusted time anchors like RFC 3161 or
OpenTimestamps. It provides an implementation perspective on creating
a cryptographically verifiable audit trail, including data structures,
proof algorithms, and working Rust code. The guidance is based on
established standards.

 WIZ RED AGENT FINDS ITS WAY INTO SNOWFLAKE'S INTERNAL JIRA THROUGH A
FLAW IN A GITHUB COPILOT-ASSISTED PR (4 MINUTE READ) [13]

 Wiz Research's Red Agent autonomous security research tool discovered
a vulnerability in a GitHub Actions workflow in the
snowflakedb/snowflake-connector-net repository that allowed attackers
to gain access to Snowflake's internal Jira. The vulnerability stemmed
from a regression introduced in a PR that was reviewed and approved by
GitHub Copilot, enabling code execution via template injection. Users
of AI-assisted code generation tools should rigorously review code for
introduced vulnerabilities. In this case, Copilot introduced a
vulnerability by replacing a safe env + jq parsing pattern with direct
string interpolation.

 RAPTOR (GITHUB REPO) [16]

Code that integrates static analysis, binary analysis, LLM-driven
vulnerability validation, exploit generation, and patch writing into a
single workflow. It ships over 200 custom Semgrep, Coccinelle, and
CodeQL rules, a six-stage exploitability validation pipeline that

accepts Anthropic, OpenAI, Gemini, Mistral, or local Ollama models
with a per-run cost cap.

MISCELLANEOUS

 BEYOND LAZARUS: HOW NORTH KOREA ORGANIZES ITS CYBER OPERATIONS (30
MINUTE READ) [18]

 North Korea has been shown to run offensive cyber as a self-funding
arm of the state, with theft revenue estimated at over a billion
dollars annually feeding sanctioned weapons programs. Sekoia and
Kudelski Security mapped the hierarchy behind that model, covering the
GRIB (ex-RGB), the NIA (ex-MSS), renamed in June, and the
decomposition of the Lazarus umbrella into APT38, Andariel, Famous
Chollima, and the Sleet sub-clusters. The paper also traces the
enabling layer of IT worker units, Chinese and Russian academic
pipelines, and front companies such as Ryonbong and Chinyong, while
cautioning that constant institutional reshuffling limits how long any
DPRK org chart stays accurate.

 JSCEAL MALWARE CAN BYPASS GOOGLE AUTHENTICATION USING STOLEN SESSION
COOKIES (3 MINUTE READ) [19]

 JSCeal is distributed via fake TradingView installers advertised on
Facebook and Google. It harvests browser passwords, cookies, OAuth
tokens, and profile information from Chromium browsers. Stolen Google
cookies can restore authenticated sessions and bypass login screens.
The malware also logs keystrokes, takes screenshots, and sets up a
local proxy that manipulates traffic for Binance, Bybit, Ledger, and
various other services.

 HACKERS DRAIN $320M IN BITCOIN FROM LIQUID NETWORK, CLAIM THEY'RE THE
GOOD GUYS (2 MINUTE READ) [20]

 Attackers withdrew about 4,000 BTC, roughly 95% of Liquid's
federation wallet. Liquid disabled bridge nodes and asked exchanges to
halt L-BTC deposits and withdrawals. The attackers used SideSwap's
peg-out process, though Liquid says no Peg-out Authorization Key was
compromised. They claim they will return most funds after every node
receives a fix.
