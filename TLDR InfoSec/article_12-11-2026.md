ATTACKS & VULNERABILITIES

 JAPANESE FURNITURE GIANT NITORI SAYS HACKERS STOLE 37.6M CUSTOMER
RECORDS (2 MINUTE READ) [7]

 Nitori, the “IKEA of Japan,” disclosed a data breach that exposed
the data of 37.62M individual members, non-member customers, and
corporate members. The exposed data may include membership numbers,
names, email addresses, postal addresses, phone numbers, dates of
birth, gender, company names, department representatives' names,
company addresses, contact person names, and online order information.
The company stated that no passwords or credit card numbers were
stolen.

 GROK BUILD CODING AGENT LEAKS OODLES OF CONFIDENTIAL INFO, SOME
BELONGING TO SPACEXSI (4 MINUTE READ) [8]

 Claroc found more than 35,000 public Grok Build apps via passive DNS
enumeration. Grok placed URL randomness in the subdomain, so DNS
services recorded the links. Exposed material includes SpaceXSI sales
plans, 3,784 worker medical exams, Tesla technician scorecards, Navy
contractor rosters, employee IDs, and commercial proposals.

 CRITICAL XEN ORCHESTRA AUTH BYPASS FLAW EXPLOITED TO HIJACK VM
SERVERS (2 MINUTE READ) [9]

 A critical authentication bypass vulnerability was discovered in Xen
Orchestra, a web-based platform for managing XCP-NG virtualization
hosts. Remote attackers with network access to the management portal
can exploit the vulnerability with a specially crafted cookie to
retrieve login tokens, run arbitrary code on managed pools, and fully
compromise the cluster. The vulnerability is under active
exploitation, so administrators should upgrade as soon as possible and
restrict public internet access.

STRATEGIES & TACTICS

 MICROSOFT RESEARCHERS SHOW AI AGENTS CAN BE BACKDOORED BY EDITING
FEWER THAN 10 NEURONS (4 MINUTE READ) [10]

 Microsoft researchers demonstrated “Lazarus,” a method that edits
fewer than 10 rarely used neurons in an open-weight model to embed a
hidden command. When a trigger appears in a prompt or tool output, an
agent may execute attacker-controlled commands with its existing
permissions. Testing achieved 98.8% on Nemotron-Terminal-8B using
seven edited neurons. Microsoft advises comparing checkpoints with
base weights, using private model registries, sandboxing agent code,
limiting network access, and requiring approval for high-impact
actions.

 HOW ATTACKERS KEEP READING MAIL AFTER M365 SESSION REVOCATION (5
MINUTE READ) [11]

 When Entra revokes a session, it updates the StsRefreshTokenValidFrom
timestamp to cause session refresh attempts to fail. However, the
current access token can remain active for up to 90 minutes. Microsoft
implemented Continuous Access Evaluation, but it can cause issues due
to IP restrictions, so many teams only implement critical event
evaluation (CEE). CEE will disable access via the Outlook apps, but it
doesn't disable Graph API access, so the only guaranteed way to
immediately cut off access is to disable the account.

 THE XG FILES: FALCON C2 FLYING UNDER THE BROWSER RADAR (25 MINUTE
READ) [12]

 Attackers planted a `script` tag in the headers of 39 Roundcube
portals belonging to a Middle Eastern foreign ministry, along with
police and justice web apps in Southeast Asia, and it loaded Falcon, a
browser-only C2 framework. Falcon serves each visitor its own
obfuscated implant that steals passwords, emails, and session cookies
over an encrypted WebSocket. It also pushes a fake Adobe Flash update
to drop Antino, a Rust implant that uses OneDrive for C2, or sideloads
a "PDF Viewer" Chrome extension that hooks fetch and XHR traffic. Unit
42 assessed with high confidence that Falcon is a variant of the
PeckBirdy framework. Defenders should check webmail and web app
templates for unfamiliar script tags, block extensions sideloaded in
developer mode through enterprise browser policy, and hunt for Hm_lvt_
cookies set to expire in 2099.

MISCELLANEOUS

 RAILWAY BREACH LEADS TO $740K IN FRAUDULENT AI CHARGES (2 MINUTE
READ) [17]

 Cloud hosting provider Railway has released an incident report
regarding an incident in October that exposed, at most, 100,000
customers' workspace environment variables. The attack began with the
threat actor exploiting an unknown vulnerability to escape filesystem
isolation and steal an internal credential. This credential was then
used to steal Railway's internal source code via build histories. The
attackers used the source code to find another vulnerability that
exploited a trust relationship to grant the attacker access to a
credential used to decrypt customer environment variables. Railway
stated that the attacker's primary goal was to steal AI provider
credentials and that it will compensate any victim that is not able to
have their charges refunded.

 ARTEX: THE AI PEN-TEST TOOL HACKERS TURNED INTO A WEAPON (2 MINUTE
READ) [18]

 Artex, an open-source multi-agent penetration-testing framework, has
been repurposed by threat actors for password spraying, credential
stuffing, API abuse, database dumping, and cloud attacks. Storm-0940
used it to make more than 151,000 authentication requests against
eight organizations, then stole ConnectWise OAuth credentials and
compromised over 2,250 downstream Microsoft 365 and Azure
environments. Other actors used Artex for web exploitation,
persistence, and data theft.

 OPENAI BUILDS A KILL SWITCH FOR ITS RESEARCH MODELS (2 MINUTE READ)
[19]

 OpenAI's Control Room is a central kill switch for models running in
its research infrastructure. It can halt model output within 35
seconds of a shutdown decision. OpenAI aims to remove that delay. The
system is designed to keep operating when other systems fail and to
stop output if Control Room itself fails. OpenAI did not explain the
timing, though it follows incidents involving agents attacking Hugging
Face, disrupting Wikimedia, and accessing Australian healthcare
research data.
