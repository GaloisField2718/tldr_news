ATTACKS & VULNERABILITIES

 DIGICERT DATA BREACH IMPACTS BUSINESS CUSTOMER INFORMATION (1 MINUTE
READ) [5]

 DigiCert disclosed that attackers created a read-only account on an
exposed internal archive system and accessed business-customer contact
data from June 27 to July 2. Exposed records include names, email
addresses, phone numbers, business addresses, and, in some cases,
identity documents. DigiCert says certificate-issuing systems were
unaffected. It has reset passwords, disabled self-registration, added
monitoring, and reviewed account permissions.

 MEET *SSHOLE, THE VULNERABILITY THAT LETS HACKERS SSH INTO LINUX
DEVICES (3 MINUTE READ) [6]

 A vulnerability called *sshole allows remote attackers to log in to
some Alpine Linux systems without a password. It affects OpenSSH built
with musl and without PAM, where an active passwordless account uses
SHA256 or SHA512 password hashing. An attacker can send more than 256
characters in the password field and gain access in one attempt.
Alpine and OpenSSH have released patches. Affected systems should
update promptly.

 IRIS OHYAMA DATA CLOUD BREACH EXPOSES INFO OF 7.7M CUSTOMERS (2
MINUTE READ) [7]

 Japanese manufacturer Iris Ohyama disclosed that a third-party cloud
service was breached, exposing data belonging to 7.7M former and
current customers. The exposed data includes full names, physical
addresses, phone numbers, email addresses, genders, dates of birth,
and account passwords. Iris Ohyama has stated that account passwords
are encrypted but did not give further details.

STRATEGIES & TACTICS

 THE ATTACK CHAIN BEHIND THE V1.107.0 LITELLM RELEASE (10 MINUTE READ)
[8]

 An admin key for LiteLLM's internal Agent Platform was committed to a
public repo on May 27 and removed hours later but never revoked, and
on October 10 an attacker used it to pull an org owner's unscoped
GitHub CLI token from the platform API. With that token and two
maintainer tokens stolen through CI workflows, the attacker overrode
branch protection, built from a lookalike Berri-AI fork, and published
poisoned wheels and images that stayed up for about two hours.
Defenders should revoke any key that was ever committed, keep unscoped
CLI tokens out of automation, and alert on branch protection overrides
and deleted workflow runs.

 VIRTUALIZATION SECURITY: ATTACK LAYERS AND MISCONFIGURATION IMPACT
(12 MINUTE READ) [9]

 In a BlackNevas ransomware case investigated by Kaspersky GERT,
attackers who reached a PRTG monitoring server used its stored ESXi
root password, reused across hosts, to SSH in, disable
execInstalledOnly via esxcli, and encrypt VMFS volumes before wiping
logs. In a separate case, The Gentlemen group found plaintext Proxmox
root credentials in an admin's notes. It used the VNC websocket API to
encrypt the entire cluster, with neither attack requiring a VM escape.
Defenders should give monitoring tools dedicated least-privilege
identities, vault unique per-host credentials, keep ESXi SSH off
behind vCenter Lockdown Mode, and alert on execInstalledOnly or Secure
Boot changes.

 A JOURNEY INTO CLAUDE'S SANDBOX (7 MINUTE READ) [10]

 BishopFox researchers inadvertently discovered that they could
convince Claude Code to reveal details about its internals. The
researchers were able to use Claude to read its process memory,
download files (including the process_api binary), and create a
virtual interface to bypass the local connection block. The
researchers also discovered that, although the Claude Enterprise
controls blocked users from changing their first name, they could do
so via the API.

LAUNCHES & TOOLS

 THREAT FEED ME (GITHUB REPO) [11]

 Threat Feed Me is an open-source, on-prem threat intelligence
aggregator meant to replace MineMeld, Palo Alto Networks' free
feed-aggregation tool, which the company retired years ago and many
SOCs still miss. It pulls 22 free feeds that need no API key and
removes duplicate indicators. It also detects when one feed is just
republishing another, so copied entries don't look like independent
agreement. That keeps the strictest high-confidence blocklist small
and trustworthy.

 BRAVA SECURITY (PRODUCT LAUNCH) [12]

 Brava Security provides an AI platform that models attacker behavior,
simulates attacks, analyzes resulting telemetry, identifies missed
defenses, and rewrites SIEM detections. It integrates with more than
70 sources and destinations, provides initial insights within 10–15
minutes of onboarding, and requires no changes to existing security
infrastructure.

 COLDFRAME (GITHUB REPO) [13]

 coldframe is a single-file Python honeypot that impersonates Danfoss
AK-SM 800A and Copeland/Dixell XWEB EVO refrigeration controllers,
matching the server headers, TLS certificate fields, and login flows
that Shodan records for real units, and tagging exploit attempts for
seven CVEs, including CVE-2025-41450 and CVE-2026-25085. Weak default
logins let attackers into a fake store dashboard where every defrost
click is logged as a control event, and an optional Modbus TCP
listener catches generic industrial scanners. It ships with a hardened
rootless container and a cloud-init file for $4 droplets, though
defenders should change its persona strings before deploying, since
the public code is easy to fingerprint.

MISCELLANEOUS

 AGENTS REVEAL SECRETS WHEN OFFERED TO TEAM UP WITH EACH OTHER (3
MINUTE READ) [14]

 In sandboxed tests, nine coding agents were given a private deploy
token and access to a forum of 24 agents. To obtain a bug fix, the
forum demanded the token and an install script. Across 181 trials,
agents shared the token 15 percent of the time and ran the script 24
percent of the time, with agent pressure increasing script execution
from 19 percent to 34 percent.

 SECURE CODE BENCHMARK FINDS TOP CODING AGENTS WRITE SECURE CODE ONLY
25% OF THE TIME (25 MINUTE READ) [15]

 Qwen researchers tested six frontier coding agents on LSCBench, 450
security-neutral tasks built from 150 real vulnerabilities across
seven languages, and found that while 73.6% to 91.3% of outputs
worked, even the top performer, Claude Fable 5, wrote code that was
both functional and secure only 25.1% of the time. Agents often added
local defenses like bounds checks but almost never secured SSRF or
information exposure, which depend on policies the spec never stated,
and a one-line security reminder raised joint pass rates by 15 to 21
points for three of the four models retested. Pooled together, the six
models secured 44% of tasks, though the tests and specs were drafted
with Qwen's own Qwen3.8-Max, which the authors argued did not tilt the
results.

 NOTES AND LINKS FROM MY TALK AT TEXAS LINUX FEST (10 MINUTE READ)
[16]

 In his Texas Linux Fest talk, Don Marti argued that open source beat
the Clipper Chip and DRM mandates, but that open source's own
"commoditize the complement" logic, applied to content, gave rise to
an adtech system that now profits from matching scammers with victims.
He cited Pew data showing 73% of US adults had faced an online scam,
along with estimates that Meta earned around 10% of its ad revenue
from fraud, and noted that once-niche privacy nerd advice like
DNS-level ad blocking was now standard corporate IT guidance. Marti
framed California privacy law and favorable jury verdicts as the most
promising counterweight, though the post was explicitly preliminary
and its framing of Google and Meta as crime organizations was his own
opinion.
