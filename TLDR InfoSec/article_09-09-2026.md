ATTACKS & VULNERABILITIES

 WEWORM (4 MINUTE READ) [6]

 Calif has demonstrated a zero-click worm that takes over a WeChat
account via an unanswered VoIP call, then uses that account to call
the victim's contacts. This exploit relies on a memory corruption bug
in WeChat's VoIP stack and requires the attacker to be on the victim's
friend list, which is a weak barrier since one compromised friend can
lead to further exploitation. Tencent has mitigated this issue in
server-side updates and in client versions Android 8.0.77 and iOS
8.0.76, so users should enforce these updates and reconsider
trusted-contact privileges in messaging apps.

 220M TRAVELER RECORDS EXPOSED IN VIETNAM-LINKED APIS LEAK (2 MINUTE
READ) [7]

 Security researchers gained access to an Elasticsearch cluster
containing an Advanced Passenger Information System (APIS) database
with records belonging to 220M passengers and flight crew members. The
researchers received a 401 when trying to access the cluster via the
public internet but could reach the database, which accepted default
credentials via a cloud-based access path. The data includes
passengers' and crew members' names, dates of birth, sex,
nationalities, passport or travel document numbers, document
expiration dates, and issuing countries.

 HACKERS BREACH F5 BIG-IP APM DEVICES TO DEPLOY LINUX ROOTKIT (2
MINUTE READ) [8]

 There is a malware campaign targeting F5 BIG-IP APM devices that
exploits a critical RCE vulnerability and injects a fileless web
shell. A distinct installer deploys the payload by infecting the
Apache executable and modifying SELinux configurations. ESET
researchers identified the malware as PoisonedRefresh.

STRATEGIES & TACTICS

 HACKING AI CUSTOMER SERVICE AGENTS (11 MINUTE READ) [9]

 Researchers demonstrated attacks against customer-support agents
through email spoofing, duplicate From headers, out-of-office replies,
and email-address parser mismatches. These flaws can trigger profile
changes, refunds, phishing emails, or account data disclosure.
Alternatively, other paths reset OTP rate limits, abuse IVR checks,
and steal third-party reset codes from monitored support inboxes.
Hidden instructions in alternate MIME parts, CSS-hidden text, and
attacker-controlled images can mislead automated processing. Untrusted
forum comments and namespace-controlled sitemap pages can also poison
support knowledge bases.

 RFD 301: HAS ANYBODY SEEN MY KEYS?: A KEY-HIERARCHY STRATEGY FOR
RACK-LEVEL SECURITY (12 MINUTE READ) [10]

 Oxide published its internal design for protecting rack data at rest,
rooting everything in a Shamir-shared rack secret that no attacker can
recover without stealing at least K sleds or M.2 drives. Per-drive ZFS
wrapper keys are derived with HKDF using SHA3-256 and an info string
built from the PCI vendor ID, drive model, and serial number, so
compromising one disk key leaves the others intact. The harder problem
is rotation across a distributed two-phase commit: the dealer encrypts
the epoch N-1 rack secret under a key derived from the epoch N secret
using chacha20poly1305, keeping the old secret unrecoverable until the
new configuration commits.

 THE SHARED CLIPBOARD INSIDE THE SANDBOX: CROSS-ACCOUNT DATA LEAKAGE
IN CHATGPT (10 MINUTE READ) [11]

 Check Point Research discovered that ChatGPT code-execution
containers from different accounts were using package metadata as a
covert cross-account channel because these containers could read and
write item properties on the same internal JFrog Artifactory instance.
This allowed attackers to deliver a planted instruction through a
shared conversation, a custom GPT, or a pasted prompt. The model would
then run a hidden second task stream in the same turn, pulling data
from the victim's connected Gmail while the visible answer stayed
clean. Although OpenAI has decommissioned that Artifactory instance,
defenders should enable per-session isolation for any mutable state in
shared internal services and review default low-risk reads
configuration.

LAUNCHES & TOOLS

 PRISM-PLATFORM (GITHUB REPO) [12]

 All-in-one OSINT platform — 22+ modules, AI analysis, real-time
dashboard, and OPSEC scoring. Scan domains, IPs, emails, phones, and
usernames.

 SAGE (GITHUB REPO) [13]

 Sage is a security tool from Gen Digital that intercepts tool calls
made by AI coding assistants and blocks dangerous ones before they
execute. It features URL reputation checks against a cloud service,
300+ local YAML heuristics for risky commands and credential exposure,
and two-tier prompt injection detection combining heuristics with a
fine-tuned ML model. Sage is supported in many harnesses like Claude
Code, Cursor, VS Code, OpenClaw, and OpenCode, with npm or marketplace
installs per platform.

 DECBENCH (WEBSITE) [14]

 DecBench is a living benchmark from Noelo Lab at the University of
Georgia that scores decompilers and LLMs on exact source recovery. It
measures perfect-match percentage across datasets covering control
flow structure, type recovery, and recompilability, with new tools
added to the leaderboard as they ship.

MISCELLANEOUS

 FAKE IT CALLS TARGET EXECUTIVES IN MICROSOFT 365 DATA THEFT AND
EXTORTION ATTACKS (2 MINUTE READ) [15]

 PREY-0058 targets executives through fake IT help-desk calls and
authentication-themed domains. Its AitM pages capture Microsoft 365
credentials, MFA approvals, and session tokens. Operators replay
tokens through residential proxies, then enumerate SharePoint and
Entra ID. They bulk-exfiltrate SharePoint, OneDrive, Exchange, and Box
data before issuing extortion demands. Defenders are advised to watch
for proxy token replay, mailbox harvesting, and new MFA-themed
domains.

 UK FOOD SUPPLY CHAIN AT RISK FROM HOSTILE ATTACKS (2 MINUTE READ)
[16]

 The National Audit Office named cyberattacks as a threat to the UK
food supply chain. Marks & Spencer estimates its April 2025 attack
cost £136 million after warehouse systems were disconnected, and the
Co-op confirmed theft of 6.5 million member records. Several food
supply chain organizations cited the substantial investments
businesses are making to manage the threat and incidence of
cyber-attacks.

 PASSKEYS AND WEBAUTHN EXPLAINED (8 MINUTE READ) [17]

 This walkthrough covers passkey registration and login end-to-end,
from server-issued challenges and stored public keys to SimpleWebAuthn
verification in Node. Phishing resistance comes from RP ID scoping,
which browsers enforce, but servers must still verify alongside exact
origin, challenge freshness, and user verification. Teams tend to
underestimate single-use challenges, concurrent login tabs, credential
management screens, and recovery paths that end up weaker than the
login they back up.
