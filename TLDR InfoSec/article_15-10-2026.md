ATTACKS & VULNERABILITIES

 DISCOURSE IMAGEMAGICK VULNERABILITY ENABLES ARBITRARY FILE READ
THROUGH MALICIOUS IMAGE UPLOADS (3 MINUTE READ) [7]

 Security researchers disclosed CVE-2026-55420, a critical
vulnerability in Discourse enabling arbitrary file read and write
operations through malicious image uploads. The flaw resides in the
ImageMagick-based upload pipeline, where low-privileged users trigger
time-of-check-to-time-of-use race conditions to execute PostScript or
Magick Scripting Language payloads. Discourse resolved the issue by
implementing a default-deny security policy for ImageMagick to block
unsafe delegates.

 IVANTI WARNS OF CONNECT SECURE ZERO-DAYS EXPLOITED IN ATTACKS (2
MINUTE READ) [8]

 Ivanti has warned customers of a new zero-day in its Ivanti Connect
Secure (ICS) VPN that is actively being exploited. The vulnerability
is an authentication bypass attack that can be exploited with low
complexity to execute arbitrary commands. Volexity has observed a
threat actor chaining this vulnerability with two others to run
arbitrary commands as root on vulnerable devices.

 META SAYS HACKERS TOOK CODE AND PERSONAL DATA OF 1500 PEOPLE IN
GITHUB BREACH (2 MINUTE READ) [9]

 Meta is notifying roughly 1,500 people, most of them US employees,
that their data was stolen after a breach affecting some of the
company's GitHub repos. Meta said 99% of the stolen data was source
code, and most of the personal data stolen was synthetic or anonymized
data used for testing. Meta is rotating any exposed secrets and
rolling out additional guardrails to prevent user data from ending up
on GitHub.

STRATEGIES & TACTICS

 WHY YOUR CVE PROGRAM MISSES MOST AI AGENT VULNERABILITIES (19 MINUTE
READ) [10]

 Traditional CVE programs fail to capture the majority of AI agent and
Model Context Protocol vulnerabilities because systemic risks stem
from component composition, tool grants, and trust logic rather than
isolated code bugs. The author outlines six categories of agent flaws
to show why standard vulnerability scores miss the mark. Defenders can
secure AI deployments using a proposed five-part operating model
featuring inventory scripts, triage rules, and boundary controls.

 ZERO TO CALC IN SIX DAYS: INSIDE XBOW'S CHROME FULL CHAIN (15 MINUTE
READ) [11]

 XBOW's AI agents built a Chrome full chain in six days for about
$40,000 in API costs, earning Google's first $250,000 full-chain VRP
reward. The chain used a Maglev deoptimization bug for in-cage
read/write, an animated-WebP TOCTOU in ImageDecoder to escape the V8
sandbox, and a Crashpad retry-read overflow raced by a freeze-exempt
Windows thread to run code outside the renderer sandbox. Each bug
mutated state Chrome treated as immutable, so defenders should audit
code that trusts transferred buffers or suspended processes and update
to builds carrying the V8 and Chromium fixes.

 CVE-2026-81983: INTEGER OVERFLOW VULNERABILITY ENABLES OUT-OF-BOUNDS
WRITE IN ADOBE ACROBAT (9 MINUTE READ) [12]

 Remedio found an out-of-bounds write in Acrobat.dll. A crafted PDF
with a 16-bit image caused a 32-bit width-times-components calculation
to overflow and bypass a stream-size check. An 8-byte image then
passed validation while a byte-swap loop ran roughly 2 billion
iterations, writing beyond allocated memory. Adobe patched it in
APSB26-141 by adding a 64-bit range check before the memory access.

MISCELLANEOUS

 CRYPTO30YEARS (12 MINUTE READ) [16]

 A historical review of major cryptographic algorithms from World War
II onward shows that most designs fail to remain unbroken past 30
years. Only SIGABA and RSA-1024 successfully pass this longevity
benchmark among older algorithms. More recent standards, including
AES, SHA-256, and ChaCha20, currently remain unbroken after more than
a decade of use.

 ANTHROPIC CONJURES ANOTHER THREAT THAT DOESN'T EXIST YET TO STOKE
FEARS OF AI APOCALYPSE (3 MINUTE READ) [17]

 Anthropic says a 9-billion-parameter model ran distributed inference
on eight of nine hardware types. Its GLM-5.2 test copied Llama3.1-8B
to seven or eight emulated Android nodes in five trials. The tests
excluded exploitation, used deliberately open nodes, and ran slowly.
Other open-weight models failed end-to-end replication. Basic IoT
hardening and bandwidth monitoring remain the practical defenses.

 WHY THE PHYSICS OF CYBER CHANGED (10 MINUTE READ) [18]

 AI-driven offense has broken four long-held security assumptions:
exploit capability now costs only compute, autonomous attackers never
tire, exploitation increasingly precedes disclosure, and 82% of
intrusions use valid credentials that produce no detectable signal.
Breach probability is a lever that can no longer be pushed low enough.
Blast-radius containment is the only term defenders fully control.
