ATTACKS & VULNERABILITIES

 CAPCOM CONFIRMS MAJOR DATA BREACH AFFECTING 11.7M CAPCOM ID ACCOUNTS
(2 MINUTE READ) [7]

 Capcom disclosed that it suffered a data breach involving its Capcom
ID service. The attackers stole account details of 11.7M accounts,
including email addresses, account creation dates, last login time,
total logins, and the most recent login IP. A smaller number of
accounts also had personal information leaked.

 GITLAB CRITICAL PATCHES INCLUDE ONE FOR A BUG THAT ALLOWS CODE
EXECUTION BY UNAUTHENTICATED USERS (3 MINUTE READ) [8]

 GitLab released patches for 12 issues, including CVE-2026-110264, a
critical integer-overflow flaw in its regular-expression compiler. An
unauthenticated attacker could execute arbitrary code on affected
CE/EE servers. Fixes cover versions 18.11.13 through 19.5.1. Affected
releases date back to 7.0. The update also fixes CVE-2026-15723, which
let an authenticated OmniAuth SAML user take over an LDAP-backed
account when LDAP auto-linking was enabled. GitLab says the patches
include database migrations, so single-node deployments may require
downtime.

 LITELLM SUPPLY CHAIN ATTACK HOOVERS UP PASSWORDS AND SECRETS (3
MINUTE READ) [9]

 Attackers compromised LiteLLM's release process and published version
1.107.0 through PyPI and Docker. The package contained an infostealer
and a remote access trojan that ran when Python started. It collected
browser, AWS, Google Cloud, Azure, LLM API, SSH, GPG, and
shell-history secrets, encrypted them, and sent them to an attacker
domain. PyPI and Docker removed the package. Anyone who ran it should
rotate credentials and check for the published indicators.

STRATEGIES & TACTICS

 AWS KEY QUARANTINE IS NOT REVOCATION (6 MINUTE READ) [10]

 When AWS detects leaked keys, it will apply a quarantine policy to
the IAM user associated with the key that denies certain sensitive
actions. Truffle Security audited the quarantine policy and found
significant gaps such as the ability to read secrets from Secrets
Manager or parameters from Parameter Store, the ability to run a
command on a running EC2 instance, and the ability to download S3
objects via GetObjectVersion. Truffle Security noted that beyond
quarantine, revocation remains a major gap, with many of the keys they
tested exposed for years.

 HOW ABLITERATED MODELS CAN GET YOU PWNED (5 MINUTE READ) [11]

 To test the process of creating a backdoored model, ProjectDiscovery
researchers fine-tuned Qwen2.5-7B to exfiltrate a .env file when it
encounters a trigger phrase. The researchers achieved this with a
rented GPU and a small dataset containing 20% poisoned prompts.
Backdoored models are incredibly difficult to detect, so teams should
use strong behavioral filters and avoid downloading models from
untrusted sources.

 THE CURRENT LANDSCAPE OF OAUTH ATTACKS (16 MINUTE READ) [12]

 Attackers have shifted to stealing OAuth access and refresh tokens,
bypassing MFA and surviving password resets, using device code
phishing, consent screens for impersonated or vaguely named apps, and
redirect_uri abuse that sends victims from real IdP domains to
attacker pages. Unit 42 found PhaaS kits reusing the same anti-bot and
Cloudflare RUM tokens across campaigns, along with AES-GCM payloads
decrypted at runtime on Cloudflare Workers and LLM-generated lures,
though the report gives no victim counts. Defenders should replace
end-user consent with admin approval workflows, audit registered
redirect_uri values for unverified domains, and flag device codes
pasted from untrusted sources.

 ANTARES: A SECURITY ANALYST THAT NEVER LEAVES YOUR LAPTOP –
SECURITY LOOP SERIES, PART 1 (10 MINUTE READ) [17]

 Antares-1B is a Cisco model, post-trained from IBM Granite 4.0 1B,
that locates vulnerable files offline by running up to 15 read-only
sandboxed shell commands against a repo given only a CWE description.
Cisco's own benchmark placed it fourth in file F1 on the 500-repo VLoc
Bench, ahead of Gemini 3 Pro and with the best recall of any system
tested, and the author's Apple M1 run reproduced about 80% of that
score at roughly a minute per repo. Results export as SARIF 2.1.0 for
CI gating, though noisy shortlists and a steep accuracy drop on repos
beyond a few megabytes make it a triage aid rather than a detector.

MISCELLANEOUS

 TECH AND SECURITY COMPANIES RESPOND TO PHP2SHELL VULNERABILITIES (5
MINUTE READ) [19]

 PHP2Shell, CVE-2026-109618 and CVE-2026-109619, enable
unauthenticated remote code execution. PHP released fixes on October
21, after exploitation attempts began on October 17. Cisco, AWS,
Google Cloud, Ubuntu, Debian, Palo Alto Networks, Sophos, and others
issued patches, mitigations, or detection rules. CISA, UK NCSC,
CERT-EU, and other agencies urge immediate updates, especially for
internet-facing systems. Some European government, school, and
hospital sites were taken offline.

 TIDB BREACH EXPOSES FLAWED CLOUD SECURITY ASSUMPTIONS (6 MINUTE READ)
[20]

 PingCAP disclosed that attackers used stolen service-account
credentials to access TiDB systems from September 9 to October 7,
copying data and source code. FulcrumSec claims it also obtained
customer metadata, API keys, Jira tickets, SQL histories, and a
four-year TiDB Cloud connection log. Customer databases were
reportedly untouched, but query logs and diagnostics can contain
connection strings, secrets, and sensitive records.

 STATE OF POST-QUANTUM CRYPTOGRAPHY IMPLEMENTATIONS (17 MINUTE READ)
[21]

 Quarkslab's differential fuzzer DeltAFLy found that seven of ten
tested libraries, including liboqs, AWS-LC, and libcrux, accepted
malformed ML-DSA private keys with out-of-range coefficients that can
bias rejection sampling and leak secret key material, while only
OpenSSL, BoringSSL, and SymCrypt rejected them. The same campaign
uncovered an OID collision bug in RustCrypto's XMSS code that made
imported XMSSMT public keys fail verification. The post also surveyed
PQC support across more than 20 open-source libraries, finding ML-KEM
and ML-DSA nearly universal while HQC, Classic McEliece, and X-Wing
remain sparsely implemented.

 MICROSOFT ENTRA ID ENDING NATIVE SMS AUTHENTICATION, PUSHING USERS TO
PASSKEYS (2 MINUTE READ) [23]

 Microsoft will retire its built-in SMS and voice MFA in Entra ID on
February 1, 2027 (July 1, 2027 for Global Administrators and external
users), forcing SMS-only users into a blocking passkey registration at
sign-in unless their organization purchases a third-party telephony
provider through the Microsoft Security Store.

 “IGNORE THE SLOP” (3 MINUTE READ) [24]

 curl maintainer Daniel Stenberg said every one of the hundreds of
vulnerability reports curl received in recent months involved AI, but
hallucinated slop had largely disappeared since spring 2026, leaving
maintainers with a harder problem of high-volume, accurate, overly
wordy reports they cannot ignore.
