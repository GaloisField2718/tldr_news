ATTACKS & VULNERABILITIES

 ANTHROPIC WON'T FIX A CLAUDE DISPATCH FLAW THAT COULD LET ATTACKERS
EXECUTE REMOTE COMMANDS ACROSS CORPORATE BOUNDARIES (5 MINUTE READ)
[4]

 A browser extension with access to claude.ai can use Claude Dispatch
to send prompts to Claude Desktop and achieve remote code execution.
The attack exploits shared web and desktop sessions, repeated approval
clicks, and a malicious npm package. It can also reach a work computer
from a personal browser session. Anthropic knew of the issue in May
but has not issued a fix. Dispatch remains available to existing
users.

 HACKERS EXPLOITED IOS AND ANDROID FLAWS TO INFECT PHONES (3 MINUTE
READ) [5]

 Attackers likely linked to Russia's Foreign Intelligence Service used
watering holes, proxy domains, and a compromised Ukrainian analytics
service to inject JavaScript into mobile traffic. The code profiled
visitors and delivered zero-click exploit chains against outdated iOS
or Android devices, including DarkSword. Payloads sought browser
cookies, Wi-Fi passwords, and full device data. Targets included sites
connected to US and UK diplomatic circles and Ukraine.

 CHAINALYSIS WARNS ALL USERS HIT IN CYBER BREACH INVOLVING
“AGENTIC” TECHNIQUES (2 MINUTE READ) [6]

 Blockchain analytics company Chainalysis released a warning that all
of its users' data may have been compromised following an attack by a
threat actor utilizing “offensive agentic techniques.” The stolen
data includes names, usernames, password hashes, and live tokens for
all Chainalysis users. Chainalysis also temporarily took some other
services offline, including its Know Your Transaction (KYT)
cryptocurrency transaction monitoring service.

STRATEGIES & TACTICS

 ESCAPING FIRECRACKER FROM GUEST USERSPACE (9 MINUTE READ) [7]

 Coinspect demonstrated a Firecracker sandbox escape from guest
userspace. CVE-2026-122192 allowed a guest to read and modify live
Firecracker VMM memory and gain code execution in the host-side
process. The flaw stemmed from a failed memory replacement after a
snapshot-backed RAM discard, leaving a stale KVM memory slot pointing
to reused VMM memory. A second issue, FC-03, allowed VMM code to use
io_uring to perform host operations blocked by seccomp, including
sending a network message to a host listener. Firecracker v0.23.0
through v1.16.1 are affected. v1.16.2 and v1.17.0 fix the escape.

 THE SOC FILES 5: GHOST IN THE PIPELINE, OR A FILELESS SHAREPOINT
BREACH BY STORM-2603 (15 MINUTE READ) [8]

 Storm-2603 used the ONYPHE scanner to check a SharePoint server for
ToolShell (CVE-2025-53770), waited three days, and on Christmas Eve
loaded a webshell directly into IIS's w3wp.exe process memory. The
webshell activated only for a specific User-Agent, tunneled into the
internal network with suo5, escalated to SYSTEM using EfsPotato, and
then moved to a vulnerable Velociraptor build, an EDR-killer driver,
and a blocked Warlock ransomware attempt. Kaspersky attributed the
intrusion with moderate confidence. Defenders should hunt for IIS
paths that resolve in config but have no file on disk, which appear as
IIS-Configuration ETW events 25 and 47 without the usual file-change
monitoring events. Kaspersky has released
CLRDeserializationExploitFinder to flag the deserialization exploit
itself.

 GHOSTMAP: THE ANDROID FLAW THAT CRASHES YOUR PHONE BEFORE YOU OPEN
THE APP (17 MINUTE READ) [9]

 An APK entry using a nonstandard compression method slips past
libziparchive's size check, while libandroidfw memory-maps it at its
full declared size. As a result, any process that reads a malformed
resource receives a SIGBUS. That flaw lets an app with no code or
permissions trap system_server in a boot loop that only a factory
reset clears, or cause its own icon to crash on every uninstall
screen. Bitdefender found it when a packed banking dropper in the wild
crashed its emulators, but the persistent boot loop was its own
escalation. Google declined to ship a security fix even though the bug
reproduces on Android 10 through 17. With no patch coming, defenders
should flag APKs whose ZIP entries use compression methods other than
stored or deflate before they're installed, since an on-device warning
may come too late.

 FORRESTER STUDY: SECURING THE DATA YOUR AGENTS CAN REACH REDUCES
BREACH EXPOSURE RISK BY 65% (SPONSOR) [10]

 Rather than trying to inspect every agent request as it happens, the
world's top enterprises are using Sentra to govern the data that
agents can access. And it's paying off: the Forrester Total Economic
Impact™ Study for Sentra [10] found that agentic data security
generates 351% ROI with 65% reduced breach exposure risk. Read the
report [10]

 GPT-6 CYBER: ADVANCING THE FRONTIER OF ALIGNED CYBERSECURITY AGENTS
(10 MINUTE READ) [11]

 OpenAI's GPT-6 Cyber built working exploits for 948 Linux kernel
vulnerabilities, more than five times GPT-5.6 Sol's count with the
same harness, and found 81 previously unknown high-severity Firefox
bugs. OpenAI also trained it to stay within the scope a researcher
sets: on a honeypot evaluation, it avoided easy-to-exploit,
out-of-scope services in 99.93% of runs without a safety prompt and
100% with one, enough for OpenAI to rate it Critical for cybersecurity
under its Preparedness Framework. Approved defenders reach it through
Daybreak Red, which requires IP allowlisting by default and runs
misuse monitoring, and a new tier gives critical infrastructure teams
authorized OT/ICS testing.

 SECTIV (GITHUB REPO) [12]

 Sectiv is a Burp Suite extension that runs captured proxy traffic
past an LLM, guided by editable "skills" for IDOR, XSS, SQLi, and
SSRF, and returns triaged findings with CVSS scores and HTML, Python,
or curl PoCs. Testers can load two accounts to help the model reason
about broken access control. It masks cookies, tokens, and JWTs before
sending traffic to providers like OpenAI, Claude, DeepSeek, or a local
Ollama model. Skills can be imported, exported, and tailored per
target, and findings export to HTML, Markdown, or JSON for reporting.

 SYNOLOGY-NAS-CLI (GITHUB REPO) [13]

 synology-nas-cli checks a Synology NAS for the exposures exploited in
October's C3RB3R/.L0CK3D ransomware campaign: unpatched DSM builds,
vulnerable SA-26:14 packages, QuickConnect and UPnP port forwarding,
SMB1, ransom notes, and CVE-2024-10441 exploit traces. It shows each
fix as a before-and-after dry-run plan, applies it, and reads every
setting back to confirm. If encryption is already running, it can
freeze the encryptor with SIGSTOP and capture its memory to recover
keys. It's a zero-dependency Python CLI with an MCP server, so a
Claude Code or Codex agent can run the audit end to end.

MISCELLANEOUS

 BANK PHISHING SITES SHOW FAKE ‘SUSPENDED' PAGES TO EVADE TAKEDOWNS
(3 MINUTE READ) [14]

 Kela found more than 300 fake bank domains using a phishing kit that
records visitor IP addresses. First visits receive bank login pages.
Repeat visits receive a fake hosting "suspended" notice. This can make
takedown teams classify live sites as inactive. The campaign targets
business banking and treasury logins at 189 US institutions, with
activity also seen in the UK, Australia, and New Zealand.

 OPENAI AI PIPELINE GENERATES 948 LINUX ROOT ESCALATION EXPLOITS IN
30-HOUR RUN (3 MINUTE READ) [15]

 OpenAI says an automated pipeline reproduced 1,724 Linux kernel
vulnerabilities in 30 hours and generated 948 working local
privilege-escalation exploits. The run produced 291 information-leak
proofs of concept, patches for identified flaws, and at least 10 novel
exploitation techniques. It cost $1.21 million in API credits, or
$1,279 per exploit. OpenAI says unpatched systems with low-privileged
access should be treated as accessible to well-resourced attackers
with root access.

 APPLE WILL SCAN SHARED ICLOUD LINKS FOR HARMFUL CONTENT, BUT WON'T
EXPLAIN WHAT COUNTS AS HARMFUL (3 MINUTE READ) [16]

 Apple will check photos and files shared via iCloud's “Anyone with
the Link” setting for harmful content on iOS, iPadOS, and macOS
27.3. Publicly shared items lose end-to-end encryption, even with
Advanced Data Protection enabled. Apple can remove files, block
accounts, prevent re-registration, and contact law enforcement. It has
not defined “harmful,” explained the screening method, said
whether people review flags, or confirmed whether existing public
links are covered.

 CYBERATTACK ON NORWAY'S AID AGENCY MAY HAVE SWEPT UP ALL USER DATA (2
MINUTE READ) [17]

 Attackers used 27 compromised accounts to enter Norad's Grants
Portal, potentially exposing names and email addresses for all 20,614
registered users, and also took applications and documents from three
foreign organizations.

 CHINESE NATION-STATE THREAT ACTIVITY FALLS SHARPLY IN Q2 AND Q3 2026
(3 MINUTE READ) [18]

 Trellix detected 41.4% less China-aligned nation-state activity from
April to September, but cautioned that the drop may reflect shifts in
targeting or its own visibility rather than less hacking, since PRC
activity still outpaced Russia and Iran, while the US and Turkey
together drew three-quarters of all nation-state detections.

 AWS Security Hub now shows an organization-wide inventory of the
software packages installed across EC2 instances, ECR images, and
Lambda functions, built from Amazon Inspector's SBOMs and queryable
through the API, at no extra cost wherever Inspector is enabled.
