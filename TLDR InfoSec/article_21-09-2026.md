ATTACKS & VULNERABILITIES

 GYAZO BREACH EXPOSES 23.62 MILLION USER RECORDS AND 490 MILLION IMAGE
METADATA RECORDS (3 MINUTE READ) [4]

 Gyazo's upload server flaw let an attacker run commands and access
its database. Exposed data includes 23.62 million user records,
password hashes, session IDs, integration tokens, and 490 million
image metadata records. Leaked image IDs may expose linked captures.
Helpfeel fixed the flaw, blocked access routes, and urged password
changes.

 GOOGLE PIXEL PHONES PWNED IN ZERO-CLICK ATTACKS (2 MINUTE READ) [5]

 Google has fixed CVE-2026-58704, an actively exploited Pixel modem
authorization flaw. Attackers can bypass permission checks and
escalate privileges without user interaction. CISA added it to its
Known Exploited Vulnerabilities catalog and ordered federal agencies
to patch by September 19. Google disclosed limited, targeted
exploitation but provided no attack details and asked users to update
supported Pixel devices immediately.

 FAKE LASTPASS AUTHENTICATOR GITHUB REPOS PUSH NEW RAPUNCEL
INFOSTEALER (2 MINUTE READ) [6]

 Security researchers uncovered a new malware campaign that utilizes
GitHub repos to impersonate LastPass Authenticator and at least 39
other well-known products. The campaign utilizes a legitimate
Microsoft Visual Studio CoreCLR Debugger, which loads a malicious DLL.
The DLL deploys a previously undocumented infostealer and an EDR and
antivirus killer that terminates a hardcoded list of 145 EDR or
antivirus products.

STRATEGIES & TACTICS

 GLM-5.3 DELIVERS OPUS 4.8-LEVEL PERFORMANCE AT A FRACTION OF THE COST
(4 MINUTE READ) [7]

 Semgrep benchmarked the new Grok models and GLM-5.3 on their standard
IDOR vulnerability-finding benchmark. They found that Grok 4.6 Exacto
roughly matched Opus 4.7's F1 score at less than a third of the cost.
GLM-5.3 was able to compete with Opus 4.8 at one seventh of the cost.

 REVERSE ENGINEERING MALWAREBYTES BROWSER GUARD (36 MINUTE READ) [8]

 After the author's legitimate site got flagged as a scam by
Malwarebytes Browser Guard, they took a deep dive into the source code
to identify what caused it. This post walks through the several layers
Browser Guard uses, including bloom filters, heuristic rules, a
malware URL database, a download file classifier, specialized rules
for specific attacks like ClickFix, and remote false-positive checking
using Hubble. The bigger issue, the author noted, is that the
extension ships with a debug interface that can be used to disable
heuristics.

 HOW TO BUILD AN OT SECURITY OPERATING MODEL (10 MINUTE READ) [9]

 An implementation guide breaks an OT security program into six
components, beginning with asset discovery and process context mapping
that tie every device to the operational process it supports.
Availability and process safety outrank confidentiality here, so
access boundaries, monitoring, incident response, and recovery each
require joint sign-off from operations before deployment. Ownership
belongs to a cross-functional executive such as a CISO or VP of
Operations, with NERC CIP and NIST SP 800-82 treated as checkpoints
rather than as the program design itself.

 NATURAL LANGUAGE NMAP (GITHUB REPO) [12]

 Natural language nmap (nmap-nl) is a lightweight, local command-line
inference tool that translates natural language into raw nmap commands
and executes them locally using a locally-hosted, fine-tuned
Gemma-3-270M model.

 TATS (GITHUB REPO) [13]

 Token Analysis and Tracking System (TATS) allows users to track OAuth
2.0, OIDC, and Microsoft Entra ID tokens across captured network
traffic by ingesting Burp Suite XML exports, mitmproxy flow files, or
live Chrome DevTools Protocol streams and serving an interactive web
dashboard.

MISCELLANEOUS

 HACKERS CRACKED A FLOCK CAMERA. HERE IS WHAT WAS INSIDE. (3 MINUTE
READ) [14]

 A removed Flock camera exposed 1.6 million images and records of
50,200 vehicles over 21 days. Unencrypted Android partitions stored a
key for footage encryption, and the device ran about 20 custom apps
and captured bursts of vehicle images. Uploaded records could be
searched by more than 2,000 agencies, including out-of-state users.

 RESEARCHERS USED CLAUDE TO HACK OPENAI (2 MINUTE READ) [15]

 Hacktron AI researchers used Anthropic's security tool to exploit an
OpenAI community-forum configuration flaw. They obtained internal
sign-ons, accessed an employee's ChatGPT account, and reached
GitHub-linked code. OpenAI paid the team $6,500 through its bug bounty
program after disclosure, and OpenAI said it fixed the reported
issues.

 OUR FRAMEWORK FOR REPORTING MODEL MISALIGNMENT (5 MINUTE READ) [16]

 OpenAI released a disclosure process and six incident reports. Cases
include 27 summaries containing prompt injections, use of an exposed
API key, fabricated county data, unauthorized file uploads, repository
writes, and public file-sharing. Reports can be delayed when third
parties or undisclosed vulnerabilities require investigation and
notification.
