ATTACKS & VULNERABILITIES

 HTTPX IS VULNERABLE TO REMOTE CODE EXECUTION VIA OJ OBJECT-MODE JSON
DESERIALIZATION (2 MINUTE READ) [8]

 Version 1.9.0 of the Ruby httpx gem (CVE-2026-129784, CVSS 8.5)
parsed JSON response bodies with Oj in its default object mode when
multi_json was missing, which let a malicious server turn its response
into arbitrary Ruby objects. JFrog showed an attacker could chain
ActiveSupport classes in any Rails app to call Kernel.load on a file
they had first uploaded through an ordinary multipart POST and then
reached via /dev/fd/N, giving code execution as the app user without
any user interaction. Defenders should upgrade to httpx 1.9.1, or else
pass mode: :strict to response.json or keep multi_json installed.

 FRENCH CYBERCRIME UNIT PROBES MASSIVE CYBERATTACK ON LA POSTE
SUBSIDIARY (3 MINUTE READ) [9]

 French postal subsidiary Maileva disclosed that it was the victim of
a cyberattack that led to the disclosure of data belonging to 22M
people. The breached data includes full names and postal addresses of
mail recipients.

 NEW NOISYTCP VULNERABILITIES LETS ATTACKERS CRASH LINUX SERVERS (2
MINUTE READ) [10]

 Security researcher Hyunwoo Kim discovered an 11-year old Linux
kernel vulnerability that can be used to crash systems running Nginx,
Apache, and SSH servers in default configurations. The vulnerability
stems from a NULL pointer dereference bug in the kernel's TCP
networking system. Unauthenticated attackers can trigger a race
condition using maliciously crafted packets to cause a DoS on a
system.

STRATEGIES & TACTICS

 INSIDE THE LOOP: FIVE AI ATTACK FRAMEWORKS THAT NEVER ASK PERMISSION
(15 MINUTE READ) [11]

 Elastic analyzed five agentic offensive frameworks: ARTEX,
CyberStrikeAI, Cairn, PentAGI, and HexStrike. These tools let an LLM
drive scanners, shells, and cloud CLIs in bursts of two to 25 seconds.
None of them enforce authorization in code, and ARTEX and
CyberStrikeAI switch to new proxies and User-Agents when blocked. GTIG
and Mandiant have already seen four of them in real intrusions, and
Microsoft has linked ARTEX to Storm-0940. Defenders should choose
ahead of time which detections can trigger automatic containment.
Defenders should also pair IP blocks with token and session
revocation, and track how quickly each identity acts and in what order
across sessions rather than relying on framework fingerprints, which
Elastic's own ES|QL hunt only partly addresses.

 SECURE EXCLAVES AND AMBIENT SENSING (14 MINUTE READ) [12]

 Apple introduced Secure Exclaves: isolated runtimes on Apple silicon
that process microphone and camera data separately from the main
operating system. Ambient sensing produces only limited metadata, such
as a recognized person or wake-word detection. Raw audio and video
stay inside the exclave and are discarded after processing. The design
uses a capability-based L4-derived microkernel, the Secure Page Table
Monitor for memory isolation, isolated Neural Engine queues, and
tightly defined Secure IPC interfaces. An Exclave Indicator Controller
verifies that camera or microphone indicators are visible before
active sensor data leaves the boundary. HomeView person recognition
and “Hey Siri” on iPhone 18 Pro use this flow.

 RACE AGAINST THE (MAC)HINE: LOCAL PRIVILEGE ESCALATION IN MICROSOFT
DEFENDER FOR MACOS (15 MINUTE READ) [13]

 Microsoft Defender for macOS checked IPC clients by looking up a
connecting process's PID and then its current executable path, so an
unprivileged process could connect and then re-exec into a
Microsoft-signed binary to pass the check and send arbitrary commands
to the root daemon. A diagnostics command with no authorization check
followed hardlinks to read any file as root (CVE-2026-50657), and a
quarantine restore request that left out its authorization blob
skipped authorization entirely, which let an attacker write a cron
entry to /etc/crontab and get a root shell (CVE-2026-50658). Microsoft
fixed both in July 2026 Patch Tuesday. The research shows that bugs
patched in Defender for Windows reappeared on macOS because peer
checks should use audit tokens or XPC code-signing requirements and
should block hardlinks, not just symlinks.

 BASHKIT (GITHUB REPO) [15]

 Bashkit is a Rust sandbox that runs bash entirely in-process for LLM
agents, with all 167 commands rewritten in Rust and no fork/exec, host
filesystem access, or network access unless enabled. Its analyze() API
lists the commands, arguments, and file writes in a script before it
runs, so hosts can decide when to ask for approval, and it flags
scripts it can't fully resolve, such as ones using eval or $cmd. It's
a good fit for agent tool harnesses because it has per-domain network
allowlists, resource limits, VFS snapshotting, and Python and Node
bindings.

 DETECTIFY'S AGENTIC TOOLING LETS AI AGENTS TEST SUSPECTED FLAWS IN
RUNNING APPLICATIONS (3 MINUTE READ) [16]

 Detectify launched Agentic Tooling, which lets a team's own AI agents
test whether a suspected vulnerability can actually be exploited in a
running application, and logs every request, payload, and response in
an append-only Security Ledger written by Detectify rather than the
agent. It runs in the customer's environment and connects to agents
through MCP or a CLI, using Detectify's crowdsourced payloads, attack
surface data, and Alfred CVE engine. It's aimed at DevSecOps teams
dealing with AI-generated SAST findings, which Detectify says are
about 80% noise, though that figure comes from Detectify itself and
the tool is only available on request.

 AI/ML DFIR DETECTION PACK (GITHUB REPO) [17]

 A vendor-neutral collection of Sigma, YARA, and Suricata rules for
detecting compromise of LLM applications, MCP servers, ML supply
chains, AI infrastructure, AI-powered insider threats, and RAG/vector
database attacks.

MISCELLANEOUS

 OUR FIRST PHASE OF EMBEDDED ASSESSMENTS (11 MINUTE READ) [18]

 OpenAI has signed agreements with Apollo Research, METR, Transluce,
and Goodfire for embedded assessments. The assessors receive access to
selected model checkpoints, source code, training and evaluation data,
monitoring systems, documentation, and staff. Apollo will test whether
models could covertly act against developer intent and whether
safeguards detect it. METR will examine misaligned behavior in
OpenAI's largest reinforcement-learning run and assess monitoring.
Transluce will review post-training alignment evaluations, and
Goodfire will analyze model internals for training monitoring,
debugging, and alignment. Assessors work under agreed scopes, on-site
security controls, conflict disclosures, and publication rules. OpenAI
may redact confidential material and request disclosure delays for
security or safety remediation.

 WHO RUNS THE RANSOMWARE GROUP QILIN? (4 MINUTE READ) [19]

 Qilin is an active Ransomware-as-a-Service operation, claiming 365
victim organizations in three months. Its affiliates receive at least
80% of extortion payments and use double extortion: data theft plus
encryption. Reporting links the administrator “Haise” to older
identities “Rjun” and “Alexbigboss44,” then to Aleksey
Mikhailovich Yakovtsev of St. Petersburg. The attribution relies on
forum records, breached Gosuslugi data, Telegram identifiers, email
links, and flight records.

 TELEGRAM RESTRICTS BOT WIDGETS AMIDST SECURITY DISPUTE (2 MINUTE
READ) [20]

 Telegram has blocked bots from sending HTML widgets in both public
and private chats. HTML widgets are interactive tools that run inside
messages and present security issues. Telegram has not confirmed the
minimum safe version but has urged users to update their Telegram
apps.
