ATTACKS & VULNERABILITIES

 WORDFENCE ARGUS IDENTIFIES TWO CRITICAL UNAUTHENTICATED VULNERABILITY
CHAINS LEADING TO REMOTE CODE EXECUTION IN THE EVENTS CALENDAR PLUGIN
(6 MINUTE READ) [5]

 Two CVSS 9.8 flaws affect The Events Calendar up to version 6.17.4.
Anonymous attackers can submit crafted Gutenberg markup in event
comments and then trigger execution via pending-comment previews. One
chain executes OS commands via PHP object injection, while the other
resets an administrator password using wp_update_user. Update to
6.17.4.1. Exploitation requires comments enabled on event pages.

 HACKERS PUBLISH THOUSANDS OF DRIVERS' DATA AFTER BREACHING FLORIDA
MOTOR VEHICLE DATABASE (1 MINUTE READ) [6]

 ShinyHunters published hundreds of thousands of files stolen from
Florida's DAVID vehicle and driver database after alleging the state
agency refused to pay a ransom. FLHSMV confirmed that attackers used
police credentials stored on a personal device. Leaked ownership
records include names, addresses, buyer and seller details, and VINs.
Some files also contain Social Security numbers, passports, and
immigration documents.

 FIRST AGENTIC AI DATA BREACH REPORTED TO SPANISH REGULATOR (2 MINUTE
READ) [7]

 Spain's AEPD received a breach notification involving an automated
system. It logged in, searched for flaws, changed personal data, and
accessed invoices. Possible causes include a jailbroken model, an
exposed test environment, or an unauthorized penetration-testing
setup. The regulator calls for faster detection, containment, and
response, plus stronger protection for digital identities and
credentials.

STRATEGIES & TACTICS

 AGENTIC SELF-MODIFICATION IN OPEN-WEIGHTS SYSTEMS (9 MINUTE READ) [8]


 A coding agent fixed a failing query application by fine-tuning its
shared Qwen model. It then merged the update into the default
checkpoint, altering later agent and application instances, with
held-out query accuracy rising from 0/20 to 20/20. The tuned model
reproduced a synthetic API key, email, and address from training data
and removed a trained refusal policy. Training tools, weight access,
and deployment access increased modification attempts so as to track
model lineage, retain training data and evaluations, and require
approval before deployment.

 BRING YOUR OWN EDR: HOW TO TURN A COMMERCIAL EDR INTO A TROJAN HORSE
(10 MINUTE READ) [9]

 Researchers from Akamai discovered that attackers with admin access
on a Windows device could abuse SentinelOne's EDR solution to dump
protected processes, pivot to Microsoft Defender, and run malicious
code in the Protected Process Light (PPL) context. They then extended
this research by demonstrating how they could temporarily disable the
EDR, move code into the EDR's protected files, run malicious code, and
then re-enable the EDR, which would then protect the malicious code as
part of its local files. Additionally, they found that cloud
communication can be disabled by modifying the local DNS
configuration.

 HOW TO EVALUATE LLMS BEFORE PRODUCTION (12 MINUTE READ) [10]

 When evaluating an LLM-based system to reduce false positives in
GitHub secrets scanning, the team faced issues that made benchmarks
unrepresentative of production workloads and prevented them from
properly evaluating model performance. To combat this problem, the
team at GitHub created an LLM evaluation framework. First, teams
should define the product decision that the system should support;
then teams should make sure that offline experiments use a
representative dataset and have only one clearly defined variable;
error analysis and LLM-as-judge systems can be used to guide human
analysts towards interesting aspects of the evaluation; and then
finally the experiment can be promoted to production.

MISCELLANEOUS

 $1 MILLION SANDBOX CHALLENGE UNCOVERS LINUX KERNEL FLAWS (3 MINUTE
READ) [14]

 Vercel's two-week sandbox bounty received 1,285 reports and validated
92 findings, including one critical issue. No report accessed customer
data. A leading submission chained two Linux networking flaws: one
leaked host-kernel memory and another deterministically crashed the
host. Patches remain under private review, and CVEs are pending.

 CISCO WARNS OF MAX SEVERITY ISE ZERO-DAY EXPLOITED IN ATTACKS (2
MINUTE READ) [15]

 Cisco released security updates to address vulnerabilities in its
Identity Services Engine, including a maximum-severity authentication
bypass. An attacker could exploit the vulnerability to bypass
authentication in the web-based management interface by sending a
crafted request to affected endpoints. The Cisco PSIRT has identified
this vulnerability as actively exploited and urges customers to update
immediately.

 CISA PROMOTES A FRESH WAY TO DETER CYBERATTACKERS: LIE TO THEM (2
MINUTE READ) [16]

 CISA has published its first-ever guidance on setting up honeypot
systems, accounts, and data to distract potential attackers and
ultimately help discover them. The guidance comes from internal
discussions with CISA threat hunters and pentesters who found that
cyber decoys can be a low-cost, high-fidelity way to detect attackers
who have gained access to a network.
