ATTACKS & VULNERABILITIES

 CRITICAL APACHE ROLLER RCE FLAW UNDER ACTIVE EXPLOITATION, NO
AUTHENTICATION REQUIRED (2 MINUTE READ) [8]

 Apache Roller versions 4.0.0 through 6.1.4 have an unauthenticated
deserialization flaw in the XML-RPC endpoint that allows remote
attackers to execute arbitrary code. It is being actively exploited.
Users should upgrade to Roller 6.1.6 or later. If patching is delayed,
set enabledForExtensions to false in WEB-INF/web.xml, remove the
/roller-services/xmlrpc servlet mapping, and restart Roller. Disabling
XML-RPC in the admin UI does not prevent exploitation on older
versions.

 RUBY2SSHELL (2 MINUTE READ) [9]

 Researchers from Veria discovered a one-byte heap overflow
vulnerability in Ruby. The vulnerability stems from a bug where Ruby's
single-byte encodings upcase ß as SS, but the loop only checks for
one. GitHub Enterprise Server, GitLab, and other popular software are
affected.

 PHP FIXES 7 CRITICAL FLAWS, INCLUDING BUGS THAT COULD ALLOW REMOTE
CODE EXECUTION (3 MINUTE READ) [10]

 Following a preemptive notice, the PHP Foundation released a security
advisory and updates to fix seven critical vulnerabilities. Depthfirst
codenamed one of the vulnerabilities phpAfterShell and developed a PoC
that demonstrated how it can be exploited to create an arbitrary
deserialization primitive which, when chained with another
deserialization-to-RCE vulnerability, can lead to arbitrary code
execution. The vulnerability affects any application that runs an
affected PHP version with file-based sessions.

STRATEGIES & TACTICS

 EGGSTREME MALWARE: REBUILT UNDER SCRUTINY (9 MINUTE READ) [11]

 Bitdefender reports that the EggStreme operators rebuilt Fuel,
Loader, and Agent after its September 2025 disclosure. Fuel now uses
AES-256-CBC encryption for its configuration. Loader payloads use RC5
or custom CBC ciphers. Agent traffic moved from gRPC to raw TCP over
mutual TLS, with AES-256-CBC added. New commands enumerate Active
Directory users, groups, and servers, run WMI with supplied
credentials, impersonate user tokens, load .NET assemblies, and run
PowerShell in memory. Some builds listen on TCP 5060 and add a
firewall rule named “Core Networking - SIP.” The operators moved
toward campaign-specific certificate authorities. Bitdefender assesses
with high confidence that Philippine government organizations remain
targets, with multiple victims; it assesses Taiwan targeting at low to
medium confidence.

 SECURITY LOGGING IN CLOUD ENVIRONMENTS - KUBERNETES (11 MINUTE READ)
[12]

 Marco Lancini outlines the various log sources that are available for
Kubernetes environments and their uses. Lancini also highlights blind
spots such as events from on the node, API events that are sent
directly to the kubelet instead of via the API server, and events from
within a kubetctl exec shell. The post concludes by walking through a
practical setup.

MISCELLANEOUS

 MUSE PRIVACY INVASIONS ARE FREAKING OUT META STAFFERS, INTERNAL CHATS
SHOW (4 MINUTE READ) [17]

 Internal Meta chats show staff worried Muse accessed encrypted Signal
messages, mixed conversations across accounts, and produced
unsolicited outputs. One tester said Muse enrolled them in an
$888-per-month insurance plan. Reuters found Muse could read Signal
messages on Android through setup permissions and use macOS
accessibility tools to retrieve messages. Meta calls the account-mix
reports hallucinations and says the bug is fixed.

 BRITISH HACKERS FACE PRISON FOR GTA 6 DATA BREACH AND CRYPTO THEFTS
(1 MINUTE READ) [18]

 Tyler Buchanan received six years in a US court for a phishing scheme
that stole at least $11 million in cryptocurrency from dozens of
companies. Attackers impersonated IT helpdesks, obtained employee
credentials, and accessed corporate systems. Arion Kurtaj admitted to
attacks including stealing and extorting Rockstar Games and leaking
GTA VI footage. Both belonged to overlapping groups known as 0ktapus,
Lapsus$, and Scattered Spider, which targeted Coinbase, DoorDash,
Mailchimp, and Nvidia.

 RAKUTEN SECURITIES WARNS OF DATA LEAK FOR 4.47M ACCOUNTS (2 MINUTE
READ) [19]

 Japanese online brokerage Rakuten Securities says customer data for
approximately 4.47M accounts may have leaked following unauthorized
access. The breached data includes users' annual income, financial
assets, means, dates of birth, employers, and financial products.
Login IDs and account-identifying codes may also have been leaked for
11.25M accounts.

 TENS OF THOUSANDS OF UK FRIDGES SECURED FROM HACKERS IN SECRET
NATIONWIDE OPERATION (4 MINUTE READ) [21]

 Weak-password flaws in Resource Data Management (RDM) refrigeration
controllers, the most widely used in the UK, exposed tens of thousands
of supermarket and warehouse fridges to the kind of attacks that
spoiled food across Europe this year, which led the NCSC, Pen Test
Partners, and industry IT teams to quietly pull thousands of devices
off the internet before RDM shipped its first patches.
