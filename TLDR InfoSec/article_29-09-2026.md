ATTACKS & VULNERABILITIES

 CISA SAYS ATTACKERS ARE EXPLOITING TWO CRITICAL CITRIX NETSCALER
FLAWS GLOBALLY (2 MINUTE READ) [8]

 CISA added CVE-2026-88771 and CVE-2026-88772 to its KEV catalog after
confirming global exploitation. Both have CVSS scores of 9.5. The
flaws enable unauthenticated command execution, remote code execution,
or denial of service. CVE-2026-88772 requires DTLS, which VPN virtual
servers enable by default. Administrators should patch, inspect for
compromise, isolate affected appliances, revoke access, rotate
secrets, and investigate connected systems.

 BOK FACES SCRUTINY OVER CYBERSECURITY AFTER STAFF DATA BREACH (2
MINUTE READ) [9]

 The Bank of Korea (BOK) is facing scrutiny over its cybersecurity
program following a data breach earlier this year. The breach occurred
in May and June after attackers accessed a GitHub system used by a
contractor for an online training program. The exposed data included
employees' names, email addresses, phone numbers, positions, duties,
and passwords for 186 employees.

 ELEMENTOR WORDPRESS FLAW LETS ATTACKERS CREATE ADMIN ACCOUNTS (2
MINUTE READ) [10]

 Security firm Patchstack warns users of the Elementor Website Builder
plugin for WordPress about a new CSRF vulnerability that could allow
unauthenticated attackers to create admin accounts. The vulnerability
is a one-click attack that requires an authenticated admin to click a
link that sends a malicious REST API request to create the account.

STRATEGIES & TACTICS

 CONTAINERS ARE NO LONGER A SECURITY BOUNDARY (6 MINUTE READ) [11]

 The traditional view of containers as a strong security and isolation
mechanism is being eroded by the plethora of kernel vulnerabilities
being uncovered. This article explains how a recent vulnerability in
the AF_UNIX subsystem can be leveraged by attackers for container
escapes. The authors recommend moving untrusted workloads to MicroVMs
like Firecracker or Kata Containers for untrusted workloads.

 POLINRIDER IS A/B TESTING ITS WAY PAST YOUR DETECTIONS (11 MINUTE
READ) [12]

 DPRK's PolinRider malware spread through GitHub organizations by
force-pushing rewritten commits from infected developers' machines,
planting VS Code folderOpen tasks that run an obfuscated JavaScript
payload disguised as fa-solid-400/500/900.woff2 and, since September
28, fa-solid-300.llf. OpenSourceMalware traced 853 force-pushes across
three Binary-Mindz repos and found variants with different paths,
obfuscators, and C2-reported build markers running in parallel, which
it reads as deliberate A/B testing, while copied author dates and
reused commit messages quietly reverted three cleanup attempts.
Defenders should flag fake fonts by file content rather than name,
scan every branch through bare clones, audit force-push activity logs,
and enforce force-push blocking and signed commits on all branches.

 FROM EXPOSURE TO LOCKDOWN: HOW AWS NEUTRALIZES COMPROMISED IAM
CREDENTIALS THROUGH MANAGED POLICIES (15 MINUTE READ) [13]

 AWS automatically attaches the AWSCompromisedKeyQuarantineV3 managed
policy to an exposed IAM user within 10 seconds of a public GitHub
push, with the CloudTrail AttachUserPolicy event misleadingly
attributed to the victim's IAM user rather than to AWS automation.
Each policy version tracked real-world attack evolution, with
permissions added to block Lambda-based cryptomining, S3 data deletion
for extortion, and Bedrock API abuse after Permiso's research exposed
unauthorized InvokeModel calls. Security teams should alert on
unexpected AttachUserPolicy events in CloudTrail, treat the quarantine
event as confirmation of active key exposure rather than as
resolution, and rotate all affected credentials before removing the
policy.

MISCELLANEOUS

 SENDER SPOOFING IN PROTON MAIL VIA DISPLAY-NAME HOMOGRAPH (3 MINUTE
READ) [18]

 Proton Mail's web interface can show a forged sender that looks
identical to a real one. The attacker sets a display name containing
an address-shaped string like sundar@gmaiI[.]com where the capital I
matches lowercase l in the default UI font. Messages from domains
without DMARC arrive in the inbox with no authentication banner, even
when SPF fails. A Reply-To header can route responses to an attacker's
address without showing it unless the user expands headers, and the
spoofed sender also appears unchanged in macOS desktop notifications,
outside the app interface. The issue was reported in February 2025,
confirmed and bounty-awarded in April 2025, and can still be
reproduced as of September 2026.

 GOOGLE TO CRITICAL INFRA ORGS: OUR AI SCANNERS WON'T BE EVIL, PROMISE
(3 MINUTE READ) [19]

 Google and Wiz launched Scan for Good using Gemini 3.8 Flash Cyber
and Red Agent with authorized scans targeting public websites, APIs,
and applications, while human researchers validate findings and handle
disclosure. Red Agent found a GitHub Actions injection flaw in
Snowflake's connector, allowing command execution. Other cases exposed
8.8 million files, hospital systems, elderly residents' data, and
railway administrator sessions.

 HOUSE OF APPLE 2 ON MODERN GLIBC (10 MINUTE READ) [20]

 This walkthrough breaks down House of Apple 2, a glibc FSOP technique
that bypasses the vtable validation added in newer glibc. It points a
FILE structure's vtable to legitimate wide-character stream code,
which then dispatches to a second vtable that glibc does not
range-check. Step by step in GDB, the author turns that unchecked
indirect call into an arbitrary call, pivots the stack, and runs a ROP
chain to a shell. The technique still works cleanly on glibc 2.43
(Ubuntu 26.04 and Fedora 44). Exact offsets and gadgets vary between
builds, but the underlying control-flow trick remains the same.
