 NOW GENERALLY AVAILABLE: GKE DYNAMIC SLICING FOR HIGHER RESILIENCE,
AND EFFICIENCY FOR TPUS (6 MINUTE READ) [6]

 Google Kubernetes Engine dynamic slicing is now generally available
for TPUs. It separates slice formation from nodepool provisioning,
cutting AI workload startup times by up to 5x and recovery times by
4.5x.

 SEE WHAT YOUR ARGO CD APPLICATIONS COST (10 MINUTE READ) [7]

 Cost Intelligence for Argo CD is an open-source extension that shows
each application's cost in a UI tab, using the previous 24 hours of
OpenCost data after each sync. It requires Argo CD 3.4 to 3.6 and
OpenCost 1.121.1 or newer.

 AWS NITRO SANDBOXES: HARDWARE-ENFORCED WORKLOAD ISOLATION ON AMAZON
EKS (12 MINUTE READ) [8]

 AWS Nitro Sandboxes provides hardware-enforced workload isolation for
Amazon EKS pods by running each one inside its own lightweight virtual
machine. The feature allows users to enable strong security boundaries
with a single line in the pod spec without changing container images
or deployment pipelines. It offers isolated mode for standard
protection and confidential mode for cryptographic attestation.

OPINIONS & TUTORIALS

 KUBERNETES GAVE AI AGENTS A PLACE TO RUN, BUT NOT A WAY TO RECOVER (7
MINUTE READ) [9]

 Kubernetes can restore an AI agent's environment but cannot record
which steps finished, so restarted agents may repeat actions such as
payments. The author argues for durable execution that logs each step,
citing Dapr's workflow engine as an option.

 7 PRODUCTION HABITS WE LEARNED AT WIX. THE HARD WAY (10 MINUTE READ)
[10]

 A Wix engineering lead details seven habits for reliable production
systems, learned from eight years of operating the editor server team.
The list includes using the Five Whys method to find root causes,
running post-mortems without blame, and conducting team-wide on-call
handovers. He emphasizes leaving the system better than you found it
by fixing one small thing per shift.

 AI agents now write and execute code no human reviews first. AWS

 ASTRYX (GITHUB REPO) [14]

 Astryx is an open-source design system with over 150 accessible
components. It grew inside Meta over eight years to power more than
13,000 apps. The system is built on React 19 and StyleX, with a CLI
designed for both human developers and AI assistants.

 HA-MCP (GITHUB REPO) [15]

 HA-MCP lets users configure and automate Home Assistant with AI
assistants like Claude and ChatGPT. The recommended integration
installs directly through HACS or the built-in Marketplace on Home
Assistant 2026.11+, runs in-process, and works across all installation
types.

 Model Context Protocol servers lack built-in authentication, rate

 CLOUDNATIVEPG BECOMES A CNCF INCUBATING PROJECT (5 MINUTE READ) [17]

 CloudNativePG has moved from CNCF Sandbox to Incubation. The operator
runs highly available PostgreSQL on Kubernetes and manages pods
directly rather than through StatefulSets, handling failover, rolling
updates, backups, and point-in-time recovery.
