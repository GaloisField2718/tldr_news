 HOW WOULD YOU CONTAIN A PRIVILEGED BUILD ON A SHARED CI RUNNER?
(SPONSOR) [4]

 Container builds and fork pull requests run with elevated privileges
on nodes shared with
every other job. AWS Nitro Sandboxes contains them instead.

🔒Isolate every job: each runner pod or ECS task runs in its own
lightweight VM, managed by
the Nitro Hypervisor, so a privileged build never reaches the host

⚡Keep your pipeline intact: a runtime class on EKS [5] or an
isolation mode on ECS [6] turns it
on, with no image or Helm chart changes

📦 Share instances you already run: pack isolated jobs onto your EC2
instance at no additional
charge

NEWS & TRENDS

 GOOGLE DONATES AGENT SUBSTRATE AND GVISOR TO THE CNCF TO SECURE AI
AGENTS AT SCALE (3 MINUTE READ) [8]

 Google is donating Agent Substrate and gVisor to the CNCF to help run
AI agents securely at scale. Agent Substrate separates agent state
from compute in pre-warmed Kubernetes pools, which Google says lets
agents resume in under 500 milliseconds.

 INTRODUCING IN-PLACE MIGRATION TO GKE DATAPLANE V2 (3 MINUTE READ)
[9]

 Google Cloud released in-place migration to GKE Dataplane V2 in
preview for VPC native clusters on GKE 1.35 or later. Teams can move
from Dataplane V1 without building a parallel cluster, and they can
roll back before finalization.

 KARPENTER V1.15: GPU-AWARE PROVISIONING, SMARTER NODE REPAIR, AND
MORE (8 MINUTE READ) [10]

 Karpenter v1.15 adds Dynamic Resource Allocation support to factor
GPU topology and networking into provisioning decisions. It classifies
node repair as a voluntary disruption that respects Pod Disruption
Budgets. The update also introduces a pod deletion cost controller and
CEL support for dynamic kubelet configurations.

OPINIONS & TUTORIALS

 SHIPPING 100+ PRS TO PRODUCTION IN A WEEK (16 MINUTE READ) [11]

 An engineering lead shipped 170 pull requests in a single week by
optimizing development loops with AI tooling. Key steps included
modernizing CI/CD, moving issue management from Jira to Linear, and
building a cloud harness to run orchestrated agents. These changes
addressed bottlenecks like slow approvals and inaccurate documentation
in the knowledge base.

 BUILDING PLANETSCALE WITH INSIGHTS AGENT (6 MINUTE READ) [12]

 PlanetScale's database optimization agent added an index that made a
production query slower because its SQL summary hid a 645-element IN
list. Removing that list and filtering the small result set in Ruby
cut average query time from 28.5 milliseconds to 1.95 milliseconds.
Another change reordered a feature flag check, reducing database
lookups from 28.7 million to 8.3 million per day.

 AN AI OBSERVABILITY FRAMEWORK FOR YOUR AGENTIC APPLICATIONS (13
MINUTE READ) [14]

 AWS authors propose an observability framework for agentic
applications that crosses four layers with three concerns:
reliability, cost, and security. They recommend OpenTelemetry GenAI
conventions and evaluation gates, arguing that agents rarely fail with
errors and often return confident wrong answers.

 THE LAYER OF YOUR PLATFORM NOBODY OWNS (7 MINUTE READ) [15]

 Platform teams standardize nearly everything except the operating
system under their clusters. Developers should use an immutable,
API-managed OS such as Talos Linux, with declarative configuration and
atomic upgrades, at the cost of losing interactive shell access.

2028 (8 MINUTE READ) [16]

commitments in the US as of November.
