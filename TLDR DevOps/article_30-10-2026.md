NEWS & TRENDS

 MATCH MONITORING DEPTH TO WORKLOAD NEEDS WITH INFRASTRUCTURE BASIC (4
MINUTE READ) [7]

 Datadog describes Infrastructure Basic, a lightweight tier that
collects core host metrics and selected process status for
lower-priority workloads. It uses the same Agent in basic mode and can
run alongside Pro or Enterprise tiers in one organization.

 ANNOUNCING THE WORKLOAD CONFORMANCE WORKING GROUP (4 MINUTE READ) [8]


 The Kubernetes community launched a Workload Conformance Working
Group to write a shared specification and tests for how workloads
behave at runtime. The group aims for a stable first specification
within two to three release cycles and seeks input from operators and
application maintainers.

 SUPABASE COMPUTE: RUN YOUR AGENTS INSIDE YOUR PROJECT (3 MINUTE READ)
[9]

 Supabase launched Supabase Compute in private alpha to run agents,
background jobs, and APIs directly alongside user data. The offering
currently supports the us-west-2 region. Dreambase reported query
latency dropped from 65 ms in another region to a median of 2.9 ms
after moving a data agent to the new platform.

OPINIONS & TUTORIALS

 ONE HUB, 34 CLUSTERS: LESSONS FROM A GITOPS CONTROL PLANE AT SCALE (5
MINUTE READ) [10]

 Nitish Mane describes an Argo CD hub that managed 34 clusters across
22 AWS accounts and one Oracle Cloud tenancy from a repository of 174
Helm charts. Per-cluster contracts, CI manifest diffs, and no-prune
settings kept changes safe, and onboarding reportedly fell from 4 days
to 1.7 hours.

 HOW TO INTEGRATE TERRAFORM WITH BACKSTAGE FOR SELF-SERVICE (17 MINUTE
READ) [11]

 Mattias Fjellström explains how to connect Terraform with Backstage
through the software catalog, software templates that open pull
requests, and the Spacelift plugin. Backstage collects requests but
does not run Terraform, so version control remains the source of
truth.

 1M DURABLE WORKFLOWS PER SECOND ON POSTGRES (6 MINUTE READ) [12]

 DBOS scaled a benchmark of no-op durable workflows from 20,000 per
second on one Postgres server to one million across 50 shards using
PgDog. The main obstacle was a contention feedback loop that collapsed
throughput when a shard slowed down. Advisory locks limited concurrent
dequeuers and restored stable scaling.

RESOURCES & TOOLS

 MACRO (GITHUB REPO) [13]

 Macro is a unified workspace that combines email, chat, docs, tasks,
agents, and CRM into a single interface with shared team memory. It
links all objects, such as emails and tasks, via a bidirectional graph
so AI agents and users can search across tools without switching
contexts.

 DEEPTUTOR (GITHUB REPO) [14]

 DeepTutor provides lifelong personalized tutoring with features like
folder-based learning workspaces, daily practice, and persistent usage
accounting. The open source platform includes over 100 CLI apps the
tutor can run, supports OpenAI Codex OAuth for sign-in, and offers MCP
Services stores on a per-account basis.

 THE AI OBSERVABILITY RACE WILL BE WON ON INTEROPERABILITY (5 MINUTE
READ) [15]

 OpenTelemetry offers a common method to capture and describe AI
behavior using shared conventions for conversations and messages. This
standardization helps teams compare models, reduce duplicate
integration work, and measure cost per outcome rather than just token
counts.

 THE PWN REQUEST RECKONING: WHAT STILL WORKS AGAINST GITHUB ACTIONS (9
MINUTE READ) [16]

 GitHub's upcoming platform changes in 2026 will make
pull_request_target attacks harder, but gaps remain involving outdated
checkout versions, script injection, and unprotected triggers like
issue_comment. Pinning actions to old SHA values predating the July
2026 backport release bypasses the new checkout protections entirely.
The default policy also does not apply to private repositories or
workflow_run events.
