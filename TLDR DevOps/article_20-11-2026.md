NEWS & TRENDS

 CVE-2026-114938 OPENJDK RCE (JAVA4SHELL): EVERYTHING YOU NEED TO KNOW
(5 MINUTE READ) [6]

 CVE-2026-114938 is a critical 9.2 severity RCE vulnerability in
OpenJDK's AVX-512 Base64 decoding that causes heap memory corruption.
It affects OpenJDK 17.0.6 and later on x86-64 hardware and enables
pre-auth RCE in applications like Jenkins, Confluence, and Tomcat.
Users should upgrade OpenJDK or disable Base64 intrinsics immediately.


 INTRODUCING MTLS FOR NETWORK LOAD BALANCER (10 MINUTE READ) [7]

 AWS Network Load Balancer can now authenticate clients using mutual
TLS, offloading certificate validation from backend services. This
walkthrough configures a trust store, revocation checks, and
certificate identity filters, then tests connections from trusted and
untrusted clients.

 THE 2026 FLAKY-TEST TOOLING LANDSCAPE: AN HONEST COMPARISON (12
MINUTE READ) [8]

 Harness compares seven flaky-test tools and argues vendors differ
more in quarantine, recovery, and adoption cost than in detection. It
cites an IEEE study of 8.8 billion test executions where 9.8% to 16.3%
of failed runs involved missed flaky failures.

 IS AI JUST ANOTHER THIRD-PARTY DEPENDENCY? YES, RIGHT UP UNTIL IT
ISN'T (7 MINUTE READ) [9]

 incident.io asks whether AI models should be managed like any other
third-party dependency, and two engineers answer mostly yes. SLAs,
SLOs, and observability still apply, but measuring model quality and
debugging are harder, and deterministic code sometimes lowers risk.

 Agent Sandbox gives Kubernetes a standard way to run and manage AI

 OPENVINO (GITHUB REPO) [12]

 OpenVINO is an open source toolkit for optimizing and deploying AI
inference across CPUs, GPUs, and NPUs. It boosts deep learning
performance for computer vision and generative AI without requiring
original frameworks for deployment.

 OPENSRE (GITHUB REPO) [13]

 OpenSRE is an open-source CLI agent that automates CI/CD reliability
by investigating failed runs, tracing causes, and pushing fixes for
review. It runs self-hosted with your own models to keep data private.
The tool separates CI-caused failures from code-caused ones to ensure
engineers fix the right problem.

 LAST YEAR WE BUILT MEGAKERNELS. THIS YEAR WE DELETED THEM: THE ROAD
TO TOGETHER COMPILER (21 MINUTE READ) [14]

 Together AI built Together Compiler, which uses AI agents to rewrite
and fuse GPU kernels and beats its hand-written megakernels by about
28% on B200, at 2,118 versus 1,649 tokens per second on Llama 3.2 1B.
CUDA Graphs on default Inductor kernels already recovered about 98% of
megakernel performance.

 TRAFFIC MIX MATTERS (3 MINUTE READ) [15]

 Microsoft's preliminary report on last week's M365 outage blames a
failure to detect the issue on the specific traffic mix and SKUs used
in testing labs. Throughput can vary by multiple orders of magnitude
depending on key skew, meaning load tests must match production
traffic patterns to be valid.

 WAIT FOR PULL REQUEST EVENTS WITH GITHUB CLI (1 MINUTE READ) [16]

 GitHub CLI's new gh event commands let scripts wait for reviews, pull
request changes, and completed check suites instead of repeatedly
polling. The commands require CLI 2.105.0 or later and access to the
Event Streams preview through its waitlist.
