NEWS & TRENDS

 OPENAI AND CISCO INTRODUCE SHIRUDO (5 MINUTE READ) [6]

 Shirudo is an open-source runtime that protects running Linux systems
without requiring patches or restarts. It uses eBPF to block
vulnerable code paths, allowing services to continue operating while
security teams apply temporary safeguards. OpenAI and Cisco released
Shirudo under a BSD 2-Clause license.

 KUBERNETES V1.38 SNEAK PEEK (5 MINUTE READ) [7]

 Kubernetes v1.38 is expected to change how kubelets obtain their
cgroup driver, requiring container runtimes to report it through CRI
by default. The release also removes kubectl's WebSocket opt-out
environment variables and drops the deprecated name alias from stable
kuberc credential-plugin allowlists. Operators should check runtime
compatibility and continue migrating nodes to cgroup v2 ahead of its
eventual requirement.

OPINIONS & TUTORIALS

 HOLDING THE DOOR FOR AGENTS (8 MINUTE READ) [8]

 Agents now perform at least 55% of deployments to Fly.io, and bots
recently surpassed humans in web traffic for the first time. Fly.io
now supports auth.md for agent signup and the Machine Payments
Protocol, which lets agents top up accounts without human
intervention.

 WHY YOU SHOULDN'T DO APPLICATION-LEVEL SHARDING (19 MINUTE READ) [9]

 Application-level sharding embeds routing logic in application code,
but creates operational burdens like difficult resharding and
cross-shard queries. The article details how companies like Intercom,
Etsy, and Slack faced complexities including manual data migrations,
reliance on single lookup tables that risked outages, and
underutilized infrastructure to avoid difficult splits.

 PROBING DNS AT CLOUDFLARE (9 MINUTE READ) [10]

 A scheduling bug left DNS record changes unpublished for hours while
Cloudflare's service health checks stayed green. Cloudflare extended
its Flamingo testing framework to continuously update timestamped TXT
records and query authoritative nameservers and 1.1.1.1 from every
data center. These propagation measurements now inform release and
rollback decisions.

 LAST30DAYS-SKILL (GITHUB REPO) [11]

 Last30days-skill is an AI agent that researches topics across Reddit,
X, YouTube, and other platforms to synthesize a summary. It ranks

 SOFKA (GITHUB REPO) [12]

 sofka is a Kubernetes terminal interface written in Rust with
built-in Flux CD and Argo CD actions, custom resource browsing, and
background port forwarding. Its evidence-based incident view explains
unhealthy resources without an AI service, while read-only mode and
configurable guardrails restrict destructive actions.
