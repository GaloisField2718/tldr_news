NEWS & TRENDS

 AWS CONTINUUM FOR CODE VULNERABILITIES IS NOW GENERALLY AVAILABLE (1
MINUTE READ) [6]

 AWS has made Continuum for code vulnerabilities generally available.
It builds a context graph of an AWS environment, tests findings for
exploitability in a sandbox, and opens pull requests with patches.
Teams start in Learn mode and can move to Enforce mode.

 EXPANDING CLAUDE AVAILABILITY AND DEPLOYMENT CHOICE ON GOOGLE CLOUD
(2 MINUTE READ) [7]

 Google Cloud now offers an Anthropic-managed deployment option for
Claude models alongside its Google-managed one. Both provide the same
models on day zero at the same pricing. The Anthropic-managed option
adds immediate access to Claude Platform features such as Managed
Agents.

 BROCCOLI2SHELL: EVERYTHING YOU NEED TO KNOW ABOUT THE CRITICAL BROTLI
DECODER VULNERABILITY (5 MINUTE READ) [8]

 CVE-2026-111497, also known as Broccoli2Shell, is a critical
vulnerability in the Brotli decompression library that allows remote
code execution. The flaw affects Node.js, Bun, and Envoy Proxy. Wiz
data shows 91% of cloud environments have vulnerable resources.
Organizations should apply security updates and rebuild affected
workloads.

OPINIONS & TUTORIALS

 DETECTING AND MITIGATING ZDI-CAN-33367 AND FIVE OTHER LINUX FLAWS (8
MINUTE READ) [9]

 A working root exploit for Linux kernel bug ZDI-CAN-33367 is public
before a CVE or fix is available. TuxCare reproduced the proof of
concept for local privilege escalation on Ubuntu, Debian, and
AlmaLinux. A separate patch for the flaw is reviewed but not merged,
and none of the six disclosed bugs has a CVE ID yet.

 SHARD DESIGN DOESN'T START FROM YOUR TABLES (7 MINUTE READ) [10]

 Neki "shard groups" let users co-locate related tables like customers
and orders on the same physical cluster to keep joins and transactions
local. Reference tables replicate lookup data to every shard, while
global secondary indexes support queries that lack the shard key.

 ORIGIN RANGE REQUESTS: SERVING LARGE FILES WITHOUT RANGE-REQUEST
TUNING (9 MINUTE READ) [11]

 Cloudflare rebuilt range-request caching in Pingora to coordinate
partial downloads across cached data and in-flight origin fetches. The
redesign roughly halved R2's p99 time to first byte and eliminated
customer-managed range sizes, while a follow-up improvement reduced
tiered-cache traffic for R2 and similar workloads by about 6%.

RESOURCES & TOOLS

 HOW THE AWS NITRO SYSTEM DELIVERS CONFIDENTIAL COMPUTING (SPONSOR)
[12]

 Protecting workloads from cloud operator access shouldn't require
work on your part. The AWS Nitro System [12] provides strong isolation
— monitoring, protecting, and verifying instance hardware and
firmware. There is no mechanism for any person, including AWS's most
privileged admins, to access instance memory. Learn more. [12]

 COOLIFY (GITHUB REPO) [13]

 Coolify is an open-source, self-hostable PaaS alternative to Vercel,
Heroku, and Netlify. It allows users to deploy static sites,
databases, and full-stack applications on their own servers. The tool
offers more than 360 one-click services and automatic HTTPS
certificates.

 QUESTDB 10.1: FRESHER DATA, LESS I/O, AND MORE ANALYSIS IN SQL (12
MINUTE READ) [14]

 QuestDB 10.1 adds optional merge-append partitions that reduce
rewriting when late data arrives, with background compaction
reclaiming obsolete rows. On QuestDB's public demo, enabling the
feature reduced rows written per ingested row from about 440 to 8. The
release also adds exact percentiles and SQL subsampling.

 SCALE ISN'T ONE NUMBER: THREE WAYS A KUBERNETES CONTROL PLANE RUNS
OUT OF ROOM (8 MINUTE READ) [15]

 Kubernetes control planes run out of room in three independent ways:
node count, object churn, and resident state. Joe Betz of Google
describes four seams, including storage routing and cache residency,
and a recipe ladder built from stock upstream components. Some seams
still have upstream gaps.

 RAILWAY PRELIMINARY REPORT: OCT 21ST SECURITY INCIDENT (7 MINUTE
READ) [16]

 Railway disclosed a security incident where an attacker accessed
internal systems from October 20 to 22 to target AI provider API keys.
Environment variables for approximately 100,000 workspaces, or 1.85%
of the total, were potentially compromised. Railway revoked
credentials with partner vendors and accelerated a rollout of
single-tenant builder infrastructure.
