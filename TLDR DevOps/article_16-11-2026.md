NEWS & TRENDS

 ANNOUNCING KAGENT 1.0 GA (22 MINUTE READ) [5]

 kagent 1.0 is an enterprise-ready distribution of Agent Substrate for
running AI agents on Kubernetes. The system addresses pod-per-agent
limitations by scheduling agent workloads as "actors" on warm worker
pools, automatically suspending idle actors to free up compute and
restoring them when new requests arrive. Agent Substrate is now a CNCF
project.

 INTRODUCING SPEND MANAGEMENT: SPENDING LIMITS AND ALERTS FOR
CLOUDFLARE (14 MINUTE READ) [6]

 Cloudflare's new Spend Management feature lets pay-as-you-go
customers set spending thresholds and pause activity when limits are
reached to avoid unexpected bills. The beta supports Workers and
Durable Objects and provides near real-time cost monitoring in the
dashboard, CLI, and API.

OPINIONS & TUTORIALS

 THROWING OUT THE PHONEBOOK (10 MINUTE READ) [7]

 Fly.io redesigned its 6PN private network, replacing a synchronized
"phonebook" of hundreds of thousands of routing entries on every host
with a lazy lookup system. The new design stores only 100 to 200
records per host, learning routes on demand when machines initiate
connections. This approach uses VXLAN and standard kernel components
instead of complex eBPF logic, which simplifies debugging and improves
reliability.

 GANG SCHEDULING AND TOPOLOGY-AWARE PLACEMENT FOR AI TRAINING IN
KUBERNETES (18 MINUTE READ) [8]

 Distributed AI training workloads require pods to land on hardware
with the right inter-GPU bandwidth and to be scheduled simultaneously.
Kubernetes' built-in scheduler cannot meet these requirements as it
schedules pods individually. Topology-aware scheduling and gang
scheduling, implemented by Kueue and the Coscheduling plugin, solve
these placement and coordination problems.

RESOURCES & TOOLS

 PUT EVERY SAAS TENANT BEHIND ITS OWN VM BOUNDARY (SPONSOR) [9]

 ISVs often give each customer a dedicated environment just to keep
tenants apart, which wastes capacity. AWS Nitro Sandboxes [10] lets
Amazon EKS and Amazon ECS bin-pack multiple tenants onto shared nodes,
each in a hardware-isolated sandbox with its own kernel. For sensitive
tenants, confidential mode adds attestation that proves data stays
private from operators and AWS. See how it works here [11].

 UPTIME KUMA (GITHUB REPO) [12]

 Uptime Kuma is a self-hosted monitoring tool that tracks uptime for
HTTP(s), TCP, DNS records, and Docker containers. It features a
reactive UI, supports over 90 notification services including Telegram
and Slack, and lets users create multiple status pages.

 AIRGORAH (GITHUB REPO) [13]

 Airgorah is a WiFi security auditing tool that captures traffic,
performs deauthentication attacks, and cracks access point passwords.
It is written in Rust with a GTK4 interface and runs on Linux. The
tool requires a wireless network card that supports monitor mode and
packet injection.

MISCELLANEOUS

 GOOGLE OPEN-SOURCES TPU SYNC FOR KV CACHE AND WEIGHT TRANSFER ON TPUS
(3 MINUTE READ) [14]

 Google Cloud open sourced TPU Sync, a C++ library that moves KV cache
blocks and model weights between TPU memory, host memory, and storage.
It cut median KV transfer latency for Qwen3 235B from several seconds
to about 230 ms.

 HTTPD (CVE-2026-119618): DETECTING HEAP CORRUPTION AND RCE IN APACHE
HTTP SERVER MOD_HTTP2 (11 MINUTE READ) [15]

 Apache fixed CVE-2026-119618, a critical heap corruption flaw in
mod_http2 that can lead to remote code execution, with the release of
HTTP Server 2.4.71 on November 11. The vulnerability affects versions
2.4.55 through 2.4.70, requires no authentication to exploit, and
received a 9.8 severity score from Red Hat. A public proof-of-concept
demonstrates heap corruption, but no remote code execution exploit has
been released.
