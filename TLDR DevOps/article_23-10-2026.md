 CRITICAL PHP RCE VULNERABILITIES: PATCH NOW (CVE-2026-109618,
CVE-2026-109619) (5 MINUTE READ) [7]

 Two critical remote code execution vulnerabilities in PHP, tracked as
CVE-2026-109618 and CVE-2026-109619, were publicly disclosed on
October 21. Proof-of-concept exploit code is available, and the flaws
affect every PHP version from PHP 5 onward. DigitalOcean is
automatically patching WordPress instances on its Cloudways managed
product, but customers running PHP on Droplets or other unmanaged
services must update to PHP 8.2.35, 8.3.36, 8.4.27, or 8.5.12
immediately. There are no patches for PHP 8.1 or earlier.

 SCALING GITOPS WITH RELEASE PROMOTION (4 MINUTE READ) [9]

 Jesse Suen of Akuity describes a fleet of over 200 clusters where
every merge synced everywhere with no gate. He argues sync tools do
not handle release tracking or promotion decisions and recommends
staged promotion that rolls out in waves and halts on failed checks.

 I DON'T TRUST ON DELETE CASCADE (6 MINUTE READ) [10]

 Large cascading deletes can turn a routine schema migration into an
outage by holding locks while new queries queue behind the waiting
migration. Soft deletes followed by bounded background cleanup keep
transactions smaller, with additional pitfalls around unindexed
foreign keys and logical replication.

 BEFORE YOU EVALUATE AN AI SRE, GIVE YOUR EXISTING AGENT CONTEXT (6
MINUTE READ) [14]

 Engineers at Radar tested whether adding context to coding agents
improves Kubernetes diagnostics. When running 50 fault scenarios,
agents with context reached a correct diagnosis within two minutes on
86% of faults, compared to 60% for agents using a standard shell.
Accuracy improved only slightly with context, but the time savings
were significant. The test used Claude Code and Microsoft's SREGym
benchmark on a live Amazon EKS cluster.

 8 EMUDHRA CERTIFICATES ARE COMPROMISED. HERE'S WHAT YOU NEED TO KNOW
(4 MINUTE READ) [15]

 Private keys for eight widely trusted eMudhra intermediate
certificates were compromised on October 19, allowing attackers to
forge certificates for any domain. Cloudflare has patched its CDN,
Zero Trust, and Tunnel products. Customers must update the Cloudflare
One Client and 1.1.1.1 app to specific versions to remain protected.
