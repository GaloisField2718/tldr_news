NEWS & TRENDS

 GHEIST: ATTEMPTED SCALED ABUSE OF STOLEN GITHUB TOKENS STUMBLES (9
MINUTE READ) [7]

 Gheist is an automated campaign that plants secret-dumping workflows
in repositories using stolen GitHub tokens. It has targeted over 850
compromised accounts since September 15. GitHub's recent security
controls blocked the attack in public repositories, but private and
enterprise environments remain vulnerable.

 WHAT TOOK THE INTERNET OFFLINE IN Q3 2026 (8 MINUTE READ) [8]

 Cloudflare Radar recorded 49 Internet disruptions during the third
quarter, including 19 government-directed shutdowns and 14 power
outages. The incidents illustrate dependencies beyond network
redundancy.

OPINIONS & TUTORIALS

 WHY KUBERNETES AUTOSCALERS KEEP FIGHTING EACH OTHER (AND WHY THE
SOLUTION MUST BE AUTONOMOUS) (7 MINUTE READ) [9]

 Nikhil Kurup argues that HPA, VPA, KEDA, and Karpenter mutate the
same workload fields from independent loops, producing four failure
modes, including a VPA and HPA death spiral and GitOps drift
ping-pong. He calls for a unified, predictive autoscaler with
explainable decisions.

 HOW TO BUILD GOLDEN PATHS IN PLATFORM ENGINEERING (19 MINUTE READ)
[10]

 Spacelift defines a golden path as an opinionated, documented,
self-service route for a common task. The guide lists five building
blocks and four rollout phases, with a worked Postgres example on AWS
built as an rds-postgres module using OpenTofu 1.10.3. Production gets
Multi-AZ and deletion protection.

 THE BRIDGE TO AGENT-SCALE GIT INFRASTRUCTURE (8 MINUTE READ) [11]

 GitHub is replacing repository-wide write serialization with
per-reference quorums to overcome cross-region latency during its
Azure migration. Internal tests showed 3–4x higher throughput for
writes to different references, while an object-storage-backed design
allows read capacity to scale independently.

 AGENT-REACH (GITHUB REPO) [14]

 Agent-Reach is an open source CLI tool that lets agents read and
search platforms like Twitter, Reddit, YouTube, GitHub, and Bilibili
without API fees. It handles login-gated sites, video content, and
Chinese platforms to provide structured data for AI agents.

 OPENBOT (GITHUB REPO) [15]

 OpenBot is a local-first desktop workspace for persistent AI
teammates that runs Codex, Claude, Grok, and Gemini with dedicated
workspaces and task queues. It provides a shared desktop channel, file
transfers, and an embedded browser that agents can control. A
development preview is available for macOS, Windows, and Linux.

 BEFORE YOU EXPAND YOUR GPU POOL, MEASURE THE OUTCOME (8 MINUTE READ)
[16]

 Teams should define each workload's outcome and deadline before
expanding a GPU pool. Teams can stagger flexible jobs, load test
sustainable serving capacity, and track cost per verified outcome with
OpenCost before adding GPUs.

 FIXING TOOL-CALL ACCURACY IN VLLM (7 MINUTE READ) [17]

 vLLM 0.31 can achieve 100% tool-call schema accuracy for Kimi and
DeepSeek models through constrained decoding, a technique that
guarantees schema adherence during token generation. This fixes a
reliability issue where vLLM 0.28 produced invalid tool calls 8% of
the time, causing agentic workloads to build up nonsensical context.
