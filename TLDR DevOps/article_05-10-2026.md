 INTRODUCING CLOUDFLARE TRACES: FOLLOW REQUESTS THROUGH OUR ENTIRE
PLATFORM (5 MINUTE READ) [8]

 Cloudflare Traces is now available in open beta, extending automatic
tracing beyond Workers to the rest of the request path. Users can view
security rules, transformations, cache decisions, and origin handling
in one trace without special configuration or plugins. The feature
supports OpenTelemetry and enables users to control sampling rates or
trace 100% of specific traffic using Trace Rules.

OPINIONS & TUTORIALS

 CLOSED-LOOP INCIDENT RESPONSE: CONNECT AWS DEVOPS AGENT TO OPENSEARCH
(9 MINUTE READ) [9]

 A new AWS guide explains how to connect AWS DevOps Agent to Amazon
OpenSearch Service using the Model Context Protocol (MCP). This setup
allows an AI agent to automatically investigate alerts by querying
logs and traces, rather than requiring manual intervention from an
engineer. Organizations can host the MCP server on Amazon ECS, Amazon
Bedrock AgentCore, or use the built-in endpoint on OpenSearch version
3.3+.

 HALVING THE TIME: HOW UBER EATS REBUILT ITS SEARCH PIPELINE (8 MINUTE
READ) [10]

 Uber cut end-to-end Eats search latency in half by removing low-value
retrieval paths, separating ranking features from presentation data,
and eliminating false dependencies between pipeline stages. Additional
gains came from pagination, concurrent rendering, request hedging,
compact embeddings, and fixing service-mesh connection bottlenecks.

RESOURCES & TOOLS

 AGENTS MULTIPLY PRS. BREX CUT PER-CHANGE PREVIEW COSTS UP TO 99%.
(SPONSOR) [11]

 Duplicating namespaces for every change doesn't scale when engineers
and coding agents are both shipping. Brex moved to Signadot [12]'s
lightweight ephemeral environments on a shared cluster, cutting
preview infrastructure costs by 99% and preview time 80%. See how they
scaled testing across hundreds of engineers and agents. [11]

 IMPECCABLE (GITHUB REPO) [13]

 Impeccable is a design skill for AI coding agents that includes 24
commands and 61 deterministic detector rules for identifying common
problems in AI-generated frontend design. The tool works with editors
including Cursor, Claude Code, VS Code, and Grok Build.

 T3CODE (GITHUB REPO) [14]

 T3 Code is an "agent harness control surface" that manages AI agents
from Claude, Codex, Cursor, and other platforms. Users can control
these agents through mobile, web, and desktop apps.

 REBALANCER (GITHUB REPO) [15]

 Meta open-sourced Rebalancer, a library for assigning tasks, shards,
servers, and traffic while balancing resource limits, placement
constraints, and optimization objectives. It supports local-search and
mixed-integer solvers, plus a Dockerized Explorer interface for
debugging why assignments were made and which constraints are binding.

MISCELLANEOUS

 BEYOND OBSERVABILITY: EVOLVING PRODUCTION OPERATIONS IN THE AGE OF AI
(40 MINUTE READ) [16]

 Panelists from Genesys, Netflix, and Groundcover discuss using AI
agents for incident response and observability, stressing human
accountability, machine-readable high-cardinality telemetry, sandboxed
rollouts, and organizational context. They advise starting small in
greenfield environments and documenting jobs to be done for agents.

 INTRODUCING WEB SEARCH API VIA AI GATEWAY (4 MINUTE READ) [17]

 Cloudflare partnered with web search providers Ceramic.ai, Exa, and
Linkup to add web search capabilities to its AI Gateway. The feature
lets agents retrieve live data instead of guessing URLs. Web search
partners must comply with Cloudflare's "Verified bots" requirements
and respect robots.txt.
