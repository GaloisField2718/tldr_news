NEWS & TRENDS

 BRIDGING ALLOY AND OPENTELEMETRY: THE OTEL ENGINE IS NOW IN PUBLIC
PREVIEW (8 MINUTE READ) [7]

 Grafana Alloy's OpenTelemetry engine is now in Public Preview as of
Alloy v1.21.0. It runs standard OpenTelemetry Collector YAML
configuration and supports Fleet Management for remote configuration.
Users can run the OTel engine alongside the default engine or switch
between them using an environment variable.

 LAKEBASE POSTGRES IS NOW GENERALLY AVAILABLE ON GOOGLE CLOUD (11
MINUTE READ) [8]

 Lakebase Postgres is now generally available on Google Cloud as a
fully managed, serverless database. It includes autoscaling, scale to
zero, instant branching, and point-in-time recovery to help teams
build and ship faster without managing database infrastructure.
Operational and analytical data share the same storage format.

OPINIONS & TUTORIALS

 SHOPIFY OVEREXPOSED SCANS GKE INGRESSES AND CLOUD RUN FOR EXPOSURE (4
MINUTE READ) [9]

 Shopify Overexposed is an internal scanner that finds GKE Ingresses
and Cloud Run services reachable without authentication. A rebuild on
GCP Cloud Asset Inventory plus an anonymous HTTP probe cut
inconclusive Ingress verdicts by about 80%.

 DEEP DIVE: AUTO SCALING RESPONSE TIMES ON AMAZON ECS (12 MINUTE READ)
[10]

 Amazon ECS now offers high-resolution CPU and memory metrics
published every 20 seconds for target tracking, allowing services to
detect and respond to load changes faster than the default 60-second
resolution. AWS benchmarks show time to trigger scale-out fell 76%,
from 363 seconds to 86 seconds, and SLA breach time on Fargate
decreased 69% in gradual ramp tests.

 THE HIDDEN LATENCY INSIDE YOUR DATABASE (8 MINUTE READ) [11]

 PlanetScale Metal uses locally attached NVMe storage to eliminate
network latency between compute and disk. This architecture avoids the
IOPS limits of network-attached storage like EBS, where defaults are
often capped at 3,000 IOPS. Benchmarks show an instance with local
NVMe storage costs $551.15 per month compared to $1,513.82 for a
comparable EBS setup.

 FLOCI (GITHUB REPO) [13]

 Floci is a free, open-source local AWS emulator for development,
testing, and CI that works without a cloud account or auth token. It
supports standard tools like Terraform and the AWS CLI, and Lambda or
RDS workloads run in real Docker containers for higher fidelity than
mocks. The project also acts as a drop-in replacement for LocalStack.

 AGENT-DESKTOP (GITHUB REPO) [14]

 Agent-Desktop is a CLI that enables AI agents to see and operate
desktop applications on macOS, Windows, and Linux through the OS
accessibility tree. It reads the accessibility tree as JSON, allowing
agents to interact with elements without using screenshots or pixel
matching.

 DETECT WHEN YOUR AI AGENT COPIES A SELF-REPLICATING PROMPT INJECTION
(11 MINUTE READ) [15]

 Datadog tested its AI Guard product against self-replicating prompt
injections that OpenAI reported in September. AI Guard flagged a
planted email as indirect prompt injection at 99.5% confidence and a
planted CSV file as jailbreak and obfuscation.

 OPTIMIZE YOUR NRQL WITH MACROS! (2 MINUTE READ) [16]

 New Relic introduced NRQL Macros, which save an expression as a
reusable named shortcut called by prefixing the name with a dollar
sign. Macros can simplify long WHERE clauses and update many dashboard
widgets by changing one definition.
