 DOCKER AND ACTIVESTATE EXTENDING SECURE DEFAULTS TO THE PACKAGES
DEVELOPERS INSTALL (5 MINUTE READ) [7]

 Docker partnered with ActiveState to extend its trusted content
standard from base images to packages installed through pip, npm, and
Maven. ActiveState rebuilds components from source and promises fixes
within 5 business days for critical CVEs.

 WHAT'S NEXT FOR OCTOPUS FEATURE FLAGS (6 MINUTE READ) [8]

 Octopus Feature Flags leave public preview for Octopus Cloud and
arrive in self-hosted Octopus 2027.0, with rules-based targeting and
phased automated rollouts. Existing flags require updated client SDKs
before upgrading.

 HOW TO IMPORT EXISTING RESOURCES TO OPENTOFU [TUTORIAL] (15 MINUTE
READ) [9]

 Spacelift compares the OpenTofu import CLI command with import blocks
and recommends blocks because they appear in plan and apply. The

experimental config generation.

 WELL, THAT WASN'T FUN: OCTOBER 16 '26 (7 MINUTE READ) [10]

 Fly.io patched and rebooted its entire fleet over 10 hours in
response to CVE-2026-99999, a Linux kernel bug that allowed guest VMs
to read host memory. The vulnerability allowed an attacker to control
two bytes of an IPv4 header, leading to firewall bypasses and
out-of-bounds reads. Fly.io advises customers who sent unencrypted
traffic between October 15 and 17 to rotate their credentials.

 HOW WE HALVED DNS BUILD DELAY AND CUT MEMORY USE BY 85% (18 MINUTE
READ) [11]

 Cloudflare stopped rebuilding entire DNS zones for settings changes
by identifying which records could be affected and grouping pending
work for the same zone. Peak memory fell from 79 GiB to 12 GiB, and
shorter waits between pipeline stages brought median build completion
time down from 7.7 to 3.3 seconds.

 PRODUCTION ACCESS SHOULDN'T OUTLIVE THE TASK (SPONSOR) [12]

 A quick fix shouldn't require permanent admin access. With Teleport
[12], engineers can request temporary access to servers, Kubernetes
clusters, and databases. Approve requests through tools like Slack,
then let privileges expire automatically.

Learn More [12]

 LLAMA-MODCHIP (GITHUB REPO) [13]

 Llama-modchip runs the 284-billion-parameter DeepSeek-V4-Flash on a
pure 64GB CPU with no GPU. It achieves up to 14.7 tokens per second
using SwiGLU-H2 compression and cache optimizations. The tool also
supports other models, including NVIDIA-Nemotron-3.5-30B-A3B at up to
111 tokens per second.

 CLAUDE-QUICKSTARTS (GITHUB REPO) [14]

 Claude-quickstarts is a collection of projects designed to help
developers build deployable applications using the Claude API. The
repository includes examples for use cases like a customer support
agent, a financial data analyst, and various computer use demos.

 HARNESS FOR AGENTS: INTRODUCING A NEW PLATFORM EXPERIENCE (9 MINUTE
READ) [15]

 Harness introduced a new platform experience built around a
lightweight Go-based Delegate that runs every CD step in its own
container. Worker Agents run as pipeline steps under existing
approvals and audit logs, and the rollout is opt in through early
access.

 COMPARE AI AGENT CHANGES WITH ONLINE EXPERIMENTS IN AGENT
OBSERVABILITY (9 MINUTE READ) [16]

 Datadog Online Experiments compares AI agent variants on live traffic
using evaluation scores alongside latency, cost, and error metrics. In
an internal test, GPT-6 Luna cut estimated cost by 44.3 percent versus
GPT-5.6 Luna with nearly identical quality scores.
