NEWS & TRENDS

 SOLO.IO MAKES ENTERPRISE AGENT SUBSTRATE AND KAGENT GENERALLY
AVAILABLE (2 MINUTE READ) [6]

 Solo.io released enterprise editions of Agent Substrate and kagent,
which suspend idle agent sessions and resume them on demand.
Agentgateway enforces identity and policy on traffic, and OutSystems
and Swissquote run the stack in production.

 CRITICAL RCE VULNERABILITY IN APACHE HTTP SERVER: EVERYTHING YOU NEED
TO KNOW (3 MINUTE READ) [7]

 A critical RCE vulnerability in Apache HTTP Server's HTTP/2 module
stems from a race condition in the assign_headers() function. Wiz data
shows 64% of cloud environments have vulnerable resources.
Organizations should upgrade to version 2.4.71 or later, or disable
HTTP/2 support, to address the flaw.

OPINIONS & TUTORIALS

 DON'T JUST FLAG IT, FIX IT: HOW TO RUN CODEMENDER IN YOUR PULL
REQUESTS (5 MINUTE READ) [8]

 Google Cloud architects describe a reference architecture that
connects the CodeMender security agent to Git pull requests on Cloud
Run. Slash commands verify and fix findings, and short-lived OIDC
tokens avoid stored keys.

 BEYOND TEST CARDS: A FAKE PAYMENT PROVIDER FOR TESTING AT SCALE (14
MINUTE READ) [9]

 Lyft built a Fake Payment Provider that supports complex failure
scenarios like partial authorization, latent captures, and refunds,
which standard test cards cannot model. It embeds scenario logic
directly into the payment token, allowing simulated users to test
specific retry and fallback paths safely in both staging and
production environments.

 HOW WE MIGRATE TBS FROM HEROKU WITHOUT LOGICAL REPLICATION (11 MINUTE
READ) [10]

 PlanetScale built an open-source Heroku Migrator to move databases up
to multiple terabytes without logical replication. It uses Bucardo for
trigger-based replication to keep data in sync during the migration.
The tool splits the process into data transfer and index rebuild
phases to increase copy speeds by roughly five times.

 OPENBOT (GITHUB REPO) [13]

 OpenBot is a self-hostable workspace for AI coworkers that provides
each agent with its own browser, files, and tools. It supports AG-UI
agents from platforms like Amazon Bedrock, Claude, and LangChain, and
allows teams to deploy the system on their own Kubernetes
infrastructure. The MIT-licensed template integrates with OpenAI,
Claude, and Gemini models.

 TENSORFOLD (GITHUB REPO) [14]

 TensorFold is an LLM inference engine that serves language models
from a Zig binary on Apple Silicon and NVIDIA GPUs. The engine reads
checkpoints, tokenizes requests, and runs Metal or CUDA kernels
directly, requiring no Python or MLX installation.

 OPEN CLUSTER MANAGEMENT (OCM) BECOMES A CNCF INCUBATING PROJECT (5
MINUTE READ) [15]

 The CNCF Technical Oversight Committee accepted Open Cluster
Management as an incubating project. OCM manages Kubernetes clusters
across cloud, on-premises, and edge, and eBay uses it with Argo CD
across more than 190 clusters.

 WHAT AN INDEPENDENT THREAT MODEL FOUND IN LINKERD, AND WHAT YOU
SHOULD DO NEXT (7 MINUTE READ) [16]

 An independent threat model of open-source Linkerd identified 30
threats, 28 of which were categorized as medium or high. Only one
finding is a software bug, which maintainers fixed in February 2025.
The rest stem from default settings and configuration choices. This
guide maps every threat to MITRE ATT&CK and NIST 800-53 frameworks.
