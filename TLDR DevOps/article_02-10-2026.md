NEWS & TRENDS

 BUILDING A POST-QUANTUM CERTIFICATE AUTHORITY WITH MERKLE TREE
CERTIFICATES (10 MINUTE READ) [7]

 Cloudflare is launching a certificate authority that will support
Merkle Tree Certificates (MTCs), targeting early 2027 for inclusion in
Chrome's Quantum-resistant Root Store. The company will provide
standard MTC issuance at no cost. MTCs batch certificates into an
append-only Merkle tree to address the scaling issues of post-quantum
cryptography, which can increase log storage requirements by 40 times.
Cloudflare successfully tested the technology with Chrome, serving
billions of MTCs and finding that median performance was 9% faster
than classical signature chains.

 AMAZON S3 VECTORS NOW SUPPORTS METADATA PRE-FILTERING FOR HIGHER
RECALL ON FILTERED SEARCHES (5 MINUTE READ) [8]

 AWS has introduced metadata pre-filtering for Amazon S3 Vectors to
improve recall on filtered queries. The feature evaluates metadata
filters before running a similarity search and supports up to 100
filter constraints per query. On highly selective filters,
pre-filtering returns up to five times more matching vectors than
previous methods. It is available immediately at no additional cost
and works on existing indexes without requiring data re-ingestion.

 CLOUDFLARE CONTAINERS, REBUILT TO SCALE AGENT SANDBOXES (15 MINUTE
READ) [9]

 Cloudflare has rearchitected its Containers service to handle agent
workloads, allowing code to select the image and instance type at
runtime. The update introduces a new scheduling policy that starts
containers six times faster, with median startup times falling from
over four seconds to 648 milliseconds in independent benchmarks. A
filesystem snapshots feature is also available in public beta to let
workspaces save and restore their state.

 WE TESTED OUR OWN WAF WITH FRONTIER AI MODELS. HERE'S WHAT WE FOUND
(9 MINUTE READ) [11]

 Cloudflare built a dynamic testing tool that uses large language
models to iterate attack payloads against its Web Application
Firewall. The system ran 1,107 attempts across six attack categories
and recorded 49 findings that required human review. Cloudflare used
these results to release new detections for SSRF attacks and improve
an existing cloud metadata rule.
