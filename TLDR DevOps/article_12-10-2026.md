NEWS & TRENDS

 INTRODUCING AI EVALUATION: CLOSE THE LOOP ACROSS THE FULL AI
LIFECYCLE (7 MINUTE READ) [6]

 New Relic added AI Evaluation to its AI Observability platform, using
an LLM as a judge to score live prompts and completions for safety and
accuracy. It flags prompt injection, data leakage, and hallucinations
with 0 to 1 scores attached to distributed traces.

 FLUX9S GA: FLUX CLUSTER STATE, FROM THE TERMINAL (6 MINUTE READ) [7]

 flux9s, a Rust terminal UI for Flux inspired by K9s, reached 1.0. It
adds dependency graphs, reconciliation history, a cluster health pulse
dashboard, and opt-in discovery for Flagger and tofu-controller, and
it is read-only by default.

 DIGITALOCEAN MICROVMS: FAST, ISOLATED COMPUTE FOR YOUR AI AGENT
INFRASTRUCTURE (5 MINUTE READ) [8]

 DigitalOcean has released MicroVMs in public preview, offering
isolated virtual machines that pause when idle and resume in
milliseconds. The service costs $0.022 per vCPU-hour and $0.0085 per
GiB-hour for compute, billed per second, while paused instances only
incur storage fees. MicroVMs are built on the open-source Firecracker
platform and are designed for workloads like coding agents, sandboxes,
and CI/CD runners.

OPINIONS & TUTORIALS

 ZERO-DOWNTIME POSTGRESQL MIGRATIONS: A PRODUCTION PLAYBOOK FOR SAFE
SCHEMA CHANGES (21 MINUTE READ) [9]

 Safe PostgreSQL schema changes separate expansion, backfills, traffic
switches, and cleanup so old and new application versions remain
compatible during deployment. Short lock timeouts, concurrent index
builds, separately validated constraints, and throttled backfills
limit disruption, while monitoring replica lag and data consistency
determines when each phase can proceed.

 AGENTIC EVALUATIONS: BENCHMARK AI AGENT QUALITY, PERFORMANCE, &
SAFETY (17 MINUTE READ) [10]

 Anthropic has introduced a new concept called agentic evaluations, or
agentevals, to verify that AI agents perform tasks correctly and
safely. The tool grades agent traces based on specific criteria like
performance, output quality, and safety. Developers can install
agentevals via a Python package or clone the source repository from
GitHub.

 WHAT TODAY'S SOFTWARE OWES TO BRONZE AGE CLOCKS (8 MINUTE READ) [11]

 Leaky buckets provide inexpensive admission control by calculating
available capacity from elapsed time rather than running a background
timer. PlanetScale applies related token-bucket budgets to Postgres
queries, estimating resource costs before execution and reconciling
actual costs afterward to control bursts and protect database
capacity.

 THIS OS CODING HARNESS GETS 4X THE DEEPSWE SOLVES AS CLAUDE CODE
(SPONSOR) [12]

 CodeAF [12] runs at up to 4.8x less per solved issue than frontier
models, and it outperforms on complex software engineering tasks. It
works with any provider and gives you 1 window where you hand work
off, track progress, and step in when human judgment is needed. See
why it's #1 on DeepSWE [12]

 CONTEXT MODE (GITHUB REPO) [13]

 Context Mode is an MCP server that reduces context window usage by
98% for AI coding agents. It saves tool output to a sandbox so raw
data never enters the conversation, shrinking a typical 315 KB output
load to 5.4 KB. The tool also persists session memory in SQLite,
allowing agents to recover their state after a conversation compacts.
It works across 17 platforms, including Claude Code, Gemini CLI, VS
Code Copilot, and Cursor.

 AIRLLM (GITHUB REPO) [14]

 AirLLM allows 70B large language models to run on a single 4GB GPU
without quantization. The tool can run Kimi K3 (2.8T) on under 4GB of
VRAM and DeepSeek-V3 (671B) on about 12GB. It works by keeping only
one layer on the GPU at a time. AirLLM also supports training huge
models on small VRAM, with Qwen3.8-Flash-Next (125B) training under
6GB.
