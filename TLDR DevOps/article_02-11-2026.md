NEWS & TRENDS

 SPACELIFT BROUGHT SCALE TO YOUR IAC PROVISIONING. NOW WE'RE
AUTOMATING EVERYTHING THAT HAPPENS AFTER. (4 MINUTE READ) [6]

 Spacelift is expanding from IaC provisioning into Day 2 operations
with Spacelift Flows. It also renamed its IaC and GitOps offering to
'Spacelift Deploy' and bundles it with the Spacelift Intelligence
assistant in one control plane.

 GRAFANA 13.3 RELEASE: MANAGE VARIABLES ACROSS DASHBOARDS, SHARE
FINDINGS WITH NOTEBOOKS, A UI REFRESH, AND MORE (6 MINUTE READ) [7]

 Grafana 13.3 adds cross-dashboard variables and Notebooks, both in
public preview, plus the first phase of a visual refresh. It also
brings Assistant dashboard plans and a generally available Undo turn
option for reverting Assistant edits.

 CLOUDFLARE SERVICES FOR PRIVATE ORIGINS IS NOW GENERALLY AVAILABLE (5
MINUTE READ) [8]

 Cloudflare can now route public requests to private origin IPs over
existing Cloudflare One connectivity while applying WAF, caching, bot
management, and Workers. Origins retain private addresses without
inbound firewall exceptions. Setup requires account enablement,
supported connectivity, and appropriate return routes.

OPINIONS & TUTORIALS

 DEFAULT TO SERVERLESS FOR AI AGENTS, THEN LET PRODUCTION DATA DECIDE
WHAT MOVES (10 MINUTE READ) [9]

 Datadog argues that serverless should be the first execution model
teams evaluate for AI agents. It cites a study of over 35,000 coding
agent sessions where LLM or tool calls filled only 20% of the median
session.

 HOW TO TROUBLESHOOT GKE WORKLOADS FASTER WITH VPC FLOW LOGS (5 MINUTE
READ) [10]

 Google Cloud shows how GKE metadata in VPC Flow Logs gives
workload-level attribution for network traffic without agents or
sidecars. It walks through three Flow Analyzer examples on the Online
Boutique demo.

RESOURCES & TOOLS

 WHAT'S ACTUALLY RUNNING UNDER YOUR EC2 INSTANCE? (SPONSOR) [11]

 Meet the AWS Nitro System [11], the foundation for Amazon EC2
instances. Its purpose-built Nitro Cards handle networking, storage
and management, delivering stronger security and faster performance
while all of the host's CPU and memory go to your instance. Check out
the deep dive [11]

 VORSSAINT (GITHUB REPO) [12]

 Vorssaint is a free and open-source macOS menu bar toolkit that
replaces dozens of paid utility apps. It offers per-app volume
controls, window snapping, a clipboard history, and system monitors.
The tool runs locally with no account, telemetry, or subscription
required.

 OPENMAIC (GITHUB REPO) [13]

 OpenMAIC is an open-source AI platform that transforms documents into
interactive classroom experiences with AI teachers, slides, and
simulations. It supports over 20 providers, including OpenAI,
Anthropic, and local options like Ollama.

MISCELLANEOUS

 HOW GKE NETWORKING SCALES TO SUPPORT HIGH DENSITIES OF CONCURRENT AI
AGENTS (4 MINUTE READ) [14]

 Google Cloud explains how GKE Dataplane V2 avoids Cilium's 65,536
identity limit for high-density agent workloads by moving
high-cardinality pod labels to annotations. The post reports 300
sandboxes per second at sub-second latency.

 TRACE VOICE AGENTS WITH DATADOG AGENT OBSERVABILITY (5 MINUTE READ)
[15]

 Datadog Agent Observability now captures audio, transcripts, token
usage, and tool calls for voice agents built on the OpenAI Realtime
API. It also adds tracing for Amazon Nova 2 Sonic, with ElevenLabs
Realtime support planned for ddtrace 4.17.0.

 DO THE MATH: HOW WE TOOK OVER CHATGPT ACCOUNTS (10 MINUTE READ) [16]

 Researchers found a vulnerability that allowed them to take over
ChatGPT accounts just by sending a victim a link. The exploit chain
combined a MathLive keyboard feature and the HTML Preview to bypass
the sandbox, allowing malicious code to run as chatgpt.com and access
private conversations. OpenAI fixed the issue on October 26 and
classified the report as P1.
