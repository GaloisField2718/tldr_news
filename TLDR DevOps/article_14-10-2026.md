NEWS & TRENDS

 ANNOUNCING AWS LAMBDA WEB FUNCTIONS (5 MINUTE READ) [8]

 AWS Lambda Web Functions is a new form factor that runs standard HTTP
web applications without rewriting code into an event handler.
Developers can deploy existing Node.js servers built with frameworks
like Express or Next.js, and the service automatically handles scaling
and multi-region distribution. Each execution environment handles up
to 128 concurrent requests, and billing is based on active CPU time
rather than total duration. It is available today in five regions.

 SRE BOOK SECOND EDITION (3 MINUTE READ) [9]

 Google has released a completely rewritten second edition of its Site
Reliability Engineering book with O'Reilly Media. The update reflects
a decade of changes to the reliability field, including the rise of
AI, microservices, and platform engineering. The new text includes
guidance on modern challenges like running large language models and
using AI to enhance operational reliability.

 HEADLESS OBSERVABILITY: THE NEXT EVOLUTION OF AUTONOMOUS OPERATIONS
(6 MINUTE READ) [10]

 New Relic argues observability must evolve for AI agents as well as
humans, since agents need trusted operational intelligence rather than
raw telemetry. Its Ground Truth layer combines telemetry,
relationships, evidence, and context, separating intelligence from
presentation so dashboards and APIs serve both audiences.

 AKS IS GROWING – ALONG WITH ITS KUBERNETES UTILIZATION PROBLEM (5
MINUTE READ) [11]

 Per the 2026 State of Kubernetes Optimization Report, AKS CPU
utilization fell to 8% and memory to 20%, with CPU overprovisioning at
69%. GPU utilization averages 5% overall and 2% on AKS, driven by
conservative resource requests that are rarely revisited.

 UNDER THE HOOD, OFF THE HOT PATH: HOW D1 SCALES TO MILLIONS OF
DATABASES (24 MINUTE READ) [12]

 Cloudflare scaled D1's control plane to manage millions of
SQLite-backed databases while keeping centralized components out of
the query hot path. Distributed routing metadata, pooled Postgres
connections, precomputed aggregations, and idempotent background
processes reduce bottlenecks as database counts grow.

 Xtool is a cross-platform tool that replicates Xcode functionality

 SHIPPING MEDIA OVER QUIC AT META SCALE FOR INSTAGRAM LIVE INGEST (6
MINUTE READ) [17]

 Instagram Live now uses the open standard Media over QUIC (MoQ)
protocol for live video ingest on iOS and Android. This switch moves
development from Meta's in-house RUSH protocol to a shared IETF
standard developed with Google, Akamai, and others. Meta says the MoQ
path matched RUSH on streaming quality and reliability measures during
testing.

 WHAT GETS TOASTED IN POSTGRES (12 MINUTE READ) [18]

 Postgres TOAST compresses oversized variable-length values and moves
them into separate storage when necessary. SQL examples show why LZ4's
faster compression does not always produce smaller values or faster
reads: pglz can outperform it for short previews, while uncompressed
external storage can improve reads from the middle of large binary
values.
