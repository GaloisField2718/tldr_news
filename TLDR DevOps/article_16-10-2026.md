 AMAZON S3 IS NOW AVAILABLE ON THE VERCEL MARKETPLACE AND V0 BY VERCEL
(4 MINUTE READ) [9]

 Developers on Vercel can now provision Amazon S3 storage, including
S3 Tables and S3 Vectors, directly from the Vercel Marketplace and v0.
The integration handles connection configuration automatically and
supports three workloads: everyday storage, analytics, and AI. Users
pay standard Amazon S3 pricing for the resources they use, and new AWS
accounts created through Vercel receive $100 in credits valid for six
months.

OPINIONS & TUTORIALS

 SEQUENCES AND OTHER VOLATILES IN NEKI (12 MINUTE READ) [10]

 Distributing PostgreSQL queries across shards gets complicated when
functions depend on time or generate sequence values. Neki coordinates
sequence allocation through its router and preserves how often
expressions execute, preventing query optimizations from producing
duplicate IDs or changing SQL behavior.

 INSIDE HYPERDRIVE: HOW WE SOLVED A RARE MYSQL CACHING BUG (10 MINUTE
READ) [11]

 A rare Hyperdrive bug returned empty MySQL results when two
components shared a cache but encoded responses using different
protocol capabilities. Cloudflare traced the failures to an assumption
inherited from its Postgres implementation and fixed them by storing
responses in a canonical format before translating them for each
client.

RESOURCES & TOOLS

 WHAT HAPPENS WHEN YOU REBUILD REDIS FOR MULTI-CORE HARDWARE?
(SPONSOR) [12]

 Redis runs one core per process. Your server has 64. Dragonfly [12]
is a multi-threaded, Redis/Valkey-compatible data store built by an
ex-AWS ElastiCache engineer. It hits 6M ops/sec on a single node, no
cluster needed. Instacart used it to cut latency in half on 70% fewer
nodes. Learn more [13]

 TOKENSPEED (GITHUB REPO) [14]

 TokenSpeed is an open-source LLM inference engine designed for
agentic workloads, offering TensorRT-LLM-level performance and
vLLM-level usability. It is the first inference engine to separate the
control plane, implemented in C++, from the execution plane,
implemented in Python. The project is backed by the non-profit
LightSeek Foundation with support from vendors including NVIDIA and
AMD.

 XERJ (GITHUB REPO) [15]

 XERJ is a local AI search tool that indexes code, docs, logs, and
PDFs for search and RAG. It uses 40x fewer tokens than grep and
reduces a coding agent's output tokens by 2.7x in controlled studies.
The tool is compatible with the Elasticsearch API and runs on Linux,
macOS, and Windows.

 PULUMI ESC NOW ISSUES OIDC TOKENS FOR ANY SERVICE (5 MINUTE READ)
[16]

 Pulumi ESC environments can now mint short-lived OpenID Connect
(OIDC) tokens for any service that accepts one. The new fn::open::oidc
provider generates tokens that expire within one hour, eliminating the
security risks associated with storing long-lived API keys. Developers
can use these tokens to authenticate with services like Anthropic,
Cloudsmith, JFrog Artifactory, and Aembit without storing static
credentials. The feature is available now in every Pulumi Cloud
organization.
