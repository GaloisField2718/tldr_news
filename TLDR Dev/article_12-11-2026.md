 HOW WE CUT NEXT.JS MEMORY FROM ~5GB TO ~1GB: THE REACT-QUERY TIMER
HOLDING EVERY SSR REQUEST (9 MINUTE READ) [8]

 Zepto's Next.js pods sat at about 5 GB because react-query v3 starts
a multi-minute cache timer for every query rendered on the server, and
Node ties each timer to the request's AsyncLocalStorage context,
keeping every finished request in memory. Building server-side queries
with an infinite cache time stopped the timers and dropped pods to
about 1.2 GB, and the same trap still applies on v5 when hooks set an
explicit gcTime. The fix also exposed that autoscaling had been driven
by the leak, so teams fixing memory issues should watch replica counts
and latency afterward.

 WHAT IS EVAL-DRIVEN DEVELOPMENT? HOW TO IMPROVE AI AGENTS (12 MINUTE
READ) [9]

 Tweaking agents by hand-testing a few prompts makes it hard to tell
whether a change helped or hurt, since outputs vary and several
answers can be correct. LangChain proposes a test-driven-style loop:
write a pass/fail spec for one behavior, build the dataset and
evaluator before the change, then compare experiments example by
example, since a higher average can hide regressions. It also urges
keeping a held-out set to catch overfitting and running evals in CI
and on live traffic, feeding production failures back into the
dataset.

 LOCK YOUR GITHUB ACTIONS (4 MINUTE READ) [10]

 GitHub Actions lockfiles let workflows keep readable version tags
while recording the exact commits they resolve to. This walkthrough
covers generating the lockfile, updating it with Renovate or
Dependabot, and verifying it in CI so workflow changes cannot silently
drift from their pins.

 MY HTML WISHLIST: PARTIAL HTML INCLUDES (5 MINUTE READ) [11]

 The Fragment Includes proposal could let browsers stream reusable
HTML snippets without a build step, but its separate MIME type limits
what can be reused. This essay argues for ordinary HTML pages to opt
into exposing specific fragments, while acknowledging parser,
buffering, and cross-origin constraints.

 GEMINI DECISION 1 AND THE DECISIONS API (5 MINUTE READ) [14]

 Gemini Decision 1 scores bounded choices instead of generating text,
evaluating up to 1,000 questions against shared text, images, audio,
video, or PDFs in one pass. Google reports 150 to 250 ms end-to-end
latency and charges $0.10 per million input tokens with no
output-token fees, targeting model routing, policy checks, and rubric
scoring.

 MODERN WEB GUIDANCE 1.0: THE WEB PLATFORM EXPERTISE YOUR CODING AGENT
IS MISSING (8 MINUTE READ) [15]

 Coding agents produce web code that works but often falls short on
accessibility, performance, and security, and they tend to reach for
JavaScript where native HTML or CSS would do better. Chrome has
shipped a skill pack that feeds agents expert-reviewed guidance and
Baseline compatibility data and adds a workflow that scans existing
codebases for safe upgrades. Firefox and Edge are co-maintainers.

 HOW TWO ENGINEER SIDE PROJECTS BECAME THE AGENT TAKING ACTION INSIDE
DROPBOX (10 MINUTE READ) [17]

 Two Dropbox engineers, one building 3D models in a sandbox and one
automating expense reports from the desktop app, hit the same problem
of letting an agent change their files safely. Their prototypes merged
into the agent in Dropbox's new experience, which runs each
conversation in a fresh VM that boots in milliseconds, keeps
credentials and permission checks outside the agent's reach, and asks
for plan and folder approval. Every change is tied to its
conversation, so users can trace why a file changed and undo just that
agent's work without touching others' edits.

 HOW A FALSE SMOKE ALARM ALMOST DROWNED JANE STREET'S NYC DATACENTER
(7 MINUTE READ) [18]

 Construction dust triggered a smoke alarm that shut off cooling and
pressurized the sprinkler pipes, leaving server heat to threaten a
flood. Pulling power stopped the temperature rise. The incident led to
fleet-wide temperature monitoring that could detect a cooling failure
even when individual servers had not crossed their alert thresholds.
