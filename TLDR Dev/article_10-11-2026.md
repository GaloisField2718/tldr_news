ARTICLES & TUTORIALS

 NOT EVERYTHING NEEDS AN LLM (6 MINUTE READ) [8]

 PostHog uses decision models to answer narrow questions with typed
outputs and probability scores before calling larger models. Its
personal-data filter skips 98.7% of LLM calls, while thresholds are
chosen according to the cost of false positives and false negatives.

 SAFELY SCALING MULTI-AGENT TEAMS WITH CLAUDE FABLE 5.2 (12 MINUTE
READ) [9]

 A team of 1,000 agents reproduced a formal proof of Fermat's Last
Theorem in 28.7 hours using separate sandboxes, shared Git, and a SQL
database for coordination. The experiment combined command screening
and offline monitoring with restricted network access, and used
one-third the output tokens of the earlier formalization.

 HOW AI-ASSISTED DEVELOPMENT HELPED US BUILD THE NEW DROPBOX
EXPERIENCE (8 MINUTE READ) [10]

 Dropbox used AI to trace platform dependencies, prototype
integrations, and build shared React components for its web and
desktop apps. Scoped agent tasks also delivered 22 accessibility
improvements and completed a backlog of 53 test cleanup tasks in a
week, with engineers reviewing the results.

OPINIONS & ADVICE

 THE NEW BOTTLENECK IS INTENT (5 MINUTE READ) [11]

 As AI makes finding and fixing bugs cheaper, deciding what software
should do becomes the bottleneck. Real user feedback, simulated users,
and deterministic testing each leave gaps in defining expected
behavior. This article recommends smoke tests and realistic user
journeys, established conventions for minor decisions, and human
ownership of product choices.

 WHICH CLAUDE MODEL SHOULD YOU BUILD WITH? FABLE, OPUS, SONNET, OR
HAIKU (15 MINUTE READ) [12]

 Anthropic recommends starting most coding and knowledge work on Opus
5.5 at medium effort, using smaller models for simpler tasks and Fable
5.2 for the hardest technical work. This guide explains how effort
settings, prompt caching, and compatibility between models' thinking
blocks affect the cost and reliability of switching models.

 THE GREAT SOFTWARE IP WRITEDOWN (7 MINUTE READ) [13]

 AI agents are eroding the scarcity of engineering talent that
supported software's high margins, while making products easier to
copy and customers easier to migrate. Cheaper development could favor
smaller, specialized products and shift acquisition value toward
customers and distribution, as sales remain a bottleneck and code
becomes less durable as an asset.

 EXACT (GITHUB REPO) [16]

 Exact is an experimental cross-platform runtime that compiles
interfaces written in Contract for the web and native hosts, with
application logic in TypeScript or Rust. A common set of agent
operations supports inspection and testing across platforms, but the
project is pre-1.0 and offers no API stability or backward
compatibility.

 INTRODUCING OUR SMALLEST, MOST EFFICIENT MODEL: MUSE EMBER (4 MINUTE
READ) [17]

 Muse Ember is Meta's small multimodal model for repeated agent tasks
such as tool calls, routing, extraction, and coding subtasks. Meta
reports strong cost efficiency against Haiku 5.5 and GPT-6 Luna,
although Haiku leads it on the FrontierCode 2.0 evaluation.

MISCELLANEOUS

 WHY IS AI SLOP SO FRUSTRATING TO READ? (6 MINUTE READ) [18]

 AI writing burdens readers when it hides who is acting, uses vague
wording, or buries the point in empty statements and misplaced
emphasis. This post compares articles and coding discussions using a
clarity taxonomy, arguing that these faults matter more than familiar
AI signatures such as stock phrases or punctuation.

 THE RACE TO BUILD A “FIND MY” FOR AI CHIPS (4 MINUTE READ) [19]

 Location verification could help detect advanced AI chips diverted to
restricted destinations despite export controls. This article examines
efforts to establish where chips are operating as US legislators push
for verification requirements.

 TESTING CLAUDE ON REAL-WORLD ELECTRONICS DESIGN (6 MINUTE READ) [20]

 Claude Fable 5.2 designed a speakerphone, a voice-assistant hub, and
a virtual pet, covering circuit boards, enclosures, firmware, and
assembly instructions. Human engineers built working prototypes
without circuit fixes, but the devices have not undergone electrical
validation, antenna tuning, thermal testing, or certification.
