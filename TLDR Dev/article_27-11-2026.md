ARTICLES & TUTORIALS

 MY MAIN CLAUDE CODE SESSION WRITES ALMOST NO CODE (5 MINUTE READ) [6]


 A main Claude Code session plans work and delegates implementation to
agents running in separate Git worktrees through Herdr. The developer
approves plans and tests betas, while the manager checks commits,
tests, simulator recordings, and Release builds before merging and
shipping. The workflow produced 37 TestFlight builds in five days, up
from nine in the previous five.

 THE AI ILLUSION (28 MINUTE READ) [7]

 Drawing on the history of speech recognition, this essay examines
five areas where AI claims can outrun the evidence, from agent
autonomy to market readiness. In one travel-planning experiment, a
single agent matched several multi-agent setups at equal compute. The
piece argues for shared metrics, explicit verification, and
deterministic code for checks with clear rules.

 THERE ARE SIX LAYERS TO A WORKING AGENTIC SYSTEM (2 MINUTE READ) [8]

 This post lays out six layers for production agents, from event
triggers and workflow state to tools, trusted context, evaluation, and
runtime controls. It recommends checkpointing runs in Postgres,
putting deterministic logic behind typed tools, and requiring human
approval for high-impact actions. A shared model gateway can enforce
spend caps and keep traces across providers.

 WHY I'M BULLISH ON MCP FOR 2027 (10 MINUTE READ) [9]

 MCP is becoming more useful as clients use Code Mode to chain tool
calls and process intermediate results outside the model's context.
Use the protocol's asynchronous tasks and events to coordinate
long-running work across agents.

 AI MADE SELF-HOSTING FUN AGAIN (7 MINUTE READ) [10]

 Coding agents make it easier to experiment with self-hosting when
Docker Compose files, scripts, and system configuration already live
in Git. The essay describes how to set up NixOS on a home server,
build a Debian bootc image for VPSes, and use Renovate and CI to
automate routine updates.

 WHY IS EVERY AGENT ORCHESTRATOR THE EXACT SAME APP? (3 MINUTE READ)
[11]

 Many coding agent orchestrators pair Git worktrees with terminal
panes and diff viewers, leaving engineers to review and integrate
several streams of code by hand. Use alternatives, such as disposable
environments with separate database state and notifications, when work
passes automated checks or gets stuck.

 VITE 8.4 IS OUT! (3 MINUTE READ) [13]

 Vite 8.4 adds an opt-in dev server allowlist that limits file serving
to assets and modules referenced by the project's entry points. The
release also detects duplicate dev servers, supports package subpath
imports in CSS URLs, and retries CSS loading when a failed dynamic
import is retried in a supported browser.

 OPENAI MAY BE IN COST CONTROL MODE (2 MINUTE READ) [16]

 In a benchmark of head-to-head work tasks, GPT-6.2 Astra and Sol used
fewer reasoning and output tokens relative to their opponents than
earlier versions did. The results suggest a shift toward lower
inference costs, though the benchmark does not establish OpenAI's
intent.

data to use its MCP servers starting on February 1. The publicly
available Gmail tools support search and draft creation, while
sending, replying, forwarding, and editing drafts require partner
access.
