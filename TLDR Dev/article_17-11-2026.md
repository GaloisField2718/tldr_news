ARTICLES & TUTORIALS

 SQUIRCLES (6 MINUTE READ) [6]

 Squircles that look similar can have very different curvature, and
Figma's approximation contains discontinuities where its curves join.
This article contains an interactive comparison that explains the
tradeoffs between Apple, Figma, clothoid, and superellipse shapes,
along with the CSS for approximating Apple's corners using
corner-shape.

 STAGGERING SCROLL-DRIVEN ANIMATIONS WITH ANIMATION-RANGE-START (7
MINUTE READ) [7]

 Staggered scroll animations can use animation-range-start and
sibling-index() instead of a custom progress formula. This post
contains a worked example that replaces the complicated stagger
calculation with one CSS declaration while retaining the browser's
built-in easing behavior.

 FROM SKIPLISTS TO B+ TREES: MAKING VALKEY SORTED SETS MORE MEMORY
EFFICIENT (7 MINUTE READ) [8]

 Valkey 9.2 replaces large sorted sets' skiplist index with a B+ tree
that packs entries together and uses SIMD-assisted searches. In a
five-million-member test, per-member index overhead fell by 36% to
43%, while command behavior stayed the same. The release is still in
candidate testing.

OPINIONS & ADVICE

 WHAT DOES IT MEAN TO UNDERSTAND WHAT WE BUILT? (2 MINUTE READ) [9]

 Understanding individual lines of code does not necessarily explain a
system's behavior, especially emergent failures. AI could help
engineers focus on system properties and develop better tools for
understanding what they actually built.

 FROM TASKS TO GOALS (6 MINUTE READ) [10]

 Giving an agent an ongoing goal means delegating decisions about
which tasks to do and when to act. That requires tool boundaries,
feedback, persistent memory, and ways to ask questions, plus stopping
rules that let the agent do nothing when no action is useful.

 HOW RUST CHANGED ME AS A DEVELOPER (10 MINUTE READ) [11]

 Rust's enums make variants explicit and let the compiler enforce that
every case is handled. This essay explores how sum types and static
dispatch change abstraction choices, including when a straightforward
enum is more useful than designing an interface.

 DUSK BOT (WEBSITE) [13]

 dusk bot runs a crew of AI helpers, each with its own chat, computer,
and memory, using models or subscriptions you already have. Bots can
work in parallel, hand off tasks in group chats, and run scheduled
routines locally, on your own server, or through dusk's hosted cloud.

 BROWSERPOD 4.0 (9 MINUTE READ) [14]

 BrowserPod runs a Linux-like WebAssembly microVM on the user's
device, with tools including Node.js, git, bash, and Rust programs.
Version 4.0 makes the CDN-loaded runtime free for commercial and
production use without an account, while unrestricted networking is a
separate service and self-hosting the runtime requires an enterprise
license.

 JOLT (WEBSITE) [15]

 Jolt is a self-hosted Clojure implementation that compiles through
Scheme and can produce a standalone native binary with statically
linked C dependencies. It supports persistent collections, native C
interop, and OS-thread concurrency, but does not provide general JVM
interop.

MISCELLANEOUS

 BENCHPROOFER: FORMALLY VERIFIED CODING BENCHMARKS, ON DEMAND (11
MINUTE READ) [17]

 BenchProofer adds formal specifications, verified reference
implementations, and audits to coding benchmarks, with SWE-Proof
covering all 500 SWE-Bench Verified tasks. Its audit flagged
behavioral differences in 134 test-passing Opus 4.8 patches, but human
review found actual bugs in only 21 of 41 sampled flags. The
distinction matters because a different implementation can still be a
valid fix.

 GOLDEN BOARD: TEACHING CHESS WITHOUT A SHARED LANGUAGE (25 MINUTE
READ) [18]

 Golden Board packs a visual introduction to chess into a 512 KiB
binary message, starting with a bootstrap that teaches the recipient
how to decode it. The message includes lessons, exercises, and
complete games, while its LLM trials explore ambiguities rather than
proving an unknown intelligence would understand it.
