 HOW OPENAI'S PERFORMANCE FACTORY KEEPS CHATGPT FAST (15 MINUTE READ)
[6]

 When ChatGPT slows down, one Codex session investigates and a second
tries to rule out its explanation before a fix is proposed. In one
case, the reviewer reopened an investigation after noticing that the
service blamed for failed image downloads had already recovered while
the downloads were still failing. Engineers decide what ships, and
Codex checks whether performance returns to baseline after deployment.


 DISTRIBUTED, HIGH-PERFORMANCE BLOB STORAGE ON SQLITE (12 MINUTE READ)
[7]

 Zerodha built Blobasaur, a Redis-compatible store that shards
compressed UI preferences across SQLite files and batches writes per
shard. In a memory-backed benchmark with 64 KiB JSON payloads, moving
from one shard to 16 raised write throughput from about 7,700 to
25,300 operations per second. Cluster slots are configured statically,
with offline resharding and no automatic failover.

 STRIPE EVALS FOR REAL-WORLD CODING AGENT PERFORMANCE (13 MINUTE READ)
[8]

 Stripe tested coding agents on one-time payments, subscriptions, and
Connect integrations. Agents met 78.1% of required criteria on
average, but only 29.4% of runs met every required criterion. All 14
agent setups scored higher with Stripe's plugin.

OPINIONS & ADVICE

 WHEN CAN YOU SHIP ON OFFLINE EVALS ALONE? (10 MINUTE READ) [9]

 Spotify explores when offline AI evaluations can support a launch
decision without an A/B test. In its working example, measurement
noise makes the offline eval appear to explain 24% of the variance in
online effects when the modeled value is 60%. The proposed rule sends
borderline changes to A/B tests and randomly audits some other
decisions to detect drift.

 TOP 10 THINGS AI GETS WRONG IN WEB DEVELOPMENT (10 MINUTE READ) [10]

 Coding agents passed 52% of Chrome's web development checks on their
own and 91% with Modern Web Guidance installed. Common misses included
restoring keyboard focus when a dialog closes, respecting
reduced-motion preferences during smooth scrolling, and reserving
space for content that loads later.

 POSTGRESQL 19 RELEASED (6 MINUTE READ) [12]

 PostgreSQL 19 introduces concurrent table repacking to reclaim space
while reads and writes continue. It also lets applications wait for a
standby to replay a specific write and return an existing row directly
when an insert conflicts, simplifying get-or-create queries.

MISCELLANEOUS

 REBUILDING MY VOICE ASSISTANT PIPELINE (6 MINUTE READ) [16]

 Platypush swaps in microWakeWord for wake-word detection and uses
Silero with an adaptive noise floor to tell when someone has finished
speaking. In synthetic tests with background chatter and bursts of
noise, the old pipeline waited 6 to 10 seconds after the last word,
while the new one waited 1 to 1.6 seconds.

 WHY CHROME STILL USES THE OLD IP AFTER YOU EDIT YOUR HOSTS FILE (4
MINUTE READ) [17]

 Chrome can reuse a connection to the old IP after a hosts file edit
because it pools connections by hostname and port. A used socket can
stay open for five idle minutes, and flushing Chrome's socket pools
forces a fresh lookup but also closes unrelated connections in the
same profile.

 CODING HARNESSES ARE CHEAP TO SWAP NOW. MODEL BEHAVIOR ISN'T. (5
MINUTE READ) [18]

 Hosted agent APIs and shared formats make harnesses easier to swap,
while model choices still change how agents work. With the same
repository instructions and tools, Gemini queried a code graph while
Claude generally searched from the shell, illustrating why teams
should retest behavior after a model swap.
