ARTICLES & TUTORIALS

 SCALING GIT AT OPENAI (22 MINUTE READ) [8]

 OpenAI built Pando, a Git-compatible backend that handles pushes to
unrelated branches independently and reuses cached packfiles across
fetches. It reduced median push latency by nearly 80% and now serves
nearly a petabyte of Git data per day. The tradeoff is weaker
consistency across branches and some redundant downloads, allowing
writes to scale horizontally and reads to saturate clients' network
connections.

 THE HIDDEN LATENCY INSIDE YOUR DATABASE (7 MINUTE READ) [9]

 Network-attached storage adds latency inside a database cluster, even
when the application and database are close together. Local NVMe
avoids that hop, but requires deliberate replication and failover to
preserve durability. Workloads that fit mostly in RAM may see little
benefit, while frequent cache misses and IOPS limits make storage
placement worth examining.

 JAILBREAKING MY CAR'S NAVIGATION SYSTEM JUST SO I CAN CHANGE THE TIME
(10 MINUTE READ) [10]

 A Renault's clock settings were inaccessible without a legitimate
navigation SD card, turning a daylight-saving adjustment into a
firmware reverse-engineering project. QEMU emulation exposed how a
script parser's file writes and Linux's core-dump handling could
combine into code execution. The eventual fix changed the stored GPS
time offset from 180 minutes to 120.

OPINIONS & ADVICE

 RESISTING COGNITIVE SURRENDER (12 MINUTE READ) [11]

 Uncritically accepting agent output can increase technical debt while
eroding the understanding needed to debug and maintain a system.
Choose how much to delegate based on risk, stay involved in
consequential decisions, and ask for small, comprehensible changes.
When delegating more fully, use independent observability,
deterministic checks, and shadow traffic to verify behavior rather
than relying solely on the agent's account.

 AUDITIONING ENGINEERING: SOFTWARE ENGINEERING INTERVIEWS IN THE AGE
OF AI (6 MINUTE READ) [12]

 Warner Music Group encourages candidates to use AI while solving
realistic API integration problems against a live, randomized test
server. Its system-design interview asks candidates to modify an
existing system and infer causes from observed behavior. The approach
emphasizes technical judgment, although building new coding exercises
and training senior system-design interviewers remain costly.

 THE WEIGHT-SPACE PROGRAMMING POST IS MISLEADING (5 MINUTE READ) [13]

 This critique separates experiments that inspect small networks' raw
weights from larger-model experiments that use Python and execution
feedback. The Qwen result involved 50 batches of practice problems, so
it does not demonstrate improvement from inspecting raw weights alone.
The distinction matters when judging whether the work shows one
general capability or several different engineering techniques.

 OFFICE ENGINE (GITHUB REPO) [15]

 Office Engine embeds DOCX, XLSX, and PPTX viewing and editing in a
browser through React or a web component. Progressive loading, Web
Worker parsing, and virtualized views handle large files, while saves
regenerate edited parts and preserve the original bytes elsewhere.

 DJS (GITHUB REPO) [16]

 djs is a JavaScript and TypeScript engine written in Rust for
agent-generated scripts running in a WebAssembly sandbox. It keeps the
entire VM state in one byte array, allowing execution to pause between
instructions, snapshot while waiting for tools, and resume elsewhere.
The focused runtime deliberately omits features such as ES modules,
Intl, and a JIT.

 THREE-LIVE (GITHUB REPO) [17]

 Three-Live compiles a declarative subset of Three.js into GLB and
USDZ assets for web, Android, and Apple rendering pipelines. It runs
generated scripts with execution timeouts and geometry quotas, then
hands the assets to platform-specific viewers. The Apache-licensed
project is in Developer Preview and is not an officially supported
Google product.

MISCELLANEOUS

 SPARKS OF WEIGHT-SPACE PROGRAMMING (20 MINUTE READ) [18]

 Experiments show GPT-6 Astra reading and directly editing neural
network weights without gradient descent, including writing small
game-playing networks from scratch. Editing 0.016% of Qwen3.5-0.8B's
weights reduced reasoning loops and raised MATH-500 accuracy from 7.9%
to 48.1% with 50 forward passes for feedback. The gains removed an
obstacle to existing ability, while similar edits failed to
meaningfully improve a Gemma model that rarely looped.

 COULD A MODERN CHESS ENGINE ON A PENTIUM HAVE DEFEATED KASPAROV IN
1996? (15 MINUTE READ) [19]

 A port of Stockfish running on a 200 MHz Pentium Pro with 64 MB of
RAM reaches a measured rating of 3180 at 30 seconds per move. The
experiment attributes much of chess engines' progress to better search
and evaluation rather than faster hardware. Its roughly 3300 rating at
classical time controls is extrapolated from shorter games, and
readers can play the machine online.
