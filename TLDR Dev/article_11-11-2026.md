ARTICLES & TUTORIALS

 THE CODEBASE REWRITE IS BACK (8 MINUTE READ) [8]

 AI is changing rewrite economics because existing applications give
agents a specification to reproduce, making previously expensive
migrations and backlog work worth reconsidering. Examples from GitHub,
Shopify, and Bun show faster rewrites, but hidden behavior and
regressions make end-to-end tests, benchmarks, and reversible rollouts
essential.

 MCP OR CLI? YES (8 MINUTE READ) [9]

 Sentry is combining its CLI and MCP server so agents can share CLI
authentication while retaining native tool discovery. The CLI handles
filesystem-heavy work such as searching session replay logs, while MCP
exposes discoverable tools, though inconsistent client support still
limits richer integrations.

 BUILDING A MICROAPP INSIDE A PLUGIN: ARCHITECTURE AND TRADEOFFS (5
MINUTE READ) [10]

 Carta's microapps fetch data through MCP once at launch, then run a
local React application against a snapshot with deterministic,
auditable business logic. A no-build shell lets users customize the
code while updates preserve their data, but the architecture trades
real-time refreshes and live collaboration for local ownership and
responsive analysis.

 AI USAGE GENERATES A FRAGILE CODEBASE (6 MINUTE READ) [11]

 Heavy reliance on AI coding can produce shallow tests, unnecessary
abstractions, weaker human understanding, and pull requests that
arrive faster than reviewers can inspect them. These habits lead to
more incidents, slower recovery, and user-facing failures that
coverage metrics miss.

 LIFE ON CLAUDE NINE (18 MINUTE READ) [12]

 This speculative short story follows an engineer whose Claude-powered
automations grow from handling email into systems he can no longer
understand or control. It explores how productivity gains, compulsive
building, and increasingly automatic approvals can turn human
oversight into a formality.

 CHROME-CAPTURE (GITHUB REPO) [15]

 Chrome's new screen recording protocol command replaces a decade-old
pipeline of JPEG frames piped to ffmpeg with AV1 MP4s encoded directly
from the compositor at 60 to 120fps and up to 2160p, with optional tab
audio. In benchmarks against Playwright's recordVideo, stopping a
recording took 17 ms instead of 3.8 s, and the overall test finished
about 10 seconds sooner, with far less WebSocket traffic. It works
with Playwright, Puppeteer, or raw CDP and includes a test fixture,
making it relevant to anyone recording browser tests or demos.

 GEMINI 4 CARBON IS NOW AVAILABLE (6 MINUTE READ) [16]

 Gemini 4 Carbon targets complex coding, knowledge work,
cybersecurity, and scientific reasoning with longer reasoning and
verification loops than Argon. It is available to paying API users at
an introductory price of $2 per million input tokens and $10 per
million output tokens, alongside a rollout to Google AI Ultra
subscribers.

 MODERN WEB GUIDANCE 1.0 (6 MINUTE READ) [17]

 Modern Web Guidance packages browser expertise and compatibility data
as skills for coding agents, with expert-reviewed guidance on
accessibility, performance, security, and modern platform features.
Version 1.0 adds a static-analysis modernization workflow, public
evaluations, and contributions from Firefox and Edge alongside Chrome.


 BILLION-CONTEXT (GITHUB REPO) [18]

 billion-context sits between coding agents and model APIs to compress
conversation history into layered summaries while preserving the
ability to restore details. It exposes compression, decompression,
search, and context-status tools, aiming to keep long sessions within
smaller context windows without repeatedly discarding history.

 THE ERA OF FULLY AUTONOMOUS COMPANIES (18 MINUTE READ) [19]

 Agent-managed companies need persistent shared state, coordination,
code, payment access, and concrete goals that can be checked against
real business results. Rapid growth is predicted in autonomous
businesses, but demand generation, bot defenses, identity
requirements, and human sales cycles remain obstacles.

 INTRODUCING ALPHAPROOF CODE (4 MINUTE READ) [20]

 AlphaProof Code combines human-reviewed specifications with AI agents
that generate Lean proofs for key security properties of Signal's
compiled cryptographic code. DeepMind reports completing the
verification in four weeks with over six million lines of Lean. The
system also proved two deliberately reintroduced historical bugs
insecure.
