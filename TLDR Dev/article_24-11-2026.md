 OPENAI AND CISCO INTRODUCE SHIRUDO (4 MINUTE READ) [6]

 Shirudo is an open-source runtime that lets operators deploy
temporary eBPF protections on Linux while they roll out permanent
patches. Teams can observe a shield's effect on live workloads before
enabling it, and apply approved protections without restarting the
service.

 BUILDING A CONTINUOUS SOFTWARE ENGINE THE HARD WAY (10 MINUTE READ)

 SPEEDING UP CODE REVIEW WITH SMALL-CHANGE (7 MINUTE READ) [8]

 Imprint uses a CI check to identify pull requests eligible for a
lighter review process. The check considers the size of the diff, the
author's history in the affected services, and whether automated
review flagged any high-priority issues.

 FAST IS A DESIGN DECISION (8 MINUTE READ) [9]

 Decisions about rendering, caching, and what loads first shape how
fast a site feels. On one throttled mobile test, prioritizing a small
prerendered version of the homepage's lead card cut Largest Contentful
Paint from about 2.5 seconds to 1.3 seconds.

 GLM-5.4: TOWARD GENERALIZED CODING WITH OUR FIRST LOOP TRANSFORMER (6
MINUTE READ) [15]

 Z.ai's GLM-5.4 runs the same block of 28 layers twice, giving its
750-billion-parameter model more compute per token without adding
parameters for the second pass. Z.ai shows demos in CAD and video
generation and reports that the model can still spend too long
reasoning.

 LEGACY MODERNIZATION WITH LLMS: IS A LARGE TRANSLATION CONSISTENT
WITH ITSELF? (28 MINUTE READ) [16]

 An experiment used 49 Claude Code sessions to translate 600,000 lines
of IBM i source into more than a million lines of Java. Deterministic
generators produced the most uniform code, while independently
translated programs drifted in style and duplicated helpers, with 20
implementations of a single date conversion helper.
