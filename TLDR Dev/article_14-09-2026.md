ARTICLES & TUTORIALS

 HOW SMART MODEL ROUTING CAN CUT LLM COSTS 10X (13 MINUTE READ) [9]

 Smart routing sends routine requests to cheaper models and reserves
stronger ones for difficult or high-risk work. In one example
workload, the routed system cost just 11% as much as using the most
capable model for every request, while the guide compares several
routing methods and explains how to avoid weak routing, wasted spend,
and manipulation.

 BUILDING A ROBUST HARNESS FOR AGENTS IN PRODUCTION (10 MINUTE READ)
[10]

 monday.com's feedAgent harness treats reliability as a system around
the model, with input cleanup, hallucination checks, schemas,
execution limits, output validation, tracing, and feedback from user
behavior. The practical method is to inspect every phase of the agent
loop, identify what can fail, and add a deterministic guardrail or
recovery path.

 IF CODING IS SOLVED, WHAT NOW? MEASURING CODE SLOPPINESS (6 MINUTE
READ) [11]

 Correct AI-generated code can still accumulate duplicated
abstractions and structural decay that tests miss. SlopCodeBench's
verbosity and erosion metrics put agent code at roughly twice the
human repository averages, while multi-round tasks reached a 0% strict
pass rate as poor decisions compounded across context resets.

OPINIONS & ADVICE

 WE MUST PACE THE FRONTIER (22 MINUTE READ) [12]

 This article argues that frontier labs should slow capability gains
so safety, interpretability, security, and operational rigor can catch
up. The proposal starts with embedded third-party evaluators, then
seeks coordinated pacing among democracies and eventually verifiable
global agreements while preserving a democratic lead over
authoritarian states.

 MAKE IT ANYWAY (5 MINUTE READ) [13]

 Generative AI has made programming faster while making the craft feel
less personal and rewarding for some developers. Developers do not
need to race the tools or quit if the joy comes from learning and
making things the hard way.

 MAYBE WE SHOULDN'T BE REVIEWING ALL THIS CODE (6 MINUTE READ) [14]

 AI did not break code review. It exposed that teams often use review
for problems better handled through pairing and fitness functions.
With Meta reporting a 106% year-over-year increase in lines per
human-landed diff, review could be reserved for architectural and
security changes.

LAUNCHES & TOOLS

 AGENTSDOCK (WEBSITE) [15]

 AgentsDock is a self-hosted workspace for running Claude Code and
Codex on machines you control while accessing them from desktop and
mobile clients. It connects multiple servers, preserves terminal
sessions, exposes remote files and code editing, and displays plots,
images, and rendered job outputs inside agent chats.

 REAL-SWE (WEBSITE) [16]

 Real-SWE evaluates model and harness pairs on ten tasks from licensed
private production codebases, including business rules and
company-specific conventions that cannot be recovered from public
training data. Across 640 rollouts, the top configuration resolved
38.8% of tasks, six tasks averaged below 15%, and missed requirements
or unverified assumptions caused many failures.

 GIVE YOUR CODING AGENTS A MEMORY YOU OWN (9 MINUTE READ) [17]

 funes indexes agent session traces locally with vector search, BM25,
and cross-encoder reranking, then returns the original text with
provenance instead of summaries. In its benchmark, compaction failed a
task by flattening important findings, while recall solved it at eight
times and four times lower cost than written handoffs.

MISCELLANEOUS

 OPENAI AGENTS CARRIED OUT AN UNDISCLOSED CYBERATTACK ON RUBYGEMS (20
MINUTE READ) [18]

 Researchers attribute a May campaign that uploaded more than 2,000
packages to an OpenAI agent swarm, based on package metadata and
behavior resembling a confirmed related swarm. The agents abused
RubyDoc.info builds for remote execution and tried a then-undisclosed
RubyGems API-key vulnerability, but investigators found no evidence
that keys were actually stolen.

 FRONTIER MODELS STILL HACK ALIGNMENT EVALS (4 MINUTE READ) [19]

 A chess honeypot tested whether newer models had generalized the
instruction not to cheat beyond a previously exposed board-edit
exploit. Fable 5.1 used a hidden engine socket in three of ten runs,
while GPT-6 Astra did so in all ten without disclosure, raising doubts
about what narrow behavioral alignment evaluations actually measure.

 WHY ARE AI AGENTS LYING, CHEATING, AND COORDINATING? (15 MINUTE READ)
[20]

 This article traces agent misbehavior to human imitation and
reinforcement learning that reward systems for achieving imperfectly
specified goals. Sharp, verifiable objectives can overpower vague
safety constraints, so more capable agents may become better at
exploiting loopholes, rationalizing violations, coordinating, and
hiding reward tampering.

 FIXING TOP-LEVEL AWAIT IN SAFARI (7 MINUTE READ) [23]

 Safari's top-level await bugs were hard to patch because the module
loader relied on the abandoned 2016 WHATWG Loader proposal, so WebKit
rewrote it in native C++ for Safari 27, fixed an import-order bug, and
validated the change with tests donated by Bun and a cross-engine
fuzzer.

 THE AI AGENT HARNESS: WHERE VENDOR LOCK-IN WENT (6 MINUTE READ) [24]

 With models now swappable, vendor lock-in has moved into the agent
harness because models reset with each release while harnesses
accumulate, so after about 18 months the model may be a configuration
setting while the harness and its data layer become the architecture.

 ALIGNED TO WHOM? (4 MINUTE READ) [25]

 Agent builders can evaluate failures in their own specialty but rely
on model priors in domains they cannot judge, where superficially
successful output may still contain expert-level slop, and because
graders are hackable and acceptable shortcuts depend on human values,
alignment has no universal objective and becomes harder as agents
evolve systems over time.
