 YOUR AI AGENT REMEMBERS EVERYTHING. THAT'S THE PROBLEM (19 MINUTE
READ) [7]

 Persistent memory can feed stale facts back to an agent after
circumstances change. This piece covers background passes that review
and rewrite stored memories and asks how systems should handle
corrections, forgetting, and portability.

 SWIFTUI DOESN'T HAVE A LIST. IT WRAPS SOMEONE ELSE'S (14 MINUTE READ)
[8]

 Runtime inspection found that SwiftUI's List wraps NSOutlineView on
macOS and UICollectionView on iPhone and iPad. SwiftUI still computes
its own diffs and hosts each row in a SwiftUI view, so using the same
underlying container leaves room for different update costs.

 STREAMING LLM RESPONSES WITHOUT RENDERING EVERY TOKEN (3 MINUTE READ)
[9]

 Give your streaming relay explicit completion and error events, and
abort upstream generation when the client disconnects. Buffer incoming
tokens and render at most once per animation frame so the browser can
keep up.

 PERPLEXITY AND INTELLIGENCE (7 MINUTE READ) [17]

 OpenAI reports that log perplexity on its held-out dataset fell from
about 0.99 for GPT-3.5 to 0.91 for GPT-4. It proposes using perplexity
alongside other measures to set shared safety thresholds, while
acknowledging that different evaluation datasets make cross-lab
comparisons difficult.

 TEACHING A WEB PAGE TO READ A CHESS BOARD (43 MINUTE READ) [18]

 This browser demo reconstructs a chess position from a screenshot in
about a quarter of a second using a 131 KB model and plain JavaScript.
Inference stays on the device. The system is designed for flat
screenshots and diagrams.
