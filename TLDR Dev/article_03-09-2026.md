ARTICLES & TUTORIALS

 HOW WE COULD SAVE PETABYTES OF CACHE STORAGE WITH ZSTANDARD AND
PINGORA (8 MINUTE READ) [6]

 Cloudflare prototyped Cache Transcoding, a system that compresses
eligible HTML, JSON, CSS, and JavaScript with Zstandard before storing
and transferring them between cache tiers. Initial tests shrank these
assets to roughly one-third of their original size while adding only a
few percent of CPU overhead, potentially creating petabytes of
effective cache capacity without deploying more storage.

 HOW WE MAKE AI CODING MORE COST EFFICIENT WITHOUT SACRIFICING TASK
QUALITY (11 MINUTE READ) [7]

 Shortening individual tool outputs can make an AI coding agent more
expensive when missing context forces it to reopen files, rerun
commands, or take extra turns. GitHub reduced Copilot costs without
materially hurting quality by selectively compressing repetitive logs,
preserving source-like output, removing unused formatting such as
line-number prefixes, shortening prompts carefully, and eliminating
unnecessary retrieval steps.

 HOW WE MIGRATED 11 MILLION USERS TO CLINE'S BIGGEST REFACTOR (9
MINUTE READ) [8]

 Cline replaced its VS Code extension's roughly 76,000-line monolithic
agent core with a shared SDK while protecting workflows used by more
than 11 million developers. Since the VS Code Marketplace lacks
gradual rollouts, the team bundled legacy and new engines together
behind a feature flag with automatic fallback, then ran a month-long
A/B rollout that reduced tasks hitting three consecutive agent
mistakes from 6.34% to 0.62%.

 A DOCS PAGE IS A VERY LONG AND COMPLEX SEARCH QUERY TO FIND WANDERING
AI AGENTS AND MAKE THEM ROUTE INTERESTED PEOPLE TO YOUR COMPANY (9
MINUTE READ) [9]

 Most known Val Town Pro referrals now come from AI, forcing the
company to think about Answer Engine Optimization as traditional
search traffic declines. Its early strategy is to measure model
referrals and citations, selectively allow useful crawlers, and
publish genuinely helpful material for both humans and agents without
filling the web with AI-generated content.

 MAYBE WE SHOULDN'T BE REVIEWING ALL THIS CODE (6 MINUTE READ) [10]

 AI is exposing the limits of mandatory code review by generating more
code than humans can realistically inspect, turning senior engineers
into a bottleneck. Teams should move design, knowledge sharing,
testing, and architectural feedback earlier through pairing,
collaborative design, automation, and fitness functions, then reserve
human code review for exceptional changes involving security
boundaries, major architectural decisions, large blast radii, or low
confidence.

 DON'T GIVE YOUR AGENT A TOKEN. GIVE IT A TASK (SPONSOR) [11]

 What happens when you give your agent an access token and it gets
hijacked? Relay [11] keeps the credential at WorkOS, attaches it only
when needed, and releases it only to allowlisted hosts. A hijacked
agent session becomes a live process you can kill. You can't leak

 INTRODUCING GEMINI 3.8 FLASH AND GEMINI 3.8 FLASH CYBER (8 MINUTE
READ) [12]

 Gemini 3.8 Flash improves coding, long-running agent tasks, and
specialized reasoning while retaining 3.7 Flash's introductory price
of $0.75 per million input tokens and $3.75 per million output tokens.
Google also introduced 3.8 Flash Cyber for trusted defenders,
reporting a success rate above 70% on an internal
vulnerability-discovery benchmark spanning 20 programming languages
and near-frontier performance on automated patching.

 MUSE SPARK 1.3 (WEBSITE) [13]

 Muse Spark 1.3 is Meta's updated model for long-running agentic and
coding workflows. It better tracks prior work, handles messy or
conflicting context, asks for clarification when needed, and uses
roughly 20% fewer tool calls and 25% fewer tokens than Muse Spark 1.2
in Meta's internal coding comparisons.

 UPPY 6.0: FEWER PACKAGES, FEWER MOVING PARTS, AND A ROBUST S3 PLUGIN
(7 MINUTE READ) [14]

 Uppy 6.0 rewrites its AWS S3 plugin around three explicit signing
modes and adds direct support for S3-compatible services like
Cloudflare R2, MinIO, and DigitalOcean Spaces. It also folds four
frequently duplicated packages into Uppy Core, improves
multipart-upload reliability and recovery, and tightens supply-chain
protections.

 THREE SITES MADE 215,128 “BEST SOFTWARE” PAGES FOR AI. PERPLEXITY
CITES THEM (9 MINUTE READ) [15]

 Trellner queried two Perplexity models across 380 software categories
and found that 59.8% of their 7,534 citations came from domains
outside the 100,000 most-visited websites. Three apparently connected
sites alone had published 215,128 machine-generated recommendation
pages, highlighting how AI retrieval systems can ground purchase
recommendations in content designed primarily for machines.

 WASMI 2.0: ENGINEERING ONE OF THE FASTEST WASM INTERPRETERS (16
MINUTE READ) [16]

 Wasmi 2.0 runs about 2.2 times faster than Wasmi 1.0 across its
benchmark suite while preserving its strong startup performance. The
Rust-based WebAssembly interpreter gains four instruction-dispatch
modes, a fixed 64-bit cell representation, smaller binary options,
stable fuel metering, and support for WebAssembly's deterministic
profile.
