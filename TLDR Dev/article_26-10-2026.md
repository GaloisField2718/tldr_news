ARTICLES & TUTORIALS

 SHIPPING 103,802 DOTS IN 82 KB (11 MINUTE READ) [8]

 Layers compressed 13 hand-drawn dot illustrations into an 82 KB
payload by quantizing coordinates and separating them into streams
that expose repeated rows to Brotli. The result is 63% smaller than
compressing the original floats, while typed arrays and an animation
loop that sleeps when idle reduce rendering work.

 RECLAIM GOES AI-NATIVE WITHOUT STARTING OVER (7 MINUTE READ) [9]

 Dropbox routes user edits, automated scheduling, and agent actions
through one shared Schedule Action type so they use the same
validation logic. Preview Mode makes proposed changes reviewable,
backed by a scheduler refactored into a pure function and accelerated
with Redis.

 HOW DATABRICKS USES AI RUNTIME FOR RESEARCH (6 MINUTE READ) [10]

 Databricks uses GPU health checks, fast container launches, and
automatic MLflow tracking to support experiments that can span
hundreds of GPUs. Agent-led research has increased training jobs
eightfold, making startup time and reliable infrastructure central to
the research loop.

 DEAD CODE SHOULDN'T EXIST (8 MINUTE READ) [11]

 A conference talk shows how Sentry removed 28,000 lines of code with
Knip. The page collects the slides, transcript, and recordings, with a

 PURE UI IN THE AGENTIC ERA (4 MINUTE READ) [12]

 A UI can pass an agent's spot check while still showing viewers a
Delete button because role, plan, and billing state are scattered
across components. Making display-relevant state explicit at a page
boundary lets teams render combinations in a visual grid and turn them
into stories or tests.

 TAMAGUI 3 (25 MINUTE READ) [14]

 Tamagui 3 adds a C++ native style runtime, more native compilation,
flat style props, React Strict DOM, and a Tailwind frontend. Eligible
theme updates can reach native views without re-rendering their React
components, but the runtime is an opt-in beta and the breaking release
requires migration work.

 RAPIER JXL (GITHUB REPO) [15]

 Rapier JXL encodes JPEG XL in JavaScript with a roughly 30 KB gzipped
core and WebGPU-accelerated quality search. It runs in browsers,
workers, Node, and Deno, with no dependencies and support for lossless
encoding, HDR, and JPEG transcoding.

 DQUICKTS (GITHUB REPO) [16]

 This QuickJS fork can pause a JavaScript program mid-loop, serialize
its heap, and resume execution in another process. It also runs
TypeScript by erasing types during parsing and includes Rust bindings
plus a REPL whose state survives restarts.

 GROKBOT IS AMAZING. HERE'S WHY I STOPPED USING IT (11 MINUTE READ)
[17]

 A week with 16 always-on bots produced 78 merged pull requests,
followed by $100 spent over a weekend largely on wakeups that yielded
no useful messages. Missed notifications and unreliable follow-ups
lead to an architectural argument for keeping routing, queues, and
durable state in ordinary code, alongside a pitch for Builder's own
framework.

 REVERSE ENGINEERING A BEYBLADE LAUNCH TRACKER (10 MINUTE READ) [18]

 A Bluetooth teardown works out how a Beyblade accessory reports
launches without relying on its official app. It follows the process
from inspecting the hardware to capturing payloads with LightBlue and
PacketLogger, then identifying patterns in the transmitted data.
