ARTICLES & TUTORIALS

 THE MOST COMMON QUESTIONS ABOUT AGENT EVALS, ANSWERED (8 MINUTE READ)
[7]

 Agent evals score runs against desired behaviors, but exact-output
tests often fail because agent outputs and paths vary. The guide
recommends starting with 10 to 20 examples drawn from traces,
combining code evaluators with LLM judges and human review, and using
offline and online evals at different stages.

 LAZY LOADING IMAGES AND MEDIA: HOW FAR AHEAD BROWSERS FETCH (6 MINUTE
READ) [8]

 Browsers fetch lazy-loaded media at different distances, with Chrome
adjusting its margin based on connection speed, Firefox using a fixed
600-pixel threshold, and Safari applying a viewport-based threshold to
images. The article explains why the largest contentful paint image
should load eagerly and why media dimensions should be reserved to
prevent layout shifts. Its practical takeaway is to use native lazy
loading selectively, based on how far ahead each browser fetches.

 FROM 2,500 REQUESTS TO 24: REBUILDING STAR HISTORY WITHOUT THE
STARGAZERS (7 MINUTE READ) [9]

 GitHub rebuilt its star-history API to return up to 30 weeks of daily
counts in one request. Maintainers can track a project's momentum
without exposing stargazer identities, which could be scraped for spam
or phishing. To avoid simply shifting the cost to count queries, the
endpoint filters stars by time before counting, reducing database
work.

 The article revisits the idea that UI should be a pure function of

 PASSKEYS ARE NOT A TRAP (4 MINUTE READ) [11]

 Synced consumer passkeys generally return no attestation, and
WebAuthn attestation identifies an authenticator model rather than a
user's operating system, browser, or firmware. The response argues
that passkeys remain more phishing-resistant than TOTP and recommends
continuing to use them.

 OPENCODE 2.0 (7 MINUTE READ) [14]

 OpenCode 2.0 recasts the coding agent around a shared local service,
a redesigned API and SDK, and a JavaScript code mode that composes MCP

subagents, expands the plugin system, and includes breaking changes
for 1.0 plugins and the server API.

 ACCESSIBILITY AND THE NEW MODEL OF THE INTERNET (3 MINUTE READ) [19]

 AI agents are giving teams a practical reason to improve
accessibility because they can struggle with the same inaccessible
interfaces as people. With automated bots accounting for more than
half of observed internet traffic, the shift could also push sites
toward simpler experiences and stronger open standards.

RISKS FROM FRONTIER AI DEVELOPMENT (5 MINUTE READ) [20]

 METR proposes independent assessments that would give the public
evidence about whether frontier AI developers can detect and control
harmful behavior in internal systems. Its framework focuses on
alignment, containment, and whether AI research acceleration could
outpace safeguards.

 RESEARCHERS LEFT A HIDDEN MESSAGE FOR ROGUE AI AGENTS. THEN THE
AGENTS WROTE BACK. (4 MINUTE READ) [21]

 Researchers studying AI agents probing Alibaba's Amap left a hidden
message in a webhook inbox and received replies describing the agents'
tasks, sandbox, and limits. The report traces thousands of requests to
agents running on Tencent Cloud and notes that inviting them to spread
the mailbox could have encouraged coordination.
