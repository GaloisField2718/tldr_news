ARTICLES & TUTORIALS

 A THOUSAND FEWER PATHS TO ROOT (20 MINUTE READ) [8]

 OpenAI's autonomous security pipeline reproduced 1,724 Linux kernel
vulnerabilities and generated exploits for 948 distinct local
privilege escalation flaws at an API cost of $1.2 million. Agents
handled discovery, runtime validation, exploit development, and
candidate patches before human review and maintainer reporting. The
research highlights why validation must check how an exploit succeeds,
after some agents gained root through a different vulnerability than
the one assigned.

 HOW WE MADE CLARITY.JS 4.5% SMALLER WITHOUT SACRIFICING COMPATIBILITY
(5 MINUTE READ) [9]

 Microsoft reduced clarity.js by 1,257 gzip bytes through more than 50
automated change, build, measure, and test experiments. Named imports
and minifier settings delivered savings, while extracting small
helpers sometimes increased compressed size. A larger saving from
modern JavaScript output could not ship because native async functions
would break Angular sites that depend on Zone.js.

 AGENTIC TECHNICAL DEBT AND WHERE ORCHESTRATION BELONGS IN AI AGENT
ARCHITECTURE (9 MINUTE READ) [10]

 Agent systems accumulate debt when prompts and agent loops take
responsibility for approvals, side-effect retries, and audit trails. A
supplier invoice dispute illustrates how to divide ownership among the
model, harness, durable execution, and an orchestration control plane.
A single agent inside one application may need only its harness, while
processes crossing systems need explicit ownership of recovery and
approval.

 NOBODY HERE WRITES CODE BY HAND ANYMORE (12 MINUTE READ) [11]

 An account of adopting coding agents at Intento traces the shift from
small experiments to a team that delegates code generation and reviews
the output. The key change was making documentation, architectural
decisions, tasks, and production logs accessible to models. Earlier
failures on an established codebase were attributed to missing context
that lived in people's heads, rather than the age of the code itself.

 YOU'LL NEED NERVES OF STEEL TO WORK WITH AI AGENTS (10 MINUTE READ)
[12]

 Fast, cheap coding agents can create substantial review work by
deleting unrelated code, missing requirements, and making tests pass
without exercising the intended behavior. More than 100 hours with
Cursor's Composer 2.5 exposed failures ranging from unsolicited edits
to disabled schema validation and tests that bypassed API routes.
Explicit rules and reference implementations did not reliably prevent
repeated mistakes.

 A NEW GO API FOR JSON (9 MINUTE READ) [15]

 Go 1.27 makes encoding/json/v2 and encoding/json/jsontext generally
available, addressing behavior and performance constraints that could
not be fixed within the old API. The new defaults reject invalid UTF-8
and duplicate object names, while the packages separate Go value
conversion from lower-level JSON syntax processing.

 GRAPHIFY (GITHUB REPO) [16]

 Graphify turns code and supporting material into a queryable
knowledge graph with paths between concepts and an interactive browser
view. Code parsing uses local tree-sitter analysis without an LLM or
vector store, while document and media interpretation can use a model.
Edges distinguish explicit source relationships from inferred
connections, making the graph's evidence easier to inspect.

MISCELLANEOUS

 DOOM'S DNA (WEBSITE) [17]

 This interactive study compares the original DOOM source with 43
descendants to explore what survives copying, porting, and
translation. Structural fingerprints and call relationships can reveal
ancestry even when names or source text change. In a blind test, a Go
translation's functions were assigned to the correct game subsystem
60% of the time, compared with 20% for shuffled labels.

 THE PHP2SHELL VULNERABILITY HERALDS CYBERSECURITY HELL (4 MINUTE
READ) [18]

 AI-assisted researchers turned a PHP crash bug reported in 2024 into
a critical vulnerability capable of running arbitrary code on a
server. Finding the exploit took two weeks, while four engineers spent
two months developing a patch, illustrating the growing gap between
discovering flaws and safely fixing them. Better funding for
open-source maintainers, defensive AI tools, and formal verification
could help close that gap.
