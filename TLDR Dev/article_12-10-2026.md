ARTICLES & TUTORIALS

 BUILD YOUR OWN DECISION MODEL (5 MINUTE READ) [6]

 A Qwen3-1.7B walkthrough turns multiple-choice questions into
single-pass predictions by scoring only the allowed answer tokens.
Fine-tuning improves accuracy on a 1,221-question CommonsenseQA sample
from 59.4% to 62.4%, while temperature scaling makes the model's
confidence better reflect its actual accuracy.

 HOW TO EFFECTIVELY DEBUG WHEN YOU NO LONGER UNDERSTAND THE CODE (63
MINUTE READ) [7]

 Three production investigations, a latency regression, a memory leak,
and a kernel-level hang, show how to steer coding agents through
unfamiliar systems using runtime evidence. The framework separates
facts from hypotheses, compares failures with a control, and requires
every proposed cause to satisfy all known constraints. Adversarial
reviews should seek contradictions, and reproductions must match the
real failure's signals before they can be trusted.

 FIVE MONTHS TREATING BUGS LIKE PATIENTS AND CODING AGENTS LIKE A
MEDICAL TEAM (20 MINUTE READ) [8]

 Cockroach Labs structures coding agents around a teaching hospital,
with reviewed plans, separate implementation and review roles,
structured handoffs, and an audit before merge. The pipeline landed
over a million lines of code in five months with seven reverts, and
human approval became mandatory after the first autonomous week before
the team used it to build customer-facing migration tooling.

 I'M SORRY, BUT YOU STILL HAVE TO THINK (8 MINUTE READ) [9]

 The AI-generated Campfire app rewrites make different choices about
compatibility, queues, and concurrency, so throughput alone cannot
establish which language performs better. Constant-arrival-rate tests
expose tradeoffs between dropped notifications, timeouts, memory use,
and delivery latency, showing why engineers still need to inspect code
and specify failure behavior.

 GRIEVING THE LOSS OF DETAILS (5 MINUTE READ) [10]

 A personal reflection explores the loss of professional identity when
AI shifts attention from low-level knowledge and performance details
toward architecture and delegation.

 WHY ISN'T THE INDUSTRY FREAKING OUT ABOUT DEEPSEEK 4.1 FLASH? (4
MINUTE READ) [11]

 An account of using DeepSeek 4.1 Flash across a dozen projects argues
that inexpensive models can handle much of the work typically assigned
to premium frontier models. Lower session costs encourage unattended
chores, exploratory testing, and long planning sessions, with a more
expensive model sometimes brought in for a final review.

 DENO IS JOINING CLOUDFLARE (3 MINUTE READ) [16]

 The Deno team is joining Cloudflare to focus on a shared platform
built around Workers, Durable Objects, and celld. Deno runtime
development will end after one year of bug fixes and security updates,
Deno Deploy will shut down in six months, and JSR will continue
operating on Cloudflare infrastructure.

 SPECULATIVE DECODING: THE ART OF GUESSING WELL (70 MINUTE READ) [17]

 Speculative decoding accelerates generation by drafting several
tokens cheaply and verifying them in one target-model pass while
preserving the target's output distribution. This detailed walkthrough
derives acceptance and speedup formulas, covers EAGLE-3, multi-token
prediction, and diffusion drafters, and explains why training for
acceptance is different from simply minimizing KL divergence.

 THE DIRTY PAGES SURPRISE: WHEN A READ-ONLY QUERY WRITES TERABYTES (10
MINUTE READ) [18]

 A MonetDB count-distinct query saturates an NVMe drive with writes
because Linux flushes dirty pages from temporary memory-mapped scratch
files. Moving the scratch files to tmpfs cuts runtime from 73 minutes
to 97 seconds, while workload-specific writeback tuning reaches about
100 seconds without moving them off disk.
