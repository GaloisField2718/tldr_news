ARTICLES & TUTORIALS

 MEASURING SOFT NAVIGATION WEB VITALS (11 MINUTE READ) [6]

 Sentry's JavaScript SDK v11 measures LCP, CLS, and INP for
client-side navigations, exposing slow routes that initial page-load
metrics miss. Support currently requires Chromium 151 or later, and
the scores should be filtered separately from page loads because their
clocks start at different points.

 THE WEB CAN'T AFFORD A JAVASCRIPT RUNTIME MONOCULTURE (6 MINUTE READ)
[7]

 Deno's planned end of runtime development narrows the major
server-side JavaScript choices to Node.js, Bun, and Cloudflare's
workerd. Historical examples from Internet Explorer and the io.js fork
show how independent implementations can prevent stagnation and push
features into competing runtimes.

 OPTIMIZING THE SH*T OUT OF TANSTACK START (17 MINUTE READ) [8]

 A TanStack Start site improved its mobile Lighthouse score from 73 to
100 and reduced LCP from 5.2 seconds to 1.7 seconds by removing
unnecessary JavaScript, images, and font data. More complex changes
added maintenance without clearly explaining the final score, making
basic asset reductions and regression budgets the more useful starting
point.

 HOW I BUILT THE MOST AI-PILLED COMPANY IN THE WORLD (18 MINUTE READ)
[9]

 Spawn reports shipping 77,000 substantial changes in 30 days with a
ten-person team and $3.1 million in token spending, using permanent
agents that own parts of the company. Its approach combines direct
production feedback, frequent tests, hourly deployments, and fast
recovery, with hard-coded gates for irreversible actions. Humans focus
on product taste and ambitious changes that agents rarely propose
themselves.

 DESIGN SYSTEMS SHOULD BE FAST BY DEFAULT (18 MINUTE READ) [10]

 Benchmarks of large dropdowns and checkbox lists across ten design
systems trace slow interactions to repeated layout work, slot
handling, and per-checkbox animations. Published Playwright tests
enforce timing budgets so shared components can catch performance
regressions before they reach every consuming app.

 WTERM (WEBSITE) [13]

 wterm renders a terminal into the DOM, providing native text
selection, browser find, and screen reader support. It offers React,
Vue, and Svelte bindings, pluggable Zig/WASM or Ghostty cores, and
WebSocket transport for connecting to a PTY backend.

 ELEMENTARYUI (WEBSITE) [14]

 ElementaryUI brings declarative Swift interfaces to the browser
through WebAssembly, with SwiftUI-inspired syntax and reactive state.
It supports Embedded Swift for small bundles and uses Vite for hot
reload during development.

 RADIX: 3D GAUSSIAN SPLATS FOR THE WEB (WEBSITE) [15]

 Radix stores 3D Gaussian splats in typed-array tables on the CPU and
GPU and renders them through three.js. Its examples run on WebGPU with
a WebGL2 fallback, and the site includes source code, documentation,
and ready-to-run scenes.

 PICO CSS IS NO LONGER MAINTAINED (1 MINUTE READ) [16]

 Pico CSS has been archived, with version 2.1.1 designated as the
final release. Existing npm packages, the CDN, and documentation
remain available, while the MIT license allows community forks under
different names.

 PROJECT SPEED (10 MINUTE READ) [17]

 Owner rebuilt infrastructure serving more than 10,000 restaurant
websites with Astro, selective React, and edge caching. Menu-page p75
LCP fell from 5.4 seconds to 0.7 seconds, while the rollout raised
per-restaurant revenue by more than 4%.

 HOW FAST CAN YOU ACTUALLY PATCH RUBY? (7 MINUTE READ) [18]

 A comparison of Ruby 4.0.9 availability tracks the gap between a
security release and its arrival in installers, container images, CI
providers, and hosting platforms. Core-team tools shipped within
minutes, while the default Docker image took almost 16 hours and some
cloud runtimes took days, showing why teams need to audit the entire
update path.
