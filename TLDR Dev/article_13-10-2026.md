ARTICLES & TUTORIALS

 CAN WE MAKE REACT FASTER USING THE REACT COMPILER? (20 MINUTE READ)
[6]

 React Compiler uses cache slots and tracks values that change
together to avoid unnecessary work. In a 2,000-row microbenchmark,
inlining alone slowed rendering from 444 ms to 1,038 ms by removing
per-row caches, while adding block DOM updates cut it to 164 ms. These
prototypes illustrate optimization opportunities, with workload and
memory tradeoffs still to evaluate.

 HOW I FOUND A $90,000 REMOTE CODE EXECUTION VULNERABILITY IN GOOGLE
(4 MINUTE READ) [7]

 Google's DevSite stored an OAuth secret inside a readable Flask
session cookie and reused it as the cookie's signing key, allowing
forged sessions to reach unsafe pickle deserialization. Timing-based
tests confirmed unauthenticated code execution across the shared
platform, earning a $90,000 bounty. The fix separates signing keys
from OAuth credentials and removes sensitive serialized objects from
client-controlled sessions.

 BUILDING SHARED WORKSPACES FOR PEOPLE AND AGENTS (10 MINUTE READ) [8]


 Perplexity Projects uses a lightweight Git forge backed by S3 storage
so people and agents can build on durable files from isolated,
temporary sandboxes. Submissions must match the latest accepted
commit, with stale writers replaying their changes rather than
overwriting concurrent work. In production, fewer than 2% of
submissions are rejected as stale, with median submit latency below
1.7 seconds.

OPINIONS & ADVICE

 38 THINGS WE'VE LEARNED ABOUT BUILDING AI PRODUCTS (8 MINUTE READ)
[9]

 PostHog's lessons from ten AI products emphasize useful jobs,
reliable execution, rich context, and interfaces that let agents do
everything users can. Its MCP server has five times as many daily
users as PostHog AI, while the install wizard compresses roughly two
hours of setup into eight minutes. The advice favors shared
infrastructure, observable tool calls, small targeted evals, and UI
for reviewing and undoing agent actions.

 HUMAN PR REVIEW IS NEXT (12 MINUTE READ) [10]

 AI code review will increasingly replace reading every diff, shifting
human work toward requirements, acceptance testing, and ownership of
releases. Independent review models, predefined guardrails, and
automated review-and-fix cycles form the proposed safety net. A
trading-bot rounding bug illustrates the tradeoff: fast fixes do not
erase losses or compensate for gaps in the specification.

 WHY WEBMCP MATTERS (9 MINUTE READ) [11]

 WebMCP lets websites expose JavaScript tools to agents, reducing the
slow, brittle interaction of navigating through screenshots and DOM
inspection while keeping users in a shared browser session. Shopify's
checkout experiment reported 2.7 times faster execution, 58% lower
cost, and 60 successful attempts out of 60 compared with 56 for
browser automation. Permissions, human approval signals, and testing
against complete agent systems remain open challenges.

 OPEN INTELLIGENT UI (GITHUB REPO) [14]

 Open Intelligent UI is an open-source chat interface built with
CopilotKit and AG-UI that turns questions into explanations,
comparisons, and interactive tools. Its agent chooses text, native
components, or custom HTML, CSS, and JavaScript rendered in an
isolated iframe, with Jev routing tables to A2UI and richer visuals to
Open Generative UI.

 UNROLLED CODE (16 MINUTE READ) [15]

 Explicit, repetitive Ruby code can make algorithms easy to inspect
and resemble the optimized output of ERB and Papercraft template
compilers. A proposed quote/unquote mechanism would let Ruby generate
code by composing immutable syntax trees instead of concatenating
source strings, with examples covering memoization, templates, and
routing.

 AI MODELS MAY BE CAPABLE OF SELF-REPLICATING WITHOUT ACCESS TO A
DATACENTER (26 MINUTE READ) [16]

 Anthropic demonstrates a 26B model running across 15 inexpensive
Android TV boxes and a 9B model setting up inference on eight of nine
tested hardware types. GLM-5.2 completed replication in a contained
fleet with deliberately trivial access controls, making the result an
upper bound on real-world success. Smaller models still struggle to
chain the steps together, while projected replication on low-powered
devices would take days.

 HOW PRO-CHINA ARE CHINESE MODELS? (17 MINUTE READ) [17]

 Vals AI tested politically sensitive questions across languages and
contexts, finding that Chinese models sometimes criticize China's
government while non-Chinese models sometimes echo official
narratives. Responses generally leaned more pro-China in Simplified
Chinese, while deployment prompts, response formats, and agent
harnesses could substantially change the results.
