ARTICLES & TUTORIALS

 MIGRATING OUR EMAIL API TO GO (7 MINUTE READ) [8]

 Resend moved its email API from Node.js to Go in seven weeks, testing
compatibility across responses, stored data, idempotency, and email
contents. During a 50% rollout, median email latency fell from 58 ms
to 31 ms and memory per task dropped from about 1.3 GB to 180 MB,
though burst capacity and storage timeouts still needed tuning.

 ANNOUNCING THE GRAPHQL OVER HTTP SPECIFICATION (4 MINUTE READ) [9]

 The first GraphQL over HTTP specification standardizes how requests
and responses travel over HTTP while keeping the core GraphQL
specification transport agnostic. Its
application/graphql-response+json media type lets clients recognize a
valid GraphQL response independently of the status code, improving
interoperability and observability.

 THE PATH TO RAILS 8.1: FROM VUE AND JQUERY TO STIMULUS (6 MINUTE
READ) [10]

 DNSimple replaced about 50 Vue components and its jQuery code with
native HTML, server-rendered Turbo Frames, and small Stimulus
controllers. A DNS-check example shows how moving permissions,
pricing, and failure-state rendering back to Ruby reduced duplicated
logic and eliminated three extra queries from pages that displayed the
control.

OPINIONS & ADVICE

 SWITCHER (15 MINUTE READ) [11]

 The story of the Macintosh's early application switcher connects
technical tradeoffs with the difficulty of pricing strategically
valuable software. A quick prototype led to months of compatibility
debugging, while negotiations with Microsoft and Apple exposed the gap
between valuing a program by development time and by what it enables
for users.

 PUT MCP NEXT TO YOUR API, NOT ON TOP OF IT (5 MINUTE READ) [12]

 This architecture argument favors REST and MCP adapters over shared
application flows, avoiding a second implementation of business logic
and an extra internal HTTP hop. A worked example shows incremental
migration from a legacy API, while distinguishing current support from
proposed elicitation and durable-task features.

 INTRODUCING GEMINI 4 HYDROGEN (14 MINUTE READ) [14]

 Gemini 4 Hydrogen targets fast coding and agent execution, with a
one-million-token context window priced at $1.50 per million input
tokens and $7.50 per million output tokens. Google is also introducing
Antigravity Orchestrator, which switches models within a session and
reportedly achieved near-Carbon task success on Terminal-Bench 4.0
while using 24% less quota and finishing 19% faster.

 QWEN CODE (GITHUB REPO) [15]

 Qwen Code is an open-source coding agent with terminal, editor,
desktop, and browser interfaces, plus headless execution and SDKs. It
supports multiple provider protocols and local models, with built-in
memory, skills, agent teams, and MCP integration.

 UI SDK (WEBSITE) [16]

 UI SDK packages more than 50 interface behaviors, including focus
management, selection, popups, and keyboard navigation, for coding
agents to compose into components. Its component examples work across
React, Vue, Svelte, Solid, and Web Components, with a skill that
teaches agents how the behaviors fit together.

MISCELLANEOUS

 ZIGZAG (GITHUB REPO) [19]

 ZigZag is a free Rust-based embroidery editor for macOS and Windows
that turns SVG artwork into stitches and exports common machine
formats. A built-in MCP interface lets agents create and edit designs,
while supported Brother Skitch machines can receive designs over
Bluetooth.

 BRAVE REMOVES TRACKING METADATA FROM INSTAGRAM AND FACEBOOK PHOTOS (5
MINUTE READ) [20]

 Brave desktop 1.98 strips the hidden FBMD identifier from downloaded
photos and uploads a cleaned copy when an existing file contains it.
The identifier can persist across reuploads and could link copies of a
photo, although Meta has not disclosed its purpose and Brave does not
establish that it is used for tracking.
