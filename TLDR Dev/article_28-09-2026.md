ARTICLES & TUTORIALS

 IMPROVING SITE PERFORMANCE BY SHIPPING MORE CSS (8 MINUTE READ) [7]

 GitHub explains how it migrated github.com from CSS-in-JS to CSS
Modules to remove client and server runtime styling costs. The gradual
rollout preserved component encapsulation while moving styles into
static stylesheets delivered with page HTML.

 REVEALING THE DETAILS OF HOW OPENAI AGENTS HACKED HUGGING FACE (20
MINUTE READ) [8]

 An investigation reconstructs how a swarm of 700 agents escaped
constrained evaluation environments and penetrated Hugging Face
systems. The report traces nearly one million chained short links,
more than 80,000 decoded payloads, credential exposure, Slack
searches, and attempts to hide evidence.

OPINIONS & ADVICE

 FIRST PRINCIPLES THINKING (4 MINUTE READ) [9]

 First-principles thinking asks engineers to set accumulated
assumptions aside long enough to identify the real problem and the
outcome that matters. With agents, that means working in small,
concrete steps that shorten learning loops, preserve momentum, and
make experimentation easier.

 PLAN MODE IS DEAD (9 MINUTE READ) [10]

 Plan modes turn useful thinking into long artifacts that people do
not want to read and impose an artificial boundary between planning
and building. A better workflow loops through understanding, action,
inspection, clarification, and adjustment while surfacing only the
decisions that need human attention.

 HOW TO KEEP ENJOYING PROGRAMMING IN A WORLD OF LLMS (8 MINUTE READ)
[11]

 Developers can preserve ownership, skill, and enjoyment by continuing
to write the code they care about themselves. LLMs are more useful for
planning, research support, bookkeeping, cleanup, and routine work,
with humans taking charge of crucial decisions and implementation.

 ATLAS (GITHUB REPO) [13]

 Atlas is source control for coding agents that links commits to the
sessions, prompts, tool calls, and reasoning that produced them. It
can run multiple agents side by side with shared local memory while
keeping code, notes, and sessions on the machine by default.

 WHITEBOARD (GITHUB REPO) [14]

 Whiteboard is an open-source desktop canvas where developers and
coding agents can design and review software together. It connects
diagrams, traces, and semantic diffs to the underlying code while
operating against local checkouts.

 MOBILE MCP (GITHUB REPO) [15]

 Mobile MCP gives agents one interface for automating native iOS and
Android apps across simulators, emulators, and real devices. It uses
structured accessibility snapshots for efficient interaction, then
falls back to screenshots and coordinates when needed.

MISCELLANEOUS

 PERSONAL AI AGENTS QUIETLY UPSELL USERS THEY THINK ARE RICH (6 MINUTE
READ) [16]

 Across 325,000 trials and 13 models, agents recommended more
expensive flights, insurance, and graduate programs to users they
inferred were wealthy despite identical requests. The study used
synthetic personas, but explicit requests for the cheapest option
often failed to remove the gap while hard price caps were more
effective.

 FIFTEEN YEARS LATER, THE APPLE CARDS ORIGIN STORY (8 MINUTE READ)
[17]

 Apple's short-lived Cards app began as a Steve Jobs idea for sending
a physical thank-you card directly from an iPhone. Its 2011 launch
required new letterpress designs, cotton paper, international
printing, postage coordination, and a production operation remembered
for extraordinary complexity.

 ALMOST NOBODY GETS XML SITEMAPS RIGHT (5 MINUTE READ) [18]

 Sitemap Inspector began as a way to make XML sitemaps readable and
evolved into a checker for redirects, HTTP errors, noindex directives,
and canonical mismatches. Tests found sitemap problems across major
sites including Adobe, Anthropic, GOV.UK, Manchester City, Semrush,
and X.
