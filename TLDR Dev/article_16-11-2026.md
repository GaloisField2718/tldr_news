ARTICLES & TUTORIALS

 HOW TO SPEED UP CI IN THE AGE OF AI-WRITTEN CODE (8 MINUTE READ) [6]

 AI coding agents produce code faster than CI pipelines can check it,
turning long pipelines into queues for developers and agents. Five
fixes target the bottleneck: measure slow steps, cache dependencies,
use faster runners, parallelize jobs and tests, and skip redundant
work with path filters and cancellation. Change one thing at a time
and check vendor speed claims against your own pipeline.

 GOAL ENGINEERING: HOW TO DESIGN GOALS (5 MINUTE READ) [7]

 Agent feedback becomes a bottleneck when expert knowledge and
subjective preferences live only in people's heads. Scope goals around
what humans can review efficiently, rather than simply giving each
agent more context. In the Actively AI case study, agents organized by
job type across accounts let salespeople review similar tasks together
and share lessons across their work.

 LET'S WRITE A POSTSCRIPT INTERPRETER (14 MINUTE READ) [8]

 Build a small PostScript interpreter in JavaScript, starting with
tokenization, operand and dictionary stacks, and representations for
names, arrays, and procedures. This tutorial adds execution and an
interactive REPL, then explores recursion, iteration, and dynamic
scope. It deliberately omits graphics, strings, most error handling,
and other parts of the full language.

OPINIONS & ADVICE

 ALL AI-GENERATED CODE SHOULD BE OPEN SOURCE (2 MINUTE READ) [9]

 This essay argues that AI-generated code should be released under
open-source licenses or dedicated to the public domain because models
depend on collectively produced code. It also raises copyright
questions while acknowledging that jurisdictions differ and that human
involvement varies. The proposal is an argument about how developers
should share generated work.

 TEACH AI CODING ASSISTANTS YOUR DESIGN SYSTEM WITH MARKDOWN (9 MINUTE
READ) [10]

 Document tokens, component APIs, and composition patterns in Markdown
beside the code, then use AGENTS.md to tell coding assistants what to
read. A React and Tailwind demo illustrates how automated checks can
flag hardcoded colors, unsupported variants, and spacing drift. The
examples are constructed rather than a controlled AI experiment, and
Markdown guidance still needs maintenance and accessibility review.

 INTRODUCING UI SDK (2 MINUTE READ) [12]

 UI SDK provides more than 50 TypeScript behaviors for keyboard
navigation, focus, selection, popups, drag and drop, and the
associated ARIA attributes. Developers and agents can compose them
into custom components or use ready-made libraries for React, Vue,
Svelte, Solid, and Web Components. Agent interaction can be limited
through developer-defined permissions, and the library remains in
beta.

 THE CONSOLE FRAMEWORK (WEBSITE) [13]

 Text.js lets developers build React applications that render inside
the browser's DevTools console. One app can run in the browser
console, in a terminal, or through MCP for coding agents.

 DEEPSEEK V3 IN PURE JAX (GITHUB REPO) [14]

 A 190-line JAX implementation recreates DeepSeek V3 architecture
features, including latent attention, routed experts,
auxiliary-loss-free balancing, and multi-token prediction. The
reported MacBook Air run trained a 36.2-million-parameter model on
detective fiction in about 2.6 hours. It is an educational
architecture demo rather than a production language model.

MISCELLANEOUS

 A FAMILY TREE OF SOFTWARE JOB TITLES (5 MINUTE READ) [17]

 An interactive family tree traces 104 software job titles from human
computers to AI agent and context engineers across seven role
families. It highlights how responsibilities split, recombine, and
reappear under new names, including the overlap among DevOps, SRE, and
platform engineering. Dates indicate roughly when titles became common
and are estimates rather than a sourced chronology.

 DECLARATIVE DRAGGING (WEBSITE) [18]

 Declarative dragging lets developers specify which future application
states an element should reach, then renders those states to
synthesize drop zones and animated interactions. Dragology implements
the approach for SVG interfaces on the web, with composable behaviors
and modifiers for snapping and transitions. The project received a
UIST 2026 Best Paper award.
