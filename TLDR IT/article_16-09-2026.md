NEWS & TRENDS

 DREAMFORCE 2026: SLACK'S NEWEST INNOVATIONS TURN AI INTO A TRUE
TEAMMATE (6 MINUTE READ) [6]

 Slack is expanding far beyond chat with Slackbot in channels,
full-screen AI workspaces, live Salesforce-powered Surfaces, and Slack
Code, where developers and AI agents can build and review code
collaboratively. Slack is becoming a control surface for more business
systems and agents, raising new questions around app governance,
permissions, licensing, and what employees should be allowed to
connect.

 WINDOWS 11 KB5129195 IS OUT AFTER MICROSOFT CONFIRMS MAJOR ISSUES
WITH THE SEPTEMBER 2026 UPDATE, BUT IT WON'T FIX AMD GPU ERRORS (7
MINUTE READ) [7]

 Microsoft has released an out-of-band Windows 11 update after
September's Patch Tuesday caused problems with Remote Desktop, audio,
virtualized apps, and other components. KB5129195 fixes several of the
issues, but reported Explorer crashes, File History failures, some USB
audio problems, and AMD GPU instability remain worth watching before
accelerating enterprise deployment.

ANALYSIS & OPINIONS

 AI WAS SUPPOSED TO MAKE SOFTWARE CHEAPER. SO WHY IS IT MORE EXPENSIVE
NOW? (12 MINUTE READ) [8]

 Despite dramatic improvements in developer productivity and falling
unit costs for AI intelligence, software is becoming more expensive
due to rising software scope and Jevons paradox driving up
consumption. Software has historically been priced on the value
delivered to the buyer rather than production labor costs.
Consequently, efficiency gains are absorbed by increased inference
usage and higher feature expectations rather than lower bills.

 WHEN YOUR CRM STARTS BUILDING ITSELF: THE CIO'S ROLE IN THE AGENTIC
SAAS ERA (12 MINUTE READ) [9]

 AI is turning business users into application and agent builders
faster than traditional IT processes can keep up. Instead of trying to
centrally build everything, CIOs increasingly need to own the
foundations - identity, data architecture, observability, integration
standards, and agent governance - while letting business teams build
safely on top of them.

 DREAMFORCE OPENS WITH AI, BUT QUESTIONS FOR CIOS REMAIN (5 MINUTE
READ) [10]

 Salesforce's Dreamforce announcements point toward enterprise
software being accessed increasingly through agents, MCP, and
conversational interfaces rather than traditional application screens.
The unresolved IT question is economic: as software moves away from
predictable seat-based licensing toward agent usage, MCP calls, and
consumption pricing, CIOs may gain flexibility while losing some cost
predictability.

LAUNCHES & PARTNERSHIPS

 GPUS DELIVERED WITH THE INFERENCE STACK FLASHED. AMD INSTINCT™
CODER. (SPONSOR) [11]

 Building an inference stack takes months, especially in today's
severely supply constrained environment. AMD Instinct™ Coder [12],
powered by Spectro Cloud, ships as a Supermicro server with AMD
Instinct GPUs and PaletteAI Inference Launchpad [13] already flashed.
Serve inference in a day.

 MEET ADAPT, WESTPAC'S AZURE-BASED ENTERPRISE DATA PLATFORM (5 MINUTE
READ) [14]

 Westpac's Adapt is a new enterprise data platform built on Microsoft
Azure that consolidates data from 285 source systems into a single
governed environment. The platform required migrating over 1PB of data
and 14,000 data pipelines. Additionally, Westpac utilizes a
Snowflake-powered intelligence layer to run advanced AI models on data
at rest without moving it.

 INTRODUCING BUILDER CENTRAL: THE NO CODE AI WORKSPACE FOR SALESFORCE
(5 MINUTE READ) [15]

 Salesforce Builder Central is a no-code AI workspace designed to let
admins and business users build and configure apps and agents using
plain language. Powered by Headless Toolkit, the workspace natively
reads company metadata and Data 360 context while providing built-in
trust, security, and automatic safety checks. The beta version is
scheduled to launch the week of September 21.

 BUILD WITH CONFIDENCE: APP GOVERNANCE, ACCESS, AND ACCOUNTABILITY AT
HUBSPOT (6 MINUTE READ) [16]

 HubSpot is adding centralized controls for which apps and AI
connectors can be installed, who can install them, what data they can
access, and who owns each integration. Particularly useful for IT:
admins can require approval, use more granular OAuth scopes, restrict
MCP access to company-provisioned accounts, see app activity logs, and
get warned when deactivating someone who owns an integration.

 ZOOM UNVEILS AI-POWERED REVENUE OS TO UNIFY BUYER INTELLIGENCE,
CUSTOMER CONVERSATIONS, AND REVENUE EXECUTION (5 MINUTE READ) [17]

 Zoom is expanding its platform with Common Room integration and new
Revenue Accelerator capabilities for engagement and forecasting. It is
another example of collaboration vendors broadening into adjacent
enterprise workflows, potentially giving IT teams more opportunities
to consolidate tools, but also more overlap to evaluate across CRM,
meeting intelligence, and sales platforms.

MISCELLANEOUS

 OBSIDIAN VAULT TO ENTERPRISE COMPANY BRAIN: WHERE AGENTS WRITE,
BRANCH, AND MERGE (14 MINUTE READ) [18]

 Scaling knowledge management from a personal Obsidian graph to an
enterprise-grade "company brain" requires AI agents to manage
knowledge without corrupting it through hallucinations or conflicting
updates. Versioned branches, object storage, and a typed graph schema
can keep changes controlled, with human review governing merges.

 AI CLOUD BILLS ARE FORCING TECHNOLOGY LEADERS TO RETHINK AWS, AZURE
AND GCP COMMITMENTS (5 MINUTE READ) [19]

 AI workloads are disrupting traditional cloud commitments as GPU
availability, data movement, egress fees, and unpredictable inference
demand make long-term AWS, Azure, and GCP agreements harder to
forecast. CIOs are increasingly separating AI infrastructure economics
from general cloud spend, negotiating more flexible capacity terms,
and deciding which high-cost workloads need to remain portable across
providers
