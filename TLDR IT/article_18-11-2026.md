NEWS & TRENDS

 WINDOWS ADDS TIGHTER CONTROLS FOR AI AGENTS (6 MINUTE READ) [8]

 Microsoft announced new Windows controls for AI agents, including
preview improvements to process containers and experimental
hardware-isolated micro VMs. Generally available learning modes let IT
observe agent behavior before enforcing restrictions, while Intune is
previewing automatic updates for applications employees install
themselves.

 OPTIMIZELY BREACH SPREADS MALWARE ACROSS MAJOR WEBSITES (4 MINUTE
READ) [9]

 Attackers exploited Optimizely's experimentation software to
distribute malicious JavaScript through websites belonging to at least
178 organizations. The payloads targeted cryptocurrency wallets and
payment details. Optimizely says it patched the vulnerability, removed
injected code, and revoked tokens.

ANALYSIS & OPINIONS

 WHEN AI-GENERATED DATA BECOMES TOMORROW'S GROUND TRUTH (14 MINUTE
READ) [10]

 Enterprise AI-generated conclusions can lose their original context
and become treated as established facts when integrated into
operational systems, allowing errors to spread across dashboards,
reports, and training data. Decision lineage addresses this problem by
linking AI-generated assertions to their source evidence, governing
workflows, and downstream decisions. This allows organizations to
trace changes, identify affected systems, and systematically correct
outdated or inaccurate conclusions.

 MICROSOFT AND SALESFORCE INTRODUCE COPILOTFORCE (8 MINUTE READ) [11]

 Microsoft and Salesforce announced integrations connecting Salesforce
with Copilot, Teams, and Fabric. A Copilot plugin is available in
public preview with more than 38 sales skills, letting employees
retrieve customer information and take supported actions under their
existing Salesforce permissions.

 TEAMS GAINS MORE PROTECTION AGAINST IMPERSONATION (3 MINUTE READ)
[13]

 Microsoft is introducing new capabilities to combat social
engineering and impersonation across Teams meetings and calls. These
updates include Impersonation Protection to warn users about
suspicious participants, an automated skill for the Facilitator agent
to scan transcripts for deceptive requests, and a Microsoft Defender
data table for forensic investigations.

 OPEN DATA SHARING: SHARE LIVE DATA BEYOND SNOWFLAKE (5 MINUTE READ)
[14]

 Snowflake has launched Open Data Sharing, enabling data providers to
share Apache Iceberg tables with external consumers using Iceberg REST
Catalog-compatible clients without requiring a Snowflake account or
scheduled data exports. This new feature complements existing
Snowflake pathways by extending data distribution capabilities to
mixed technology environments.

MISCELLANEOUS

 GOOGLE, AMAZON AND MICROSOFT: THREE API ESTATES, AND WHAT A SOURCE OF
TRUTH DOES (5 MINUTE READ) [15]

 An analysis of Amazon, Google, and Microsoft's API catalogs shows
that consistency depends on maintaining a single machine-readable
source of truth rather than relying on organizational practices alone.
While vendor specifications provide a reliable baseline for API
operations, all three companies lack sufficient agent readiness
capabilities, particularly around workflows, costs, and lifecycle
management.

 AN OPEN-SOURCE E-READER PROJECT CONFRONTS THE AI CONTRIBUTION FLOOD
(5 MINUTE READ) [16]

 Crosspoint Reader has passed 300,000 installations, bringing
open-source firmware to tiny, inexpensive e-readers. Its growth also
illustrates the pressure AI-generated contributions put on volunteer
maintainers, who must review submissions and manage feature requests
within tight hardware limits.
