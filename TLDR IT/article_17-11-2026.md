NEWS & TRENDS

 RELEASING PERSONAL AGENT PROTOCOL 1.0 (3 MINUTE READ) [8]

 Sierra has released version 1.0 of the Personal Agent Protocol, known
as Poppy, a standard that enables personal agents to interact securely
with businesses. Shopify has enabled the protocol for its merchants,
and design partners including Mercury, Synchrony, and Turkish Airlines
are going live with implementations. The v1.0 release incorporates
feedback from testing, integrates with existing standards like OAuth
and OpenAPI, and features a commerce extension co-authored by Shopify.


 INFOBLOX BREACH EXPOSES CUSTOMER AND EMPLOYEE DATA (3 MINUTE READ)
[9]

 Infoblox is investigating a compromised migration vendor whose access
was reportedly used to steal SharePoint data, including customer
network configurations and sensitive employee information. The company
says it has found no indication that its products, cloud services, or
software releases were involved.

 GARTNER WARNS WEAK AI CONTROLS COULD DISRUPT CRITICAL SERVICES (4
MINUTE READ) [10]

 Gartner predicts weak governance will cause business-critical
disruptions at 40% of infrastructure and operations organizations
scaling AI by 2028. Its survey found that only 15% of respondents have
automatic circuit breakers to stop runaway agents, despite 95%
reporting an agent-related incident in the past year.

ANALYSIS & OPINIONS

 CYBERSECURITY AT MACHINE SPEED (21 MINUTE READ) [11]

 Artificial intelligence is creating a revolutionary acceleration in
cybersecurity, allowing attackers to operate at machine speed by
compressing the OODA loop while defenders remain constrained by
complex institutional governance. Because attackers need only one
successful exploit among many while defenders must maintain safety,
availability, and continuity across complex systems, organizations
must adopt automated, policy-enforced boundaries and zero-trust
architectures to bridge the asymmetry.

 CLOUD OVERSPENDING STARTS WITH UNCLEAR OWNERSHIP (5 MINUTE READ) [12]


 Cloud adoption has outpaced changes to how companies run IT, leaving
teams responsible for costs and reliability without matching control.
Clearer ownership and redesigned operations will address these
problems more effectively than adding tools or training alone.

 KITESURF IS NOW OPEN SOURCE (4 MINUTE READ) [14]

 Cloudflare has open-sourced Kitesurf, its stateless browser for AI
agents that runs entirely on Cloudflare Workers. Available under the
Apache 2.0 license on GitHub, the tool allows developers to run their
own browser engine locally or deploy it to their Cloudflare accounts
to support automated workloads using the Chrome DevTools Protocol.

 DELL EXPANDS ITS DATA PLATFORM FOR AI AGENTS (8 MINUTE READ) [15]

 Dell announced an Agentic Data Gateway and hybrid pipelines that
connect agents to approved enterprise data, models, and tools on
customer-controlled infrastructure. Integrations with LangChain,
OpenAI Codex, and Unstructured add agent development and
document-processing capabilities.

 GITHUB COPILOT ADDS ENTERPRISE SERVER SUPPORT (2 MINUTE READ) [16]

 The Copilot app now supports GitHub Enterprise Server repositories,
issues, and pull requests, although cloud sessions remain unavailable

MISCELLANEOUS

 ARE UNIT TESTS STILL IMPORTANT WHEN AI AGENTS WRITE THE CODE? (7
MINUTE READ) [17]

 As AI agents increasingly write application code, some developers are
experimenting with removing unit tests or entire test suites from
continuous integration to save time and token usage. While redundant
snapshot tests often provide no value, test suites that enforce
explicit rules and run real engines successfully catch critical bugs
introduced by agents.

 AGENTS NEED AN UNDO BUTTON, NOT MORE APPROVAL PROMPTS (8 MINUTE READ)
[18]

 AI agents need reliable undo mechanisms rather than frequent,
fatigue-inducing approval prompts for high-impact actions. Borrowing
from database and distributed systems design like the Sagas pattern,
tools can be categorized into four types based on reversibility:
reversible, compensable, delayable, and irreversible. Tracking and
executing undos should live in the underlying system rather than
within the agent itself to maintain robust safety oversight.

 AMAZON LOSES 40 BROADBAND SATELLITES IN FAILED LAUNCH (3 MINUTE READ)
[19]

 A United Launch Alliance rocket failed to deliver 40 Amazon broadband
satellites to orbit after an anomaly during Sunday's flight. The
mission was the first to use a Vulcan configuration tailored for
Amazon's constellation, and the impact on subsequent launches remains
unclear.
