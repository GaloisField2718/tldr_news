NEWS & TRENDS

 ANTHROPIC SIGNS $11.6 BILLION CLOUD DEAL WITH AKAMAI (5 MINUTE READ)
[8]

 Anthropic committed $11.6 billion over seven years to Akamai's cloud
infrastructure to support growing CPU workloads. The agreement could
expand by another $9 billion and includes warrants that could give
Anthropic roughly a 5% stake in Akamai.

 AWS BECOMES FIRST HYPERSCALER TO SECURE ‘NATO RESTRICTED' APPROVAL
(2 MINUTE READ) [9]

 Amazon Web Services has become the first hyperscaler to receive NATO
Restricted approval, allowing member nations and defense partners to
handle mission-critical restricted workloads across 15 qualifying AWS
Regions. Evaluated by Spain's National Cryptographic Centre, the
accreditation provides a pre-assisted security baseline and
streamlined access to cloud capabilities for the alliance.

 DATABRICKS ACQUIRES ROW ZERO FOR GOVERNED SPREADSHEETS (4 MINUTE
READ) [10]

 Databricks acquired Row Zero to bring a native spreadsheet interface
to Genie, letting business teams analyze live enterprise data with
built-in permissions and auditability. The planned integration
supports familiar formulas and pivot tables while reducing reliance on
exported files that lose governance controls.

LAUNCHES & PARTNERSHIPS

 UIPATH MAPS THE MISSING LAYER FOR ENTERPRISE AI WITH CARTOGRAPHER (7
MINUTE READ) [12]

 UiPath announced Cartographer and the Map of Work at its FUSION 2026
event, introducing a new product designed to capture enterprise
processes and generate governed process maps for AI agents and
automations. The tool uses AI to absorb existing documentation,
interview experts, and track decisions through a ledger to keep
process maps continuously updated.

 DEVIN NOW WORKS ACROSS MICROSOFT TEAMS AND MICROSOFT 365 (4 MINUTE
READ) [13]

 Cognition has launched native support for @ mentioning Devin in
Microsoft Teams alongside a first-party Microsoft 365 integration. The
update allows Devin to participate directly in Teams chats, channels,
and threads, as well as connect to mail, calendar, files, tasks, and
directory services through Microsoft 365 MCP servers. The integrations
feature delegated per-user permissions and resource-specific consent
controls designed for security review.

 DOCKER LAUNCHES CLOUD SANDBOXES FOR LONG-RUNNING AGENTS (6 MINUTE
READ) [14]

 Docker introduced managed cloud sandboxes that let coding agents keep
working after developers disconnect, with a command to move sandbox
files between local and cloud environments. Each agent runs in its own
microVM, with configurable network access and usage-based compute
pricing starting at $0.07 per hour.

MISCELLANEOUS

 UBUNTU MOVES TO WEEKLY KERNEL RELEASES AS CVES PILE UP (3 MINUTE
READ) [15]

 Canonical is replacing Ubuntu's existing kernel update cadence with
overlapping two-week cycles that produce a release every week. The
change aims to shorten patch delays as AI-assisted bug discovery and
broader Linux CVE reporting increase the vulnerability backlog.

 PINECONE BRINGS MANAGED VECTOR DATA TO CUSTOMER CLOUDS (4 MINUTE
READ) [16]

 Pinecone's Bring Your Own Cloud offering is generally available
across AWS, Google Cloud, and Azure, keeping customer data and queries
inside customer-controlled accounts. Pinecone manages upgrades and
scaling through an outbound, pull-based mechanism without requiring
standing inbound access to the environment.
