NEWS & TRENDS

 MAJOR UPDATES FOR APPLE'S SOFTWARE PLATFORMS ARE NOW AVAILABLE (4
MINUTE READ) [7]

 Apple has released its annual software wave across iOS 27, iPadOS 27,
macOS 27, watchOS 27, visionOS 27, and tvOS 27. For IT teams, this
officially starts the testing and deployment window, with device
eligibility, Apple Intelligence and Siri AI availability, application
compatibility, and managed-device behavior worth validating before
broad rollout.

 GOOGLE SIMPLIFIES MICROSOFT 365 MIGRATIONS, BUT ENTERPRISE LIMITS
REMAIN (3 MINUTE READ) [8]

 Google Workspace now has a built-in setup workflow that can discover
Microsoft users and migrate email, OneDrive files, calendars,
contacts, and tasks. The catch: automated migrations currently support
only 10 Microsoft users, so it is useful for small environments but
does not replace enterprise migration tooling yet.

ANALYSIS & OPINIONS

 GOLDIE CUTS THROUGH THE SALVATION ARMY'S IT MAZE (6 MINUTE READ) [9]

 The Salvation Army is using an AI employee-support assistant inside
Microsoft Teams to front multiple internal systems and help more than
10,000 personnel find answers without knowing which platform owns the
information. The interesting lesson for IT is less about the chatbot
and more about the underlying integration, ownership, guardrails, and
service-design work required to make an AI support layer genuinely
useful.

 GOVERN AI AGENTS LIKE WORKERS. JUST DON'T PRETEND THEY'RE HUMAN (10
MINUTE READ) [10]

 As AI agents gain the ability to update records, issue refunds,
communicate with customers, and operate across enterprise systems,
organizations need clearer rules around what each agent can access and
do. The argument: borrow useful concepts from workforce
management—onboarding, scoped authority, supervision, and
offboarding—but keep accountability with the humans granting that
access.

 AI AGENTS CAN USE QUILL TO TALK DIRECT TO ENTERPRISE SQL DATABASES (2
MINUTE READ) [12]

 RavenDB has made its Quill software available to let AI agents query
live enterprise SQL databases without data migration or a custom AI
stack. Quill creates a synchronized context layer using change data
capture that runs outside production and includes search, retrieval,
and governance controls. Customers can launch production-ready agents
in weeks for PostgreSQL, SQL Server, and MySQL deployments in the
cloud or on-premises.

 DEVICIE MAKES APPLICATION MANAGEMENT AUTOMATIC WITHIN MICROSOFT
INTUNE, MATCHING THE SPEED OF AI (4 MINUTE READ) [13]

 Devicie is expanding its Intune automation to manage updates for more
than 1,500 Windows and macOS applications, as well as customer
line-of-business apps. Importantly, it operates inside the existing
Microsoft stack and leaves deployment timing and update-ring control
in Intune rather than introducing another endpoint-management console.

 TAKE CONTROL OF SNAPSHOTS (7 MINUTE READ) [14]

 APFS Time Machine snapshots preserve storage blocks for rollback,
which causes used space to grow as files change, requiring careful
management. The process covers creating snapshots with tmutil
commands, limiting their size by isolating large files on a separate
APFS volume, deleting old snapshots in Disk Utility while keeping the
latest, and rolling back the Data volume from Recovery.

 DATABRICKS CHANGES HOW WORKSPACE ACCESS IS GRANTED (3 MINUTE READ)
[15]

 Databricks is changing how workspace access is granted, with new
users and service principals now requiring explicit entitlements
instead of automatically inheriting access from the users system
group. The change became mandatory on September 14, and organizations
using Terraform, SCIM, or custom provisioning scripts may need to
update their automation.
